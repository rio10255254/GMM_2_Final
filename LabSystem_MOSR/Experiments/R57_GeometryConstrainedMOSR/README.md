# R57 Geometry-Constrained MOSR

R57 is the next LabSystem_MOSR experiment after R55/R56. It keeps the current
GeoEdgeAlignSR model family and starts from the R55 best-tradeoff checkpoint,
then adds geometry/CD safeguards for the HS-100MG sample captured with the
Basler ace acA2040-120um camera.

## Why This Exists

The current R55 reconstruction improves some visual edge qualities, but the
Basler-corrected SEM comparison shows that it worsens absolute CD on the
100MG sample:

- via radius becomes too small compared with SEM;
- pillar radius becomes too large compared with SEM;
- PSF on/off changes are small and do not fix the CD bias.

R57 treats this as a geometry-bias problem, not as a reason to discard the
displacement thesis direction. The target is geometry-constrained error
transformation: preserve frame-to-frame displacement behavior while preventing
the reconstructed boundary from moving to the wrong absolute location.

## Data Plan

R57 training uses a mixed package:

- Base data: the R55 source-style repaired R53 package.
- Anchor data: generated HS-100MG circle/cylindrical-hole patterns at 69 nm/px,
  using the SEM reference radii from the current sample. The default anchor
  count is intentionally high so the 100MG geometry is not drowned out by the
  larger R55 base package.
- Sidecars: boundary, centerline, and distance-edge geometry maps for every
  label image.

## Training Plan

R57 defaults to fine-tuning R55 best_tradeoff. The PSF-forward loss is disabled
by default because this sample does not yet have a recalibrated PSF.

```powershell
C:\Users\Rio\anaconda3\python.exe -u .\LabSystem_MOSR\Experiments\R57_GeometryConstrainedMOSR\scripts\launch_r57.py `
  --candidate r57_geom_cd_anchor_finetune `
  --num-epoch 20 `
  --batch-size 8 `
  --val-batch-size 2 `
  --num-workers 2 `
  --seq-batch-size 2 `
  --run-suffix hs100mg_gc_finetune_e020
```

For a short sample-focused calibration pass, add `--anchor-focus`. This trains
only on the HS-100MG anchor subset inside the mixed package.

## Required Gate

than R55:

## Adoption Rule

R57 is adoptable only if it is not worse than the original image on both pillar
and via CD error, and it keeps the existing sequence/displacement checks within
the R55 acceptance range.
