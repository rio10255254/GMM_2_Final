# MOSR Project Archive 20260624

This folder is the clean entry point for the current MOSR evidence state.

Use this order:
1. 01_raw_data_index: original data locations and calibration-report photos.
2. 03_step_validation: curated Step evidence for displacement, GMF, CD, and shape.
3. Experiments/R61_STEP_Generalization_20260623: full R61 model-candidate run folders.
4. 05_generalization_tests: copied phantom/simulation summaries for shape generalization checks.
5. 06_thesis_evidence_pack: short thesis-ready summary.

Important guardrails:
- Step and 100MG are separate samples.
- The Mitutoyo CHART-009 photos belong to the Step sample.
- The circle table in the report is roundness/form deviation, not certified circle diameter CD.
- The 0.4 mm line width has a certified value of 399.63 um, but the current Step displacement images do not capture that line-width region.
- R61 is both an R-series research line and a thesis/model-candidate evidence source.
- Current evidence supports Step-sample CD/shape preservation with stable displacement; it does not prove universal cross-sample guarantee.
