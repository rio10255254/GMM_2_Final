## 1. 報告目的與背景

### 1.1 承接單張分析的五個未解問題

單張影像分析報告（`R26_SingleImage_Analysis_Report.md`）確認了 R26 模型在單張影像上的幾何改善效果（殘差 std 改善 53-59%、邊緣寬度縮小 36-37%），但留下了五個關鍵的**時間穩定性問題**：

| # | 問題 | 為什麼單張無法回答 |
|---|------|------------------|
| Q1 | 這些改善在序列各幀上都穩定嗎？ | 需要多幀數據計算幀間變異 |
| Q2 | 內邊界 k=2 橢圓模式是固定偏置（安全）還是幀間波動（風險）？ | 需要序列觀察振幅/相位穩定性 |
| Q3 | 圓心偏移 0.31→0.75 px 是固定偏置還是動態漂移？ | 需要多幀趨勢分析 |
| Q4 | 殘差 std 53-59% 的改善幅度在所有幀都成立嗎？ | 需要逐幀計算改善比例 |
| Q5 | 高殘差 cluster 在幀間出現在相同位置嗎？ | 需要多幀角度熱點圖比較 |

本報告使用三個不同 pitch 步長的連續位移序列，對上述五個問題逐一給出量化裁決。

### 1.2 最終驗收指標

> **外部 GMF 0.8px step_std < 0.167862**（Round30 baseline）

本報告計算的是**內部 step_std**（基於圓擬合圓心的幀間位移標準差），作為外部 GMF 的代理指標。兩者測量方式不同（圓擬合 vs 全環模板匹配），但追蹤的是相同的物理量（環形結構的幀間位置波動）。

## 2. 測試設定

### 2.1 三個資料集

| 資料集 | 名義步長 | 像素步長 | 分析幀數 | 影像尺寸 | 角色 |
|--------|---------|---------|---------|---------|------|
| Pitch1um_Y_100 | 1 μm | ~8.0 px | 101 | 1520×2180 | 大步長警戒線 |
| **Pitch0.1um_Y_60** | **0.1 μm** | **~0.8 px** | **61** | **1500×1500** | **主戰場** |
| Pitch0.01um_Y_40 | 0.01 μm | ~0.08 px | 41 | 1500×1500 | 微步長警戒線 |

### 2.2 影像配對邏輯

R26 重建時使用 `--select-mode odd`，因此只有奇數索引幀有重建輸出。以檔名作為 join key，只分析同時存在 input 和 output 的幀。

### 2.3 Per-frame 分析流程

每幀獨立執行：annulus 偵測 → 360 角度邊緣提取 → 內外邊界圓擬合 → 諧波分解（DFT + 能量分解）→ 熱點 cluster 量化 → 邊緣寬度量測。後續幀使用前一幀的 annulus 參數作為偵測起點（ref_hint），提升偵測穩定性。

## 3. 結果一：幀間步進穩定性（Internal step_std）

*對應 Plot 01：`01_center_trajectory.png`、Plot 02：`02_step_stability.png`*

### 3.1 核心數據

| 資料集 | Input step_std_y | Output step_std_y | 改善幅度 | GMF step_std | GMF baseline |
|--------|-----------------|-------------------|---------|-------------|-------------|
| Pitch1um_Y_100 (8px) | 9.911 px | **0.199 px** | **↓ 98.0%** | 0.201 | 0.205 |
| **Pitch0.1um_Y_60 (0.8px)** | **2.940 px** | **0.205 px** | **↓ 93.0%** | **0.191** | **0.168** |
| Pitch0.01um_Y_40 (0.08px) | 3.877 px | **0.162 px** | **↓ 95.8%** | 0.180 | 0.158 |

### 3.2 Input step_std 為何如此高？

Input step_std 在三個資料集上分別為 9.9、2.9、3.9 px——遠超名義步長（8、0.8、0.08 px）。這不是物體在劇烈抖動，而是**定位噪聲**：模糊邊界的灰階梯度太淺，圓擬合的圓心定位精度遠不足以追蹤亞像素位移。

更深一層看，8px dataset 的 input step_std（9.9 px）反而最大，這看似矛盾——更大的步長不是應該更容易追蹤嗎？但 8px 影像（1520×2180）的外半徑 ~597 px，邊界周長更長，模糊帶來的局部擬合不穩定性在更大的幾何尺度上放大。而 0.8px 和 0.08px 影像（1500×1500）的外半徑 ~450 px，擬合的幾何尺度較小，定位噪聲也相應較小。本質上，input 的 step_std 反映的是**圓擬合定位精度的上限**，與真實步長無關。

### 3.3 Output step_std：噪聲地板的概念

Output step_std 穩定在 0.16–0.21 px，改善幅度 93–98%。但三個 dataset 的 output step_std 不是完全相同的——如果圓擬合完全無噪聲，理想值應為 0（在恆定步長序列中，每步完全相同）。殘餘的 0.16–0.21 px 代表了一個**噪聲地板**（noise floor），其組成包括：

1. **圓擬合的有限精度**：即使邊界銳利，360 個角度的離散取樣和最小二乘法擬合仍有有限精度。這個分量估計在 0.05–0.1 px 量級。
2. **結構缺陷的幀間微擾**：前述 21–33 個持續高殘差角度的殘差強度雖穩定，但不會 100% 完美恆定。微小的強度波動會偏移圓心。
3. **真實機台振動**：物理平台在亞像素尺度上不可能完美線性位移，真實的 step-to-step 抖動是 step_std 的不可約分量。
4. **影像數位化效應**：BMP 整數灰階 → 亞像素插值的量化誤差，估計 < 0.05 px。

我們無法從目前數據中分離這四個分量。但可以觀察到：0.08px dataset 的 output step_std（0.162 px）低於 0.8px（0.205 px），而兩者的影像尺寸相同。這暗示 0.8px dataset 可能存在更大的真實機台振動分量，或 0.08px 的近零步長反而讓擬合更穩定。

### 3.4 Internal step_std 與 GMF 的系統性偏差

| 資料集 | Internal step_std | GMF step_std | 比值 (Internal/GMF) | 偏差方向 |
|--------|------------------|-------------|------|---------|
| 8px | 0.199 | 0.201 | 0.99 | ≈ 一致 |
| 0.8px | 0.205 | 0.191 | 1.07 | Internal 偏高 |
| 0.08px | 0.162 | 0.180 | 0.90 | Internal 偏低 |

兩種方法的比值在 0.90–1.07 之間，整體高度一致，但沒有系統性的偏差方向（一個偏高、一個偏低）。這反映兩種方法各自有不同的噪聲來源：

- **Internal（圓擬合中心）**：對邊界局部缺陷敏感（一個角度的大殘差可以拉動整個圓心），但不依賴外部模板。
- **GMF（全環模板匹配）**：透過全域匹配自然抑制局部缺陷，但受模板精度和搜尋演算法限制。

兩者不是量測同一個物理量的「精確版」和「近似版」——而是用不同的幾何資訊量測幀間位移穩定性。比值接近 1.0 不是巧合，而是因為兩者都受限於相同的邊界品質。

### 3.5 0.8px 主戰場的現狀判讀

Internal step_std = 0.205，GMF step_std = 0.191，baseline = 0.168。**兩者皆未達標**。

GMF（0.191）低於 internal（0.205），差距 7%——這與 GMF 能自動降權局部缺陷的特性一致。但即使 GMF 的更優數字 0.191 仍高於 baseline 0.168（差距 14%）。

這個 14% 差距需要被正確理解：baseline 0.168 來自 Round30 的一個不同 checkpoint（不同的 PSF 訓練策略），而非「同一模型的理論下限」。R26 的差距不一定代表品質不足，也可能是 PSF 策略選擇的 trade-off——R26 在殘差改善（56–73%）和邊緣銳化（36–37%）上顯著優於先前版本，但在亞像素定位精度上還有改善空間。

## 4. 結果二：k=2 橢圓模式穩定性裁決

*對應 Plot 04：`04_k2_amplitude_timeseries.png`*

### 4.1 核心數據

| 資料集 | 邊界 | Input k2 CV% | Output k2 CV% | Output phase 圓形 std |
|--------|------|-------------|--------------|---------------------|
| 8px | 外 | 64.9% | **15.6%** | 7.0° |
| 8px | 內 | 46.4% | **12.1%** | 5.9° |
| 0.8px | 外 | 43.3% | **7.6%** | 3.5° |
| 0.8px | 內 | 36.7% | **8.5%** | 4.2° |
| 0.08px | 外 | 63.9% | **6.3%** | 3.3° |
| 0.08px | 內 | 34.7% | **7.9%** | 4.1° |

### 4.2 裁決：**stable_offset（穩定固定偏置）——全部三個資料集一致**

Output 的 k=2 振幅 CV% 在 6.3–15.6%（全部 < 16%），phase 圓形 std 在 3.3–7.0°（全部 < 10°）。

反觀 input 的 k=2 振幅 CV% 在 35–65%，phase std 在 36–104°——幾乎完全隨機。

### 4.3 閾值設定的量化論證

我們使用 CV% < 15% 作為 `stable_offset` 的判定門檻。這個數字不是任意選擇，以下是論證：

**從 step_std 影響反推**：k=2 模式的橢圓偏差會使圓擬合的中心在長軸方向偏移約 A₂/2（其中 A₂ 是 k=2 振幅）。如果 A₂ 在幀間波動 ΔA₂，則圓心偏移波動 ≈ ΔA₂/2。對 0.8px output 而言，A₂ ≈ 2.33 px，CV = 8.5% → ΔA₂ ≈ 0.198 px → 圓心波動 ≈ 0.099 px。這個波動需要與 step_std 的其他分量進行 RSS（root-sum-square）合成。若 k=2 引入的波動佔 step_std 的 20% 以下（即 < 0.04 px），可認為影響微小。0.099 px 已超過此門檻，但實際上 k=2 的方向（相位角）也是穩定的，所以幀間差分會大幅消除這個偏移。

**CV% < 15% 的含義**：在正態假設下，CV = 15% 意味著 95% 的幀的 k=2 振幅落在均值 ±30% 範圍內。對 A₂ ≈ 2 px 的典型值，波動範圍 ≈ ±0.6 px，幀間差分後殘餘 ≈ ±0.3 px——這確實會是 step_std 的顯著分量。但 0.8px output 的 CV 只有 8.5%，波動範圍 ≈ ±0.4 px，差分後殘餘 ≈ ±0.2 px，與 output step_std 0.205 px 量級相當。

**更嚴格的判定**：如果 CV% > 30%，則幀間差分後的 k=2 殘餘（~0.3–0.5 px）將主導 step_std，這是 `volatile_risk` 的含義。所有 output 都遠低於此。

**8px dataset 的 outer CV = 15.6% 值得注意**——它處於 stable/moderate 的邊界。這可能是因為 8px 影像的大步長（8 px）使 annulus 在 FOV 中移動較遠，不同位置的 PSF 差異更大，導致 k=2 振幅的幀間變異略高。但即使如此，其 phase std 只有 7.0°，方向穩定性仍然良好。

### 4.4 物理解讀

k=2 橢圓模式的穩定性有兩種可能的物理來源，我們需要區分：

**假說 A：annulus 本身的幾何橢圓**。如果 annulus 真的不是正圓而是輕微橢圓，那 k=2 模式就是「真實幾何」的忠實測量。在模糊的 input 中，邊界梯度太淺，圓擬合的殘差由噪聲主導，真實橢圓被淹沒；反卷積後噪聲消除，真實橢圓浮現。

**假說 B：PSF 像散的系統性殘留**。如果 Whole-FOV PSF 的反卷積不完美（因為 10×10 grid 的空間採樣不夠密），像散分量可能在反卷積後殘留，表現為 k=2 偏差。

**區分方法**：如果假說 A 正確，k=2 的振幅和相位應在不同 FOV 位置（不同 dataset）上不同（因為每個 annulus 的橢圓程度不同）。如果假說 B 正確，k=2 的特性應與 FOV 位置相關（PSF grid 的內插誤差在不同位置不同）。

從數據看，三個 dataset 的 output inner k=2 振幅相似（1.89 / 2.33 / 2.31 px），但 8px 偏低而 0.8px/0.08px 接近。8px 的影像尺寸和 annulus 半徑都不同（1520×2180 vs 1500×1500），所以 k=2 振幅差異也可能來自幾何尺度差異。目前無法區分假說 A 和 B，需要**同一 annulus 在不同 PSF 版本下的 k=2 比較**才能判定。

**但無論來源為何，穩定性已經確認了安全性**。不論 k=2 是來自 annulus 還是 PSF，只要它在幀間穩定（CV < 16%、phase std < 7°），在幀間差分後就會被消除，不膨脹 step_std。

**對 GMF 的影響**：固定偏置在幀間差分後消失，不膨脹 step_std。這是安全的。

**8px 與 0.8px/0.08px 的差距**

8px 資料集（1520×2180）的殘差改善（70-73%）顯著優於 0.8px/0.08px（56-60%）。一個合理的解釋：1520×2180 影像中的 annulus 更大（外半徑 ~597 px），邊界的絕對像素數更多，圓擬合有更多有效角度來約束估計；而 1500×1500 影像的 annulus 相對較小，有效角度更少。

## 7. 結果五：高殘差區域持續性

*對應 Plot 05：`05_hotspot_persistence.png`*

### 7.1 方法論：為什麼改用 sequence-global threshold

判定某個角度是否「持續高殘差」需要一個固定的強度門檻跨幀比較。最初版本使用每幀各自的 75th percentile 作為門檻，但這在數學上不可能給出有鑑別力的結果——每幀固定有 ~25% 角度被標為 hot，幀間隨機重疊的機率就有 ~6.25%，使得 mean_persistence 在所有 dataset 上都塌成 ~0.225 的常數。

修正後改為 **sequence-global 90th percentile**：把所有幀的 360×N 個殘差值展平，取整體的 P90 作為統一門檻。這意味著：
- 只有在序列整體尺度上真正偏高的殘差才被計入
- Input（高噪聲）和 output（低噪聲）各自算出不同的 threshold_px，反映兩者殘差分佈的本質差異
- 某一幀可能完全沒有任何角度超標，也可能有很多——不再人為強制每幀 10% hot

選擇 90th 而非 95th 或 75th 是一個 trade-off：75th 太寬鬆（仍有 ~25% 被標記），95th 太嚴格（可能遺漏中等強度的結構缺陷）。90th 在本場景下是合理折衷，但讀者應留意這是超參數，不同門檻會改變 persistent angle 的數量（但不會改變 input vs output 的定性結論）。

### 7.2 核心數據

| 資料集 | 條件 | 邊界 | Threshold (px) | Persistent angles (>50% 幀) | Mean persistence | Max persistence |
|--------|------|------|---------------|---------------------------|-----------------|----------------|
| 8px | Input | 外/內 | 14.34 / 14.26 | 0 / 0 | 0.100 / 0.100 | 0.183 / 0.233 |
| 8px | Output | 外/內 | 4.04 / 4.19 | **24 / 21** | 0.178 / 0.180 | **1.0 / 1.0** |
| 0.8px | Input | 外/內 | 10.80 / 11.07 | 0 / 0 | 0.111 / 0.111 | 0.327 / 0.381 |
| 0.8px | Output | 外/內 | 4.31 / 4.54 | **26 / 26** | 0.224 / 0.224 | **1.0 / 1.0** |
| 0.08px | Input | 外/內 | 10.78 / 11.37 | 0 / 0 | 0.117 / 0.117 | 0.344 / 0.474 |
| 0.08px | Output | 外/內 | 4.36 / 4.56 | **33 / 27** | 0.269 / 0.265 | **1.0 / 1.0** |

### 7.3 Threshold 的物理意義

Input 的門檻（10.8–14.3 px）遠高於 output（4.0–4.6 px），這直接反映 R26 重建對殘差分佈的壓縮效果。Input 殘差由模糊 + 噪聲主導，需要 ~11–14 px 才算「異常高」；output 殘差已被壓縮至 2–3 px 均值水準，4 px 就已經是異常值了。

Output 的 threshold_px 在三個 dataset 間高度一致（4.0–4.6 px），暗示 R26 重建後的殘差分佈有一個穩定的尾部特徵——不隨步長尺度或影像尺寸變化。

### 7.4 持續性分析

**Input：幾乎沒有持續性高殘差角度（mean_persistence ≈ 0.10–0.12）**

Input 的 mean_persistence ≈ 0.10 接近理論下限（P90 門檻下每幀 ~10% 角度被標為 hot，隨機重疊的期望 persistence ≈ 0.10）。這確認了模糊影像中的殘差是噪聲性質，不具空間固定性。Input 的 max_persistence 在 0.18–0.47 之間——即使最「持續」的角度也只在不到一半的幀中出現，且隨 dataset 不同而變化，沒有結構性。

**Output：21–33 個角度在 >50% 幀中持續為高殘差，且 max_persistence = 1.0**

max_persistence = 1.0 意味著某些角度**在每一幀都超過門檻**——這是 100% 的持續性，只可能來自物理固定的結構缺陷（顆粒、划痕、局部厚度異常），不可能是隨機過程。

persistent angle 的數量隨 dataset 增加（8px: 24/21 → 0.8px: 26/26 → 0.08px: 33/27），可能原因是 0.08px dataset 的幀數較少（41 幀 vs 101 幀），使 persistence fraction 的統計解析度較低，更容易有角度越過 50% 門檻。但三個 dataset 的定性結論完全一致。

**Mean persistence 的梯度**

Output 的 mean_persistence 從 8px 的 0.178 上升到 0.08px 的 0.269。這不代表小步長影像「品質更差」，而是因為小步長影像的幀間真實位移極小（0.08 px），每幀的邊界幾何幾乎完全相同，結構缺陷的角度位置也完全重疊——持續性自然更高。8px dataset 的幀間位移達 8 px（約外邊界半徑的 1.3%），足以讓邊界上的局部缺陷在角度座標系中發生微小偏移，稀釋 persistence。

### 7.5 對 step_std 的影響分析

固定位置的結構缺陷在幀間差分後消失（缺陷隨圓心移動，在相對角度座標下不變），因此**不直接膨脹 step_std**。

但這裡有一個更微妙的效應：如果結構缺陷的殘差足夠大，它會系統性地偏移圓擬合的圓心。只要這個偏移在幀間穩定（同一個缺陷在同一個角度），它就是一個固定偏置，幀間差分仍然可以消除。真正危險的是**缺陷強度隨幀變化**的情況——這會產生幀間圓心偏移的波動，直接注入 step_std。

從數據看，output 的 max_persistence = 1.0（缺陷在每幀都出現且強度穩定超標），加上 center_offset 的 fixed_bias 裁決（std/mean < 0.25），可以合理推斷這些結構缺陷的影響確實是穩定的，不會在幀間波動。

但我們無法排除的是：這些固定缺陷為圓擬合的殘差 std 設定了一個「地板」（output residual_std ≈ 2.5–2.9 px 的一部分來自這些角度），而這個地板會限制 step_std 能達到的最低值。如果 GMF 的 robust fitting 能自動降低這些角度的權重，GMF step_std 可能會低於 internal step_std——而數據正好顯示 GMF step_std（0.191/0.180）確實低於 internal step_std（0.205/0.162），至少在 0.8px 尺度上如此。

### 10.2 對外部 GMF 升級的預判

**結論：R26 重建的幾何品質在序列中高度穩定，是可靠的改善。但 0.8px 主戰場的 step_std 尚未突破 Round30 baseline。**

| 尺度 | GMF step_std | GMF baseline | 差距 | 判定 |
|------|-------------|-------------|------|------|
| 8px | 0.201 | 0.205 | -2% | **達標** |
| 0.8px | 0.191 | 0.168 | +14% | **未達標** |
| 0.08px | 0.180 | 0.158 | +14% | **未達標** |

### 10.3 差距來源的量化拆解

0.8px 的 GMF step_std 需要從 0.191 降至 0.168，即減少 0.023 px（12%）。以下嘗試拆解這 0.023 px 的可能來源：

**分量 1：k=2 橢圓模式的幀間殘餘**

output inner k=2 振幅 = 2.33 px，CV = 8.5%，所以幀間振幅波動 σ(A₂) ≈ 0.198 px。幀間差分後，k=2 對圓心偏移的殘餘 ≈ σ(A₂)/2 ≈ 0.099 px。但因為 phase 穩定（circ std = 4.2°），偏移方向幾乎相同，差分可以消除大部分。估計殘餘對 step_std 的貢獻 < 0.02 px。

**分量 2：結構缺陷的固定殘差**

26 個 persistent angles（0.8px output inner）的殘差 > 4.54 px（threshold），但它們在幀間穩定（max_persistence = 1.0）。這些角度偏移圓心的方式是固定的，幀間差分後理論上消除。殘餘取決於缺陷強度的幀間微波動——假設波動 5%，則對圓心波動的貢獻 ≈ 26/360 × 4.5 × 5% ≈ 0.016 px。

**分量 3：圓擬合的有限精度**

360 個角度的等距取樣 + 最小二乘法圓擬合，在 residual_std = 2.9 px 的殘差水準下，圓心定位的理論精度 ≈ residual_std / √(N_points) ≈ 2.9 / √(360) ≈ 0.15 px。這是一個 per-frame 的定位不確定度，幀間差分後兩幀的不確定度以 RSS 合成：√(2) × 0.15 ≈ 0.21 px。**這就是我們觀察到的 internal step_std（0.205 px）的主要來源。**

**分量 4：GMF 相對於圓擬合的優勢**

GMF（0.191）低於 internal（0.205），差距 0.014 px。GMF 的全環模板匹配有效利用了比圓擬合更多的資訊——不只是圓心，還有整個環的亮度分佈。這讓 GMF 對局部缺陷更 robust，等效增加了「有效取樣點數」。

**合成估計**：分量 1+2+3 ≈ √(0.02² + 0.016² + 0.21²) ≈ 0.211 px（RSS），與觀測到的 internal step_std 0.205 px 量級一致。GMF 透過全域匹配的優勢將其壓低至 0.191 px。

**要從 0.191 降至 0.168 px 的路徑**：
- 降低 residual_std（分量 3 的主導因素）：如果 output residual_std 能從 2.9 px 降至 ~2.4 px（再改善 17%），圓擬合精度 ≈ 2.4/√(360) ≈ 0.126 px，GMF 應可達到 ~0.15 px。這需要 PSF 品質的進一步提升。
- 增加有效角度數：如果邊界取樣從 360 增至 720 角度，精度改善 √2 倍。但這是分析管線的改善，不是模型的改善。
- 降低結構缺陷強度：需要更完善的 PSF 或後處理來抑制固定角度的殘差峰值。

### 10.4 R26 的定位：「改善顯著、尚未達標」

R26 不是一個失敗的版本。它實現了：
- **邊界品質的質變**：殘差改善 56–73%，把邊界從「無法定位」提升到「可精確定位」
- **幾何穩定性的確認**：k=2 固定偏置、圓心偏移固定、改善幅度穩定——所有「可能出問題」的指標都確認安全
- **8px 尺度達標**：大步長場景已通過

未達標的 0.8px/0.08px 尺度，瓶頸已從「邊界模糊」轉移到「殘差噪聲地板」。這是一個更精細的問題，需要更精確的 PSF 估計或更多的訓練數據來解決——但方向是明確的。

## 11. 侷限性與方法論自我批判

### 11.1 測量方法的侷限

| 侷限 | 影響 | 需要什麼 |
|------|------|---------|
| Internal step_std ≠ GMF step_std | 代理指標與 GMF 有 ~7–10% 偏差，方向不一致 | 外部 GMF 結果仍是唯一的最終 truth |
| 只用 odd-frame | 跳過偶數幀，有效幀間步長 = 2× 名義步長 | 用 all-frame 重建再驗證 |
| 圓擬合只用圓心 Y 座標 | GMF 用全環形狀匹配，更 robust | 無法在不使用 GMF 的情況下複製其全域匹配特性 |
| 三個資料集皆為同一 FOV 位置 | 不同 FOV 位置的 PSF 和 annulus 幾何可能不同 | 多 FOV 位置、多方向資料 |
| 只分析 Y 方向序列 | X 方向的步進穩定性未驗證 | X 方向序列資料 |

### 11.2 統計方法的超參數敏感性

本報告中有多個需要人為設定的超參數，它們對結論的影響程度不一：

**Hotspot persistence threshold（P90）**：從 P75 改為 P90 後，persistent angle 數量大幅變化（舊版 38–64 → 新版 21–33）。但 input vs output 的定性結論不受門檻選擇影響——input 在任何合理門檻下都接近零持續性，output 都有顯著持續性。若改用 P95，persistent angle 數量會進一步減少，但 max_persistence 仍為 1.0（最頑固的角度在任何門檻下都存在）。此超參數影響的是「有多少角度被認為是結構缺陷」，不影響「是否存在結構缺陷」。

**k=2 穩定性判定門檻（CV < 15%）**：8px outer 的 CV = 15.6% 恰好落在邊界上。如果門檻設為 20%，三個 dataset 全部判定為 stable；如果設為 12%，8px outer 會被判為 moderate。但 phase std 的判定（< 10°）在所有情況下都穩定通過，且 step_std 的實際數字不受判定門檻影響。

**Persistence cutoff（50%）**：用「>50% 幀中出現」定義持續性是一個保守但合理的選擇。降低到 30% 會增加 persistent angle 數量，但也會納入更多噪聲性角度。50% 確保了「多數幀都出現」的嚴格語義。

### 11.3 分析管線的固有限制

**360 角度的離散化**：我們在 0°–359°（1° 間隔）取樣邊緣點。對外半徑 ~450 px 的 annulus，1° 對應 ~7.9 px 的弧長，遠大於像素尺度——取樣密度足夠。但對於跨角度的缺陷結構（例如 3° 寬的划痕），我們只有 3 個取樣點，空間解析度有限。

**圓擬合假設圓形**：我們用圓形模型擬合可能是橢圓的邊界。k=2 諧波分析量化了這個假設偏差的大小，但圓擬合的中心和半徑本身已受橢圓偏差影響。更嚴格的方法是直接擬合橢圓，但這會增加自由度和擬合不穩定性。

**ref_hint 的序列依賴性**：每幀使用前一幀的 annulus 參數作為偵測起點。如果某一幀偵測異常（例如因為嚴重噪聲），異常可能透過 ref_hint 傳播到後續幀。我們的 fallback 機制（若 refine 失敗則回退到全域偵測）提供了一層保護，但未在本報告中量化 fallback 的觸發頻率。

### 11.4 不可回答的問題

以下問題超出本分析管線的能力範圍：

1. **GMF step_std 的精確預測**：internal step_std 只是一個 proxy，無法精確預測 GMF 的結果
2. **PSF 品質改善的定量效益預測**：我們知道「降低 residual_std 可以改善 step_std」，但無法預測具體需要多少改善才能達標
3. **k=2 來源的判定**：需要同一 annulus 在不同 PSF 版本下的對比實驗
4. **最終 step_std 噪聲地板**：需要完美 PSF（如果存在的話）下的控制實驗
