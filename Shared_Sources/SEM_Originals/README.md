# 原SEM尺寸工作表與共用來源

[via_pilar.xlsx](via_pilar.xlsx)是原實驗使用的工作表，40,628 bytes；原內容身分為`e650ff144740f46b2644cd75df8ff020a099bf1886168d1fda3fb7290bf0e62c`。它與原論文SEM資料位置中的相同原件逐位元組一致，本頁只提供共用只讀位置，不改寫表格。

完整18張P/V SEM原圖、工作表與舊配對程式仍在[既有共用來源附件](https://github.com/rio10255254/GMM_2_Final/releases/tag/research-shared-sources-20261016)的`research-sem-paired-originals-028.zip`；不為每輪複製一份照片。

本表保存36柱／36孔的原尺寸參照。R61訓練曾取用其中逐顆及全體平均尺寸，[來源審查](../../Experiments/R135_UnifiedModelComparison/reports/R135_R61_TRAINING_AUDIT.md)與[完整證據表](../../Experiments/R135_UnifiedModelComparison/results/r61_training_audit)必須與SEM成績一起讀。這不是未知樣本獨立驗證，也不能把操作上的SEM取邊值直接當成已認證的材料邊界真值。

R69指定的12張歷史配對光學裁切圖在同一發布版的`research-camera-multiscale-001.zip`，不是上面的SEM附件；它們也不是全幅相機原檔。[R69逐檔對照與原結果](../../docs/reproducibility/round_source_reviews/R69_20261022.md)說明原映射、模型與換位置時的限制。
