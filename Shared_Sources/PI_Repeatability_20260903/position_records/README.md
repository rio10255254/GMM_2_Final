# 30趟原始平台位置紀錄

此處是2026-09-03原始`positions.csv`的只讀閱讀副本：30個資料夾，每份31列，包含起點與30步，共930列。每個檔案的完整內容都符合原拍攝清單；沒有調整位置、時間、影格或曝光，也不是從模型輸出反推。

CSV原欄位是`image`、`x`、`y`、`frame`、`exposure_us`、`scan_started_at`及`recorded_at`。位置單位沿用原實驗µm，平台讀值是原實驗參考，不因此變成另一份獨立物理校正。

[各份原紀錄、原ZIP位置與內容身分](ORIGINAL_RECORD_MAP.json)對回正式`raw/<scan>/positions.csv`。這裡沒有照片，不能把它當完整影像資料根目錄。需要930張相機BMP時，按[原始拍攝資料說明](../README.md)從同一份原ZIP恢復到新的空目錄；原恢復工具與既有檔案保護保持。

這些副本只為直接閱讀與下載，不能單獨改寫。所有研究輪次仍共用同一份採集來源，不把這930列當930次獨立重拍。
