# GeoEdge COMBO ONNX Company Package

This folder contains the COMBO production baseline export for company-side testing.

## Contents

- `model/geoedge_combo_body.onnx`: ONNX model.
- `assets/preprocess_config.json`: preprocessing constants.
- `assets/psf_mean.npy`: PSF data used by the preprocessing step.
- `run_combo_onnx.py`: image-to-image inference runner.
- `samples/sample_input.bmp`: sample input.
- `samples/sample_output_onnx.bmp`: sample output generated by this package.
- `verification_report.json`: local verification record.

## Install

```bash
python -m pip install -r requirements.txt
```

## Run

Single image:

```bash
python run_combo_onnx.py --input samples/sample_input.bmp --output outputs
```

Image directory:

```bash
python run_combo_onnx.py --input path/to/images --output outputs
```

The runner accepts grayscale or color images. Color inputs are converted to grayscale. Output images keep the input image shape and integer dtype.

## Model Identity

- Production baseline: COMBO / r38v2_8px_gate_p95
- Source checkpoint: `training_progress_GeoEdgeAlignSR_v1_v5_NoCoord_SimpleTest_20260408_003525/weights/best_tradeoff.pth.tar`
- Best epoch: 21

The ONNX file contains the main neural network body. The fixed PSF preprocessing step is kept outside ONNX because the original model uses FFT operations that this local PyTorch ONNX exporter cannot place inside a single ONNX graph.
