# R137副本 V42自動八候選PSF模組

接收100顆PSF，沿用V42的WeakPSFDeconvBlock：程式自動取8顆候選，內部網路根據當前特徵決定8顆的混合比例，不需手動指定。

100顆不是由網路直接做100選8。本包沒有視野位置表，因此沿用V42無位置表時的自動等間距取樣規則。每次運算會分別處理8顆，再依網路權重混合，最後做小幅殘差修正。

將真實資料放入calibration/psf_100.npz，陣列all_kernels形狀為(100,101,101)。載入：

```python
from model_api import load_model
model, info = load_model(device='cuda')
```

保留R137已訓練的重建主幹，替換舊平均PSF及其轉換層。新模組接在R137的64通道特徵位置；它和V42的模組運算相同，不代表整個模型換成V42。初始修正強度0.02；V42的beta_scale_max設成1.0以保留此初始有效強度，其餘採此模組原預設設定。

新增的混合比例網路尚未訓練，目前初始比例為各1/8，不能宣稱已經學會選擇PSF。未重訓、未用真實100顆資料驗證。原R137和先前的100顆平均版均保留不動。

此版使用完整影像；沒有沿用會改變V42全圖權重與頻域運算的逐塊推論。
