# 2026-09-24：用同顆 SEM 真實外框檢查 PSF

## 直接回答

先前的 BADS 擬合確實完成了「理想柱形 → PSF 卷積 → 對照照片」：25/25 張正常結束，每張做了 515–709 次目標比較。**但當時的理想柱形是按 SEM 直徑畫的圓盤，不是 SEM 照片裡的不規則真實外框。** 因此「擬合程序完整」與「真實 PSF 已精準確認」是兩件事。

這次另用原始 `P-01`、`P-02`、`P-05`、`P-06` SEM 照片已提取的逐顆外框，固定已有 PSF，不再用留出的柱子改 PSF，實際做了你要求的前向比較。結果是：新 BADS PSF 比七月舊 PSF 更接近這次照片，但一個只調模糊寬度的簡單高斯模型在這批留出柱子上還略好。**所以目前能支持「主要模糊程度有抓到」，不能支持「唯一且精準的物理 PSF 形狀已被證明」。**

## 真正使用的 SEM 外框

來源是既有 R69 驗證留下的 `D:\GMM_2_Final\Experiments\R69_ACMContourSEMValidation\results\masks\acm_primary_masks.mat`。它的 `truth_masks` 是從原始 P 系列 TIFF 逐顆取出的 36 個完整輪廓，不是 Excel 直徑推導的圓。所用九顆沿用已核對的現行 20× 排列：

```text
36 35 34
30 29 28
24 23 22
```

SEM 的原始亮度屬於電子顯微鏡訊號，不能直接當作光學相機的亮度。因此本次取 SEM 的**外形**，按原有柱距換算到 20× 的 0.1725 µm/像素，再給它光學柱子的明暗，才與 PSF 卷積。SEM 外框沒有按個別照片放大、縮小或旋轉；方向使用之前固定的上下翻轉，並保留未翻轉版本作敏感度檢查。

「同編號」沿用現行 20× 影像到新照片的直接對位，以及歷史 P-SEM 編號紀錄；新照片本身沒有獨立的 SEM 拍攝方向標記。因此這是按專案現有對應鏈做的逐顆驗證，不把它冒稱為新取得的跨年代身分證明。

## 公平的留出檢查

選視野三個代表位置：第 1、13、25 張。每張用六顆柱子擬合 PSF，保留 **SEM 36、29、22** 三顆完全不參與 PSF 擬合。每種預測只用六顆訓練柱估一次整張亮度，再將同一亮度套到三顆留出柱；沒有為留出柱單獨調位置、尺寸或亮度。下列數字是三張照片的留出柱平均平方差，越低越像實拍：

| 預測方法 | 留出柱平均差 | 與實拍相似程度 |
|---|---:|---:|
| SEM 外框，未加模糊 | 0.02591 | 0.9234 |
| SEM 外框＋七月舊 PSF | 0.00472 | 0.9517 |
| SEM 外框＋本次 BADS PSF | **0.00238** | **0.9761** |
| SEM 外框直接作 BADS 擬合目標，再測留出柱 | 0.00257 | 0.9741 |
| SEM 外框＋只用六顆訓練柱調寬度的高斯模糊 | **0.00220** | **0.9832** |

本次 BADS 比舊 PSF 更接近的比較是 9/9 顆；高斯又比本次 BADS 更接近的比較也是 9/9 顆。這九個數字來自同一實物的三顆柱子在三個視野位置的重看，**不是九個獨立樣品**。

使用本次 PSF 時，真實 SEM 外框的留出誤差 0.00238，換回「SEM 直徑圓盤」則是 0.00235；兩者只差約 1.3%。SEM 外框方向上下翻轉或不翻轉的結果也只差約 1%。以這次 20× 解析度，照片不足以有效分辨那些細小的不圓整細節。因此不能用「照片看起來相似」來唯一證明 BADS 的光學 PSF 比簡單模糊更真實。

## 判定與剩餘限制

原先的 25 個 PSF 是有完整執行的**實測影像擬合候選**，且比七月 PSF 更能重現這組照片。但這項真正使用 SEM 外框的留出檢查顯示：簡單高斯也能做到略好，SEM 細微外形又無法由 20× 影像分辨。加上不少 BADS 參數仍貼近人為設定界限，**現在不能宣稱已精確識別真實光學 PSF，也不能因此宣稱後續量測準確度已改善**。需要另一種能清楚區分 PSF 形狀的獨立校準影像或更高解析度的同顆對照，才能提升這個結論。

原始 SEM TIFF、25 張照片、舊 PSF 和已交付的 PSF 檔沒有被這次驗證覆寫。這次使用的二值 SEM 外框目標 `gt_sem_contour_20x.bmp` 及浮點版 `gt_sem_contour_20x_float.npz` 保存在本資料夾，可由 `validate_sem_shape.py` 重做；`run_sem_contour_cv.m` 僅產生獨立的比較輸出。
