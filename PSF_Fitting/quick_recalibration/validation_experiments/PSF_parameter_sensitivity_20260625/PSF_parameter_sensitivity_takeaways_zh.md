# PSF參數敏感度分析：簡報用重點

## 一句話結論

這次不是只用「有沒有碰到上下界」來決定哪些參數能看，而是把15個參數逐一擾動，直接量測它們對最後PSF形狀與強度的影響；因此可以把「參數本身有沒有影響力」和「目前擬合結果是否可信」分開說。

## 主要發現

1. 對PSF形狀影響最大的是 x7/Z8 coma Y 與 x8/Z9 coma X，約為0.14%。
   但它們在目前Round1擬合結果中屬於 dead，也就是實際擬合時幾乎沒有被資料有效推動。這代表它們有物理影響力，但目前不能拿來當穩定可估的主要證據。

2. 在目前可信的參數中，影響最大的是 x12/Z13 spherical 與 x4/Z5 defocus，約為0.03%。
   這兩個最適合拿來說明「為什麼目前會重點看這些參數」，因為它們同時滿足兩件事：對PSF形狀有可見影響，而且目前擬合狀態比較可信。

3. x15/AC amplitude 對完整影像強度影響最大，約為0.33%。
   但它主要改變亮度尺度，不是改變PSF形狀，所以簡報時要和形狀參數分開講。

4. x1/Z2 tilt 與 x2/Z3 tilt 在目前流程中沒有影響。
   原因是目前PSF產生時會把tilt固定為0，所以它們不是本輪敏感度討論的重點。

5. 9個視野位置的排序趨勢一致。
   這表示結果不是只在單一位置成立，而是在目前Round1的9個位置上都呈現類似趨勢。

## 建議簡報說法

「我們沒有只憑上下界來決定哪些參數要看。這次把15個參數全部逐一擾動，直接看PSF最後會變多少。結果顯示，有些參數本身確實會改變PSF，但在目前擬合裡幾乎沒有被穩定估出來；所以我們把『有影響力』和『目前可不可信』分開。最後真正適合拿來當主要討論對象的，是同時具備PSF影響力與擬合可信度的參數，例如defocus和spherical。」
