# R42 — 顯微邊界忠實度

## 假說

模型真正需要學會的不是只把環形重建好，而是碰到不同顯微結構時，都能忠實重建邊界位置、細線中心、格線相位與小缺陷位置。環形仍保留為舊能力守門，但它只是代理測試，不是 R42 的主要訓練目標。

## 設計

R42 建立新的合成顯微邊界資料包。每張資料除了來源圖與答案圖，也保留邊界遮罩、中心線遮罩與距離圖，讓評估和訓練都能直接針對「邊界有沒有偏掉」。

R42 第一版不改模型本體，也不加入真實影像。它是研究優先路線：先確認通用顯微邊界能力能不能被推起來；若同時守住 COMBO 的外部環形能力，才進入升級候選討論。

## 候選

| 標籤 | 起點 | 說明 |
|---|---|---|
| `r42_boundary_from_combo` | COMBO | 保守起點，檢查舊能力附近能否學到邊界忠實度 |
| `r42_boundary_from_r41` | R41 直接端點 | 顯微能力較強起點，檢查能否補上邊界位置精度 |

後續外部 GMF 補測使用三個實際權重：

| 外部候選 | 角色 |
|---|---|
| `r42_r41_best` | R42 強候選中，本地環形退步相對最小 |
| `r42_combo_latest` | 邊界畫面與分數很強，用來看多拿顯微能力的外部代價 |
| `r42_r41_latest` | 顯微邊界能力上限參考 |

## 評估

- R42 邊界測試集：細線、格線、交叉線、曲線、大區塊、缺陷、混合場景。
- 邊界指標：邊界位置誤差、邊界 F-score、中心線偏移、格線 pitch / phase 誤差、缺陷元件召回。
- 舊能力守門：本地三尺度環形測試與外部三尺度 GMF。

## 結果

R42 第一輪正式訓練、兩個深度補測，以及後續外部 GMF 補測都已完成。結論是：**研究成功但不可升級，也不建議作量測替代。**

- 顯微邊界能力成功：未看過邊界測試上，最佳 R42 版本達到 PSNR `34.18`、boundary F1 `0.87`，明顯高於 COMBO 的 PSNR `20.55`、boundary F1 `0.63`。
- 舊環形守門失敗：四個 R42 權重在本地三尺度環形測試都比 COMBO 退步；最佳本地環形結果 `r42_r41_best` 仍退步約 23% 到 41%。
- 低比例權重平均失敗：0.01 到 0.05 的 COMBO ↔ R42 混合沒有找到邊界能力與環形守門同時成立的點。
- 守門 KD 診斷失敗：短訓練後顯微邊界仍強，但環形守門更差，表示靜態單張影像牽引不足以修正舊代理退步。
- 外部 GMF 補測失敗：最佳外部候選 `r42_r41_best` 仍在 8px +24.63%、0.8px +94.33%、0.08px +98.87%。

## 判讀

R42 證明模型可以被資料與幾何目標推向更好的顯微邊界重建；肉眼代表圖也顯示格線、曲線、缺陷與混合場景確實更接近答案圖。

但 R42 也證明另一件事：單張圖更清楚不代表連續量測更穩定。當顯微邊界能力被大幅推高後，邊界在連續位移下會漂，尤其小尺度 0.8px 與 0.08px 外部 GMF 退步太大。

## 下一步方向

下一輪不應只繼續加 COMBO 混合或更強靜態老師。R42 之後最合理的方向是建立「通用邊界位置一致性」：讓線條、格線、曲線、缺陷與大區塊在已知位移或相位變化下保持正確位置。環形仍是舊守門，但不再是訓練目標本身。
