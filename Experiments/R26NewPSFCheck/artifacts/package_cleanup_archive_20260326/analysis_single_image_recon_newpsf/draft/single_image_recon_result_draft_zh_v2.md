# 單張影像重建分析結果草稿 v2

## 主結果分析正文
以 RAW 與新 PSF 重訓後的 R26 單張比較結果來看，最主要的正向證據仍來自邊界剖面量化。主邊界的 `edge_width_main_px` 由 `43.56` px 下降至 `36.26` px，弱邊界的 `edge_width_weak_px` 由 `51.26` px 下降至 `49.08` px；同時，主邊界 `max_slope_main` 由 `2.63` 上升至 `4.39`，弱邊界 `max_slope_weak` 由 `1.90` 上升至 `2.08`。這表示重建後的灰階轉換仍有集中化趨勢，但改善幅度主要集中在主邊界，弱邊界僅呈現有限改善，因此不宜寫成整體邊界都明顯強化。
局部對比指標則需更保守解讀。`CNR_main` 由 `6.98` 提升至 `9.19`，但 `CNR_weak` 由 `9.03` 下降至 `7.79`，顯示對比改善並不一致。背景指標方面，`background_std` 由 `2.9010` 降至 `1.0903`，`background_grad_p95` 由 `24.2074` 降至 `3.1623`，表示背景波動與背景高梯度雜訊顯著下降。因此，較合理的寫法應是：主邊界的局部對比改善來自邊界集中化與背景抑噪的共同作用，但弱邊界對比並未同步提升，故不能寫成全面性的對比增強。

## 頻域圖的保守解讀正文
頻域分析在本次結果中只能作為輔助資訊，且需要明確保守措辭。`HF_ratio` 在本流程中的定義為固定頻帶能量比 `E(r=0.35–0.60) / E(r=0.05–0.60)`，其數值由 `0.6185` 降至 `0.0164`，較接近固定高頻帶或噪聲帶能量佔比，不宜直接解讀成有效細節量。另一方面，`checkerboard_ratio` 的定義為 `|fx|, |fy| >= 0.80` 的 corner energy 比值，其數值由 `0.1447` 升至 `0.2148`。因此，本次頻域結果不能寫成「高頻提升」或「細節全面增強」；較合適的寫法是：固定高頻帶能量明顯受抑，但棋盤格傾向指標上升，故頻域結果只能作為需保守看待的輔助證據，不能單獨支撐成像品質全面提升的結論。

## 幾何 proxy 的保守解讀正文
幾何 proxy 層面呈現的是混合訊號，其中較穩健的主指標仍應為 `ring_thickness_std_px`。其數值由 `5.5552` 下降至 `1.5523`，表示在固定 RAW 幾何參考下，R26 所對應的環狀厚度分布更一致，這是一個正向訊號。相較之下，`edge_continuity_ratio` 由 `0.4861` 降至 `0.2667`，在目前 threshold、edge rule 與 valid angle 判定下反而變差，因此不能再把此指標寫成正向證據。較合理的幾何層寫法應是：厚度一致性 proxy 顯示結構規整度可能提升，但連續性 proxy 未同步改善，因此幾何價值只能保守描述為「部分 proxy 顯示較有利」，而不能直接延伸成後續辨識或量測一定提升。

## 最終結論建議寫法
綜合本單張分析結果，新 PSF 重訓後的 R26 相較於 RAW，仍在主邊界剖面上呈現較集中的灰階轉換與較陡的邊界變化，這是本次結果最主要的正向訊號。局部對比與背景指標顯示，主邊界的改善與背景抑噪同步出現，但弱邊界對比並未同步提升，因此不宜寫成全面性的邊界與對比增強。頻域結果顯示固定高頻帶能量受抑，但 checkerboard 傾向指標上升，故只能作為需保守解讀的輔助資訊。幾何 proxy 方面，`ring_thickness_std_px` 顯示厚度一致性改善，但 `edge_continuity_ratio` 未同步改善，因此只能寫成部分 proxy 顯示較有利，而不能直接宣稱真實解析度提升或量測精度已獲直接證明。
