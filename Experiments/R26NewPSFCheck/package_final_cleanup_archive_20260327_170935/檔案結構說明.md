# GeoEdge R26 封包結構說明

這份文件說明封包裡每個資料夾和檔案的用途，讓你知道東西在哪裡、能做什麼。

---

## 整體目錄結構

```text
GeoEdge_R26_使用包/
│
├── [入口腳本] ← 你平常只需要動這幾個
│   ├── START_HERE.bat
│   ├── FIRST_RUN_SETUP.bat
│   ├── RUN_DEMO_INFERENCE.bat
│   ├── RUN_CUSTOM_INFERENCE.bat
│   ├── RUN_QUICK_TRAIN.bat
│   ├── RUN_FULL_TRAIN.bat
│   └── INSTALL_GPU_PATCH.bat
│
├── [文件]
│   ├── 使用說明.md          ← 怎麼用，從哪裡開始
│   └── 檔案結構說明.md      ← 本文件
│
├── 內部檔案/               ← 封包核心資產，一般不需要手動修改
├── 參考文件/               ← 技術參考文件
├── 容器進階/               ← Docker 備用入口（一般不需要）
└── 輸出結果/               ← 所有執行結果都輸出到這裡
```

---

## 根目錄入口腳本

| 檔案 | 用途 |
|---|---|
| `START_HERE.bat` | 主入口。偵測環境後顯示選單，第一次使用從這裡開始 |
| `FIRST_RUN_SETUP.bat` | 首次環境設定，通常由 `START_HERE.bat` 自動呼叫 |
| `RUN_DEMO_INFERENCE.bat` | 對封包內示範影像做推論 |
| `RUN_CUSTOM_INFERENCE.bat` | 對你自己指定的外部影像做推論 |
| `RUN_QUICK_TRAIN.bat` | 快速 smoke test，只確認環境能動，不代表正式訓練效果 |
| `RUN_FULL_TRAIN.bat` | 基於歷史 R26 baseline 的完整重新訓練 |
| `INSTALL_GPU_PATCH.bat` | 安裝 GPU 加速套件（需要 GPU patch 包放在旁邊） |

---

## 內部檔案/

封包的核心資產全部在這裡。你平常不需要手動進來修改，各入口腳本會自動讀取所需的東西。

### 內部檔案/weights/（模型權重）

| 檔案 | 用途 |
|---|---|
| `r26_sm035_best_tradeoff.pth.tar` | **目前標準 winner 權重**，推論直接使用這個 checkpoint |
| `r25_sw010_seed_best_tradeoff.pth.tar` | **正式 seed checkpoint**，完整重新訓練從這個起點開始跑 |

### 內部檔案/PSF_Fitting/（PSF 參數）

| 路徑 | 用途 |
|---|---|
| `Crop_circle_FreqFiltered/Fits/PSF_fitted_2D_FOVstack.mat` | **目前標準 PSF**，訓練與推論都使用這個光學點擴散函數參數 |

### 內部檔案/Demo_Input/（示範影像）

| 檔案 | 用途 |
|---|---|
| `VisionTop_20251029182653732.bmp` | 執行 `RUN_DEMO_INFERENCE.bat` 時使用的示範輸入影像 |

### 內部檔案/Model/（核心 Python 腳本）

| 檔案 | 用途 |
|---|---|
| `GeoEdgeAlignSR_v1_Train_v5_NoCoord_return_v2_SimpleTest.py` | 訓練腳本 |
| `GeoEdgeAlignSR_v1_Infer_v5_NoCoord_return_v2_SimpleTest.py` | 推論腳本 |
| `GeoEdgeAlignSR_v1_ModelA_v5_NoCoord.py` | 模型架構定義 |
| `GeoEdgeAlignSR_v1_Utils.py` | 共用工具函數 |
| `GeoEdge_R26_FormalTrainAdapter.py` | 正式訓練 adapter，供 wrapper 呼叫 |

> **注意：** 這些腳本直接對應主線程式碼，不直接管理正式 R26 的 recipe 設定。不要手動修改腳本的預設參數值，正式參數由 wrapper 透過 `formal_r26_recipe.json` 注入。

### 內部檔案/Training_Data/（訓練資料）

訓練資料分兩層，用途不同：

**一般層**（供 demo / smoke test 使用）

```text
Training_Data/
├── tra_src_ring/   ← 訓練來源影像
└── tra_lbl_ring/   ← 訓練標籤影像
```

**baseline 訓練層**（供 `RUN_FULL_TRAIN.bat` 使用）

```text
Training_Data/
├── generated/              ← 原始合成資料
└── generated_convolved/    ← 經 PSF 卷積後的資料
```

這一層只保留 `r26_sm035` baseline 實際依賴的 10 個 stage 子集：

| Stage | 描述 |
|---|---|
| `stage_08_annulus_focus` | 環形對焦 |
| `stage_09_annulus_non_overlap` | 環形無重疊 |
| `stage_10_annulus_overlap` | 環形重疊 |
| `stage_14_annulus_edge_defect_focus` | 環形邊緣缺陷對焦 |
| `stage_15_annulus_sparse_clean` | 環形稀疏乾淨 |
| `stage_16_annulus_sparse_defect_clean` | 環形稀疏缺陷乾淨 |
| `stage_23_annulus_gmf_sequence_mid_clean` | GMF 序列中段乾淨 |
| `stage_24_annulus_gmf_sequence_mid_defect` | GMF 序列中段缺陷 |
| `stage_27_annulus_gmf_sequence_midwide_clean` | GMF 序列中寬段乾淨 |
| `stage_28_annulus_gmf_sequence_midwide_defect` | GMF 序列中寬段缺陷 |

### 內部檔案/wrapper 與設定檔

| 檔案 | 用途 |
|---|---|
| `GeoEdge_R26_FormalTrain.ps1` | 完整重新訓練 wrapper，讀取 baseline recipe 並套用正式參數後呼叫訓練腳本 |
| `GeoEdge_R26_FormalInfer.ps1` | 正式推論 wrapper，套用正式參數後呼叫推論腳本 |
| `GeoEdge_AutoLauncher.ps1` | 自動環境偵測與分派，所有 `.bat` 都透過這裡執行 |
| `GeoEdge_NativeLauncher.ps1` | Host Python 模式執行器 |
| `GeoEdge_Launcher.ps1` | 通用執行器 |
| `formal_r26_recipe.json` | **R26 baseline recipe**，記錄完整重新訓練所需的核心超參數、資產路徑與 stage 子集定義 |
| `LAUNCHER_CONFIG.json` | 自動 launcher 設定 |
| `NATIVE_LAUNCHER_CONFIG.json` | Native 模式設定 |
| `requirements.txt` | Python 套件需求清單 |
| `Dockerfile` | Docker 容器定義 |
| `docker-compose.yml` | Docker 服務編排設定 |

## 輸出結果/

所有執行結果都輸出到這裡。`推論結果` 和 `訓練結果` 預設為空，執行後才會產生內容。

```text
輸出結果/
├── 推論結果/        ← RUN_DEMO_INFERENCE 和 RUN_CUSTOM_INFERENCE 的輸出
├── 訓練結果/        ← RUN_FULL_TRAIN 的輸出
│   └── _smoketest/ ← RUN_QUICK_TRAIN 的輸出（和正式訓練分開）
└── 驗證分析/        ← 已完成的外部驗證成果（封包內附帶）
    ├── R26_validation_complete/     ← 目前主要驗證成果
    │   ├── R26_GMF品質分析報告.md   ← 主要驗證報告
    │   ├── figures/                 ← 分析圖表
    │   ├── data/                    ← 原始數據與指標 JSON
    │   └── scripts/                 ← 產生分析的腳本
    └── archive/                     ← 舊版驗證成果（保留備查）
```

### 驗證分析的現有成果

封包內已附帶兩個完整的外部驗證成果，可直接引用：

| 成果 | 位置 | 適合用途 |
|---|---|---|
| GMF 品質分析（目前主要） | `驗證分析\R26_validation_complete\R26_GMF品質分析報告.md` | 幾何一致性、方位均勻性等深度分析 |
| 批次外部驗證（封存） | `驗證分析\archive\R26_external_batch_bundle\R26_批次外部驗證分析報告.md` | 10 張外部影像的彙總表格與保守結論 |

詳細的引用建議與快速資訊，請看：`參考文件\R26_VALIDATION_ANALYSIS_BRIEF.md`

---

## 這份封包不包含什麼

- 完整的 `round26` candidate sweep / decision pipeline
- 全量歷史 `generated*` 訓練資料（只保留 `r26_sm035` 依賴的 10 個 stage）
- 其他 round26 候選模型的權重

封包只保留 **current-standard 正式資產**，承諾且只承諾 `r26_sm035` winner 的使用，以及基於歷史 R26 baseline 的完整重新訓練。
