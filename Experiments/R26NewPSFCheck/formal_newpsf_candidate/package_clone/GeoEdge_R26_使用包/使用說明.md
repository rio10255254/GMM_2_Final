# GeoEdge R26 使用說明

這份封包的正式定位是：

- **正式使用封包**：直接用正式 `r26_sm035` 權重做推論
- **正式重現封包**：可在封包內重跑正式 `R26 / r26_sm035` 的歷史訓練配方

它不是 generic training sandbox。  
封包內的完整訓練入口只服務 **正式 R26 重現**，不是任意 recipe 的自由實驗。

## 1. 最常用的入口

- `START_HERE.bat`
  - 主入口；先做環境判斷，再進選單
- `RUN_DEMO_INFERENCE.bat`
  - 使用正式 `r26_sm035` 權重對封包內示範影像推論
- `RUN_CUSTOM_INFERENCE.bat`
  - 使用正式 `r26_sm035` 權重對外部資料做推論
- `RUN_QUICK_TRAIN.bat`
  - 快速 smoke test，只做環境與流程檢查，不代表正式歷史重現
- `RUN_FULL_TRAIN.bat`
  - 正式 `R26 / r26_sm035` 歷史重現訓練

## 2. 這份封包固定使用什麼正式基準

- 正式 checkpoint：
  - `內部檔案\weights\r26_sm035_best_tradeoff.pth.tar`
- 正式 PSF：
  - `內部檔案\PSF_Fitting\Crop_circle_FreqFiltered\Fits\PSF_fitted_2D_FOVstack.mat`
- 正式 seed checkpoint：
  - `內部檔案\weights\r25_sw010_seed_best_tradeoff.pth.tar`
- 正式 recipe：
  - `內部檔案\formal_r26_recipe.json`

如果你要查 provenance、hash 與 stage 子集，請看：

- `參考文件\R26_FORMAL_REPRO_MANIFEST.md`

## 3. 推論怎麼用

### 示範影像推論

直接執行：

- `RUN_DEMO_INFERENCE.bat`

這會固定使用正式 `r26_sm035` 權重與 checkpoint 內封存的 PSF buffer 做推論。

### 外部資料推論

直接執行：

- `RUN_CUSTOM_INFERENCE.bat`

這同樣固定使用正式 `r26_sm035` 權重。  
如果你是做外部驗證，請走這個入口，不要直接改 model script 的預設值。

## 4. 訓練怎麼分

### 快速訓練 smoke test

- 入口：`RUN_QUICK_TRAIN.bat`
- 目的：檢查 package 環境、資料路徑與訓練腳本能否正常啟動
- 輸出：`輸出結果\訓練結果\_smoketest\`

這條線不是正式歷史重現，也不應被拿來和正式 `R26` 效果直接對照。

### 正式 R26 歷史重現訓練

- 入口：`RUN_FULL_TRAIN.bat`
- 目的：在 package 內重現正式 `R26 / r26_sm035` 訓練配方
- 配方來源：`內部檔案\formal_r26_recipe.json`

這條線會固定套用：

- 正式 `r26_sm035` winner 配方
- 正式舊 PSF
- 正式 `r25_sw010` seed checkpoint
- 正式 stage subset dataset
- 固定 seed 與 deterministic 設定

這不是 generic full train；它是 **formal reproduction**。

## 5. 訓練資料為什麼有兩層

`內部檔案\Training_Data\` 內有兩種用途的資料：

- `tra_src_ring / tra_lbl_ring`
  - 給一般 demo / smoke / quick train 使用
- `generated_convolved / generated`
  - 給正式 `R26` 重現訓練使用

一般使用者不用碰 stage dataset。  
只有 `RUN_FULL_TRAIN.bat` 會自動吃 formal stage layout。

## 6. 目前執行結果放哪裡

- 推論結果：
  - `輸出結果\推論結果\`
- 訓練結果：
  - `輸出結果\訓練結果\`
- quick train smoke：
  - `輸出結果\訓練結果\_smoketest\`
- 驗證分析：
  - `輸出結果\驗證分析\`

## 7. 使用上的重要原則

- 不要把 `RUN_QUICK_TRAIN.bat` 的結果當成正式 `R26` 歷史效果
- 不要自行替換 package 內正式 PSF，除非你明確是在做實驗
- 不要把這個 package 當成 candidate sweep sandbox；它只承諾重現正式 `r26_sm035`

## 8. 建議檢查順序

1. 執行 `START_HERE.bat`
2. 先跑 `RUN_DEMO_INFERENCE.bat`
3. 需要外部資料時再跑 `RUN_CUSTOM_INFERENCE.bat`
4. 需要 smoke check 時才跑 `RUN_QUICK_TRAIN.bat`
5. 真的要重現正式歷史訓練時，再跑 `RUN_FULL_TRAIN.bat`
