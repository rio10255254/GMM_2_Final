# R123 — 下一代模型設計：真實影像優先

2026-09-08。**設計已具體化，模型尚未實作或訓練。** 真實顯微影像與 SEM 對照是架構取捨的第一順位；合成資料可用來訓練和檢查運作，不能靠合成分數贏得「實際有用」的判決。

## 選定的方向

下一代採用 **完整二維重建、逐步核對原始觀測、另外核對形狀**。不再要求模型一定要有互相獨立的「移位置、變窄、補細節」三個修正頭。真正要透明的是：用了什麼資料與校準、每一步改了什麼、改完是否仍能解釋原圖、實際輸出是否通過真實量測。

概念流程：

**一張原圖與儀器條件 → 二維影像初值 → 學習提出修正 → 按成像方式還原成觀測並核對原圖 → 重複四步 → 原大小重建影像＋形狀診斷＋可信範圍**

重建不是以 SEM 作為推論輸入；SEM 留在獨立評估端。使用時仍只有一張顯微影像，可附已知儀器／曝光資訊。輸出仍在原圖座標與像素尺寸，內部較細網格不等於已獲得兩倍實際解析度。

## 1. 為什麼選這條路

| 已知實驗事實 | 設計回應 |
|---|---|
| R61 v16 主要在既有重建上作小幅修正，形狀與位移已有訓練要求 | 保留幾何／位移目的，增加可重建任意二維結構的容量；不只調整最後幾個亮度值 |
| R109 改善 ACM 輪廓但使半對比位置變差；兩種方向皆在 36 柱成立 | 主評估不能只挑有利讀法；圖像、幾何與材料對應必須獨立核對 |
| R119 的逐像素位置路徑同時壓窄邊界，細節又能補償前面操作 | 不用三個名字假裝分工純粹；沒有最後不受觀測檢查的細節補丁 |
| R121 的合成位置改進使所有真實柱體摘要與紋理指標退步 | 每個短候選直接評估真實樣品；不設「先贏合成才有資格看真實」關卡 |
| R122 證明位置／光學中心、固有寬度／模糊、未取樣細節都可能混淆 | 成像參數要有獨立依據；小殘差不是唯一答案或正確幾何的證明 |
| 真實全視野有尖角、間隙、密集排列、刮痕與亮暗反轉 | 主表示保留完整二維影像，不強迫每处都是對稱單調邊緣，也不預設圓柱模板 |

選擇比較了三種路線：

| 路線 | 優勢 | 為何不是單獨的最終選擇 |
|---|---|---|
| 明確形狀加紋理的生成器 | 容易記錄形狀參數 | 材料邊界和光學灰階未必一致，對相鄰邊界、角落與複雜紋理可能太僵硬 |
| 完整二維、反覆核對成像的重建 | 結構自由度較大，每次改動都有觀測核對 | 若成像假設錯，就會精確地解錯問題；未觀察細節仍依靠先驗 |
| **上項加獨立核對的幾何表示** | 同時保留重建能力與量測解釋，能找出圖像與幾何不一致 | 需要避免幾何分支自證；實際輸出影像必須自己通過外部量測 |

第三項是本輪的設計決定，**不是已驗證優於前兩項的成績**。R122 的剖面操作測試繼續保留作反例與診斷，但其一維公式不再限定唯一主架構。

## 2. 精確的影像與座標契約

以下為可實作的第一版工程提案，設定見 [architecture.json](../config/architecture.json)。

- 潛在影像 `x` 表示取得影像之前的理想光學強度；保留物體固有的亮暗過渡及紋理。它不是 SEM 灰階，也不是預設的二值材料圖。
- 第一個表示用兩倍密度的二維小格平均強度。原像素由小格面積平均得到 `P(x)`；內部表示與最終顯示的目標要固定，不可在訓練中偷偷多套一次目標模糊。
- 觀測模型為 `y ~ likelihood(F_kappa(x))`。`F_kappa` 一次施加取得影像的光學模糊、像素積分與已校準的相機響應。物體移動在這之前發生。
- 初值把每個原像素平均值複製到對應小格；重新積分可精確返回原圖。這是初始化恆等，不代表經過四步之後必然不變。
- 同一張圖的所有分塊共用原始座標、相機條件及校準身分，不以每個裁切重新估不同的全圖亮度統計。

第一版可以用有限支援的強度光學模型，但必須先對實際儀器資格判定。暈圈、相位、材料响应、非對稱中心、飽和等若不符合這個模型，不能用漂亮的擬合殘差宣稱物理正確。現有 PSF 資料尚未被認定全部適用這一版。

不允許對每個評估物件自由調 PSF 中心或寬度來吸收幾何錯誤。校準偏移若存在，記錄它的座標意義與不確定性，不把它任意重置成零。獨立取得的同一儀器校準可以供不同樣品共用；從評估樣品反推並拿去訓練的校準不行。

## 3. 四個共享重建步驟

第一版固定四步，使用同一個局部學習網路；四步不是經結果挑出的最佳數字，而是可控制成本的起點。

每一步：

1. 根據目前二維影像、原圖、目前重新成像與原圖的差異，以及局部噪聲／儀器條件，提出完整的二維修正 `p_t = x_t + alpha_t R_theta(...)`。
2. 對 `p_t` 做一次明確觀測校正：`x_(t+1) = p_t - eta_t grad L_observed(F_kappa(p_t), y)`。
3. 保存這兩種改動、目前影像、重新成像結果、差異以及實際圖像讀到的幾何變化。

初始學習部分使用 64 通道、四組局部殘差運算，範圍依序為 1 / 2 / 4 / 2，沒有步進降採樣、全圖注意力、全圖統計或全圖頻域求解。這些限制是為分塊與座標可核對性，不是宣稱某個網路元件天生不好。是否增加容量，應在機制有真實效益後，再用固定資料與成本比較。

觀測步長不能只有「是正數」：初版線性、二次誤差模型要用已實作邊界規則與噪聲權重的獨立上界限制步長，且記錄有限的校準噪聲下限。非線性相機或飽和資料需要對應的似然與界限，否則該模式不具備資格。不能把飽和值當成精確的未飽和答案。

沒有最後額外加上的自由細節修正。紋理和輪廓都存在同一個 `x` 裡，經過相同的觀測核對。這降低了未經檢查的補丁風險，**仍不能消除光學看不到的細節歧義**。模型可能依靠訓練先驗猜錯，故真實細節與不確定性仍要另外測。

## 4. 幾何與不確定性

另外從最後影像及固定局部線索輸出一般邊界與距離表示。第一版幾何讀取只用兩個 3×3 局部運算，範圍固定；不按圓柱模板、固定尺寸或固定排列生成影像，也不另行扭曲重建圖。

在有獨立幾何答案的訓練資料上，它可以幫助學習形狀；但外部評估一定從**實際重建影像**再量一次。幾何分支的漂亮數字不能挽救實際輸出偏移。影像與幾何的一致性，要依已校準的材料／光學對應定義；對應未成立時分開報告，不強迫 SEM 材料邊界等於光學中點。

可信範圍至少要交代：噪聲影響、校準變動造成的差異、不同初始化的差異、操作是否超出適用條件。兩個初始化只提供初步差異資訊，不足以把分布當成已校準的信賴區間。位置／尺寸區間必須用獨立資料檢查涵蓋率、寬度、以及自信卻錯誤的例子。

低可信度可以退回原圖並附原因，但「全部退回原圖」不能取得有用模型的判決。效益、接受修正比例及全部輸入的結果必須一起交代。

## 5. 分塊、記憶體與修正過的設計錯誤

交叉審查找到兩個數學問題，已在實作前修正並保留 [初稿與原因](../results/initial_design_review.json)：

- 原先預留 192 px 邊界不足。因學習部分也吃重新成像的差異，其依賴範圍會跟四次觀測校正一起累積。以初版光學核半徑最多 16 個原像素計算，含取樣、局部條件及幾何讀取的保守解析範圍為 **248 px**；第一版預留 **256 px**。這是設計推導，還不是實作分塊驗證。
- 單步更新從 `p_t` 出發時，額外 `||x-p_t||²` 的梯度為零；原先描述的近接限制實際不生效，已移除，改成上面真正會執行的觀測步驟。

因此第一個訓練提案使用 640 px 輸入、中間 128 px 算監督，兩側各 256 px 作周邊。必須記錄訓練中心實際包含哪些邊界、紋理、間隙與空白；整張場景的類別名稱不能代替中心內容。

內部 1280 px、四次重建會增加記憶體和時間。提案是每次一個場景的兩張觀測，保留精確的抽樣及更新計數，允許已宣告的重算節省記憶體。正式啟動前必须跑代表性反向運算及分塊測試；本輪沒有實測新模型的顯示卡用量、速度或完整梯度。

已實跑的獨立小檢查確認：像素平均的反向操作、觀測梯度、有限差分與一次觀測修正相容；同時證明「初值回原圖」不等於「非恆等光學下整模型不改原圖」。檢查使用簡單零邊界線性算子，不構成實際儀器校準或新模型效能證據，見 [數學檢查](../results/operator_math_checks.json)。

## 6. 最小、可歸因的訓練比較

正式設定提案見 [training_design.json](../config/training_design.json)。三組都使用同樣二維表示、四次共享學習修正、相同殘差輸入與觀測訓練要求：

| 組別 | 唯一機制差異 |
|---|---|
| A：匹配的學習修正對照 | 不執行明確的觀測梯度步驟；仍保留相同成像輸入與訓練資訊，不能稱完全沒有物理資訊 |
| B：迭代觀測核對 | A 加上每一步明確的觀測校正 |
| C：幾何輔助版 | B 加上幾何監督與已定義的一致性要求；幾何讀取部分各組均配置，但對照不啟用該訓練要求 |

另列 Raw 和適用條件下的傳統處理作參考，R109／R119／R121 A 僅供歷史背景。V42 不作教師、不作必須超越的門檻。若要比較普通單次直接重建網路，另立容量／運算量條件，不把上述 A 誤稱單次網路。

初始小試驗：512 個獨立生成場景、各兩張觀測、兩次完整資料遍歷、每次一個場景，即各組每個起點 1,024 次更新；兩個起點，合計六次。這是同資料／更新預算，不是相同運算成本。共同參數從同一份初值複製並核對，資料亂數與模型建立分開；只用相同 seed 不夠。

在 0 / 256 / 512 / 1024 次更新都跑固定的真實面板，主要架構比較固定用 1024。早期檢查點全數保留作診斷，不能某一組挑早期最好、另一組用最後。若依結果改資料、損失或選點規則，另立版本與完整開發記錄。

目前應用容差尚未由獨立校準與用途決定，故短試驗只能探索，**不能自動觸發長訓練**。要用真實結果作晉級依據，最低效益、保護界線和主要用途必須在該次結果第一次被看見之前固定。不能等看見有利指標才補判準。

## 7. 哪些部分還沒有完成

完整網路、實際儀器成像資格、實作邊界與分塊一致性、真實非柱體的獨立細節答案、真實平台絕對位置、以及新樣品確認都未完成。本輪不把它們包裝成「架構設計已寫好，所以能力已具備」。

實作下一步是：先把固定真實面板及量測入口接妥，將上述二維重建核心做成可運行原型，檢查成像與數值運作；完成後立即用小試驗的真實面板決定是否值得繼續。成像假設若未通過，不把相應步驟宣稱已受物理保障。

Primary-method context: [MoDL](https://arxiv.org/abs/1712.02862) combines an explicit observation model with learned updates and shared iterative weights; [Learned Primal-Dual](https://arxiv.org/abs/1707.06474) incorporates potentially nonlinear observation operators into learned reconstruction. These support the architectural family, not its performance on this microscope. The chosen design is an inference from the local failed and successful experiments; no published MRI/CT scores are transferred here.
