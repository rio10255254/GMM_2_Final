# R123：真實影像優先的下一代模型設計

[研究時間線](<../../docs/research/TIMELINE.md>) · [前一輪 R122](<../R122_OperatorPrinciples/FILE_GUIDE.md>) · [照這份設計做的 R124](<../R124_RealFirstPrototype/FILE_GUIDE.md>)

**一句話：** 第七階段的轉折點。2026-09-08 依使用者的要求，把真實顯微影像與 SEM 比較放到第一順位：每個候選從一開始就跑真實樣品，不再先贏合成資料才有資格看真實結果。架構選「完整二維影像、四步共享重建、每步回頭核對原始觀測、另外讀形狀」，不再強迫有「移位置、變窄、補細節」三個修正頭。這輪只有設計與資料核對，沒有訓練。

|---|---|

## 為什麼選這條路

| 已知事實 | 設計上的回應 |
|---|---|
| R109 讓 ACM 輪廓變好、半對比位置變差，36 顆柱方向一致 | 不能只挑有利的讀法，影像、幾何與材料對應要分開核對 |
| R119 的位置路徑同時壓窄邊界，細節又能補償前面的操作 | 不用三個名字假裝分工純粹；沒有最後不受觀測檢查的細節補丁 |
| R121 在合成形狀上變準，真實柱與紋理全部退步 | 每個短候選直接評估真實樣品 |
| R122 證明位置／光學中心、寬度／模糊、未取樣細節會混淆 | 成像參數要有獨立依據，殘差小不等於答案對 |

## 設計的重點

1. **潛在影像是取得影像之前的光學強度**，用兩倍密度的小格表示，不是 SEM 灰階；初值把每個像素複製到對應小格，重新積分可以精確回到原圖。
2. **四步共享修正：** 每一步先由同一個局部網路提出完整的二維修正，再做一次明確的觀測梯度校正；沒有全圖注意力、全圖統計或頻域運算，方便分塊。
3. **三組最小比較：** A 不做觀測梯度步、B 加上觀測校正、C 再加幾何監督；兩個起點、各 1,024 次更新。
4. **交叉審查改掉的錯：** 原本 192 px 的分塊周邊不夠，依賴範圍推導出 248 px，改成 256 px；單步更新裡原本寫的近接項梯度為零、實際不起作用，已移除。初稿保留在 `results/initial_design_review.json`。

## 用舊結果示範「不能誤判成功」

全局柱距參考下，相對 Raw 的配對中位數（負值較好）：R109 輪廓 −0.033、半對比位置 +0.070 px；R119 兩項都退步（+0.074、+0.174 px）。這張表不是新模型的比較，是用來說明兩種讀法互相矛盾時，不能挑對自己有利的那個。

## 讀這些內容要知道的事

1. **真實資料全部是「已用過的開發資料」。** 364 個光學影像檔案、9 張原始 SEM、144 個固定區域（重跑 R68 的選法，跟舊紀錄完全一致）都被多輪開發看過，而且禁止進入訓練；它們能決定方向，但不能稱為未見樣品。
2. **應用容差還沒定**，所以短測只能探索，不能自動觸發長訓練；要拿真實結果當升格依據，標準必須在結果第一次被看見之前固定。
3. R73、R74 是合成資料，不算真實面板；舊的 144 場景確認集已用掉，本輪沒有讀它的影像。
