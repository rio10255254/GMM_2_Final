# R145 — 修正方向對應後的新中心九顆 PSF 完整實驗

**目前狀態：修正後的正式 MAT、768 組新配對、8192 次完整訓練、930 張實拍與 8370 顆圓量測均已完成並通過稽核。**先前同名 MAT 已移到 `diagnostics_prior_orientation/`，對應的 R144 訓練只到第 160 次並中止。本輪使用重新擬合後、SHA-256 為 `a41413274d4134588070216f9699fd985b986c2419ae895ef6eabce0d0937231` 的正式檔案，不沿用舊銀行或其權重。

## 目的和設計

將修正九顆圓方向對應後的 25 顆 PSF，同時用於配對訓練影像卷積與 R141 系列模型的光學銀行。與 R143 保持相同的 768 個清楚母場景、分組、位移、噪聲方式、逐場景 PSF 編號、模型架構、初始種子及 8192 次更新；只讓新 PSF 銀行及由它形成的模糊輸入改變。R143 原資料、權重、930 張影像與報告都保留。

同一組 30 趟／930 張實拍影像與九顆圓已完成 PI 位移、尺寸與輪廓重拍；R143 是首要直接對照，R140v2、R129 與 RAW 作歷史參照。完成標準在 `reports/R145_VALIDATION_PLAN.md` 事先列明。[完整結果](reports/R145_RESULTS.md)、[穩定性追查](reports/R145_STABILITY_FOLLOWUP.md)與[PSF 為何未帶來預期增益的深入分析](reports/R145_PSF_LIMITING_MECHANISMS.md)保存實際數字與限制。

校準 PSF 時使用已知 SEM 圓柱直徑，是為了估計系統模糊特性。**神經訓練的清楚答案是原合成場景，沒有用 SEM 直徑作訓練標籤。**若後續拿同九顆、同一張 SEM 表比較尺寸，屬於校準所用參照的同樣本檢查；PI 位移與重拍結果分開報告。為保持與 R143 可比，模型半解析度光學分支及原尺寸資料卷積的尺度用法不在本輪另改。

本輪 PSF 擬合實際讀取的 Excel 九顆平均直徑為 2629.737 nm；舊輪廓點位換算參照的九顆平均為 2614.439 nm。尺寸結果會分別標示兩個來源，主表採本輪擬合所用的 Excel 值和已確認的九顆編號。

短步 PI 平均絕對差 R145 為 3.990 nm，比 R143 的 4.425 nm 低，仍高於 R140v2 的 3.640 nm。直徑重拍波動 21.013 nm，比 R143 的 24.161 nm 低，仍高於 R140v2 的 18.581 nm。輪廓重拍波動 16.001 nm，比 R140v2 的 18.430 nm 低。相同九顆的 SEM 校準尺寸平均差 R145 為 +191.887 nm、RAW 為 +169.883 nm；新版沒有保住 R143 的尺寸差優勢。合成測試 PSF 首選僅 6/206，實拍 930 張全選同一顆第一名，不能宣稱自適應選擇成功。正式基準不變。

追加的定量分析發現：現有光學分支的 PSF 中心在頻域運算中錯位，對低頻的反推又被設定強烈壓低；12 張實拍開關分支僅改變圓心約 0.24–0.32 nm、直徑約 0.35–0.50 nm。206 組保留場景中，不同 PSF 導致的典型影像差異皆低於各自雜訊。這些檢查解釋了為何 PSF 在擬合照片上很好，模型仍主要靠重新學到的整體影像修正作答。完整證據及未隔離的原因見深入分析。
