## 為什麼 PSF 擬合得好，量測卻沒變好（深入分析）

1. **頻域原點錯位（已證實）。** 模型把以中心為原點的 101×101 PSF 直接填進頻域陣列中央；在 160×160 特徵上，放在 (80,80) 的測試點經反推後峰值跑到 (1,1)，只修正原點就回到 (80,80)。
2. **作用被壓得很弱。** PSF 分支只在最後一次修正啟用，混入比例約 1.6%；反推式的常數 30 讓零頻只剩 3.2%，作用範圍只涵蓋約 5% 的頻率。12 張實拍開關分支，圓心只差 0.24～0.32 nm、直徑差 0.35～0.50 nm。
3. **25 顆差異低於雜訊。** 206 組場景用 25 顆分別卷積，不同 PSF 造成的典型差異中位 0.094 灰階，雜訊中位 1.5 灰階；選擇損失後段平均 3.2186，跟 25 類亂猜的 ln(25)=3.2189 幾乎一樣。
4. **物理尺度放大兩倍。** 資料製作把 PSF 用在原尺寸影像，模型卻在寬高減半的特徵上用同一個核。
5. **擬合拍攝與驗證拍攝條件不同。** PSF 是 9/24 拍的（背景中位 238、對比 111 灰階），930 張是 9/03 拍的（背景 166、對比 75），而且驗證批次內前後的邊寬也在變。

所以 R145 與 R143 在尺寸上的大差異（R143 縮小 74.7 nm、R145 放大 22.0 nm），主要是換了模糊資料後主網路學到不同的邊界修正，而不是推論時直接用了 PSF。

## 讀這些數字要知道的事

1. **SEM 對應在這一輪定案。** 九顆圓的影像位置依序對應 SEM 編號 36、35、34／30、29、28／24、23、22（R136 當時用的是另一個工作推定）。九顆集合相同，平均尺寸不受影響。
2. **有兩套 SEM 平均直徑。** 本輪 PSF 擬合讀的 Excel 九顆平均 2629.737 nm，舊輪廓點位換算的是 2614.439 nm，差 15.3 nm；主表用 Excel 值，兩者不能混用。
3. **用 SEM 校準 PSF 是合理的光學校準**，SEM 直徑沒有當成神經訓練標籤；但拿同九顆比尺寸只是同樣本對照，不是獨立準確度證明。
4. **PSF 只是比舊版好，不是唯一的物理答案。** 留出的圓外觀上新 PSF 平均差 0.00238、舊版 0.00472，但只調寬度的簡單高斯在同一批又略好（0.00220）。
