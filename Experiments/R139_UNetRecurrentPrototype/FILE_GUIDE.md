# R139：改回 U-Net，把光學放回解碼位置

[研究時間線](<../../docs/research/TIMELINE.md>) · [前一輪 R138](<../R138_V42PSF8/FILE_GUIDE.md>) · [修正它的 R140v2](<../R140v2_StableUNet/FILE_GUIDE.md>)

**一句話：** V42 本來是真正的 U-Net（編碼、解碼、跳接），PSF 放在半解析度的解碼層；R129 之後的模型都不是。R139 重建三層 U-Net（通道 32／64／96／128），保留原圖參照與四次共享修正，V42 八候選 PSF 放在半解析度解碼層、只在最後一次修正用一次。2026-09-23 從零訓練 8,192 次並跑完 930 張。但事後因果審查發現：訓練第 128 次輸出就完全飽和，模型退化成「原圖減一個固定灰階」，量測結果跟原圖幾乎一模一樣。

## 因果審查找到的崩潰過程（9/23）

1. **第 128 次就全部飽和。** 每個修正回合的輸出值絕對值平均約 6,132（tanh 在 8 以上就飽和），第 8,192 次約 9,880。
2. **之後主幹完全不再學。** 第 512 次與第 8,192 次比較，69 個模型狀態裡只有四個步幅參數變了，步幅從每回合 0.05 縮到約 0.0022。
3. **實拍輸出等於原圖整體減少約 2.29 灰階**，ACM 靠梯度找邊界，所以圓心與輪廓幾乎不變。
4. **PSF 分支表面上有強度，但傳不到輸出**，開關 PSF 的差別是 0。

原因是這套 U-Net 主幹沒有特徵正規化，卻沿用了 R130 淺層模型的 0.001 學習率。報告強調：這是本輪設計與訓練流程的失敗，不能據此說 U-Net 不適合或 PSF 沒用。
