# R139 U-Net 反覆修正原型

**狀態：架構原型，尚未正式訓練或驗證量測效果。** 這是獨立新一代，不覆蓋 R129、R130、R137、R138 的模型或證據。

## 為何改回 U-Net

V42 使用真正的編碼器、解碼器與跳接，PSF 弱殘差預設放在半解析度的解碼層 y2。R129 起改走四次共享修正；R130 再移除內部放大狀態，R137／R138 沿用，因此它們的主體不再是 U-Net。這是先前針對邊界、成本及原圖參考的工程選擇，並不是 U-Net 已被公平實驗證明無效。

R138 只複製 V42 的 PSF 模組，放在輸入主幹並呼叫四次；其 beta 約在第 2304 次被壓到零。R139 重新設計主幹，讓 PSF 回到 U-Net 解碼位置，使用一次。仍須正式訓練才能知道這樣是否真的改善量測。

## 現有原型

- 原尺寸輸入和輸出；三層向下編碼、三層向上解碼、對應跳接。編碼各層通道 32／64／96／128。
- 下採樣前固定低通；上採樣採雙線性插值、固定低通、卷積。奇數尺寸以跳接尺寸直接對齊。
- 保留原始影像作基準、七個局部影像線索、共用 U-Net 的四次修正、各回合可學步幅和 ±0.35 修正界線。
- V42 八候選弱 PSF 模組沿用其原類別，使用既有 25 顆，候選自動選擇。放在半解析度解碼層，僅最末次修正啟用一次。
- 光學分支先關閉兩個訓練循環，再漸進加入；光學參數學習率暫定為主幹的 5%。每次優化後把 beta 原始參數保持在有效範圍內，避免 R138 跌成負值後永久失去梯度。
- 起始輸出精確等於原圖；本版仍是從零訓練設計，沒有移植先前已訓練神經權重。

詳見 [架構與預定驗證](reports/R139_METHODOLOGY.md)。原型配置在 [model.json](config/model.json)。

## 已檢查

- 257×263 奇數影像的三層下／上採樣與跳接尺寸正確，四次修正正常；初始輸出精確等於原圖。
- PSF 在啟用後僅呼叫一次，混合權重及 beta 可收到梯度；beta 在零邊界仍能收到梯度。
- 既有一組 320×320 合成訓練配對可計算三項原有損失，做了兩次可丟棄的更新，沒有保存為候選權重。
- 1544×2064 完整尺寸在 RTX A6000 前向成功。這只是未訓練網路的可運作檢查，不是實測速度排名或有效性證明。

核對結果在 `results/`。目前沒有正式訓練模型、930 張重建、ACM／LSC、SEM 結論或消融結論。

## 資料與保存

模型和既有 25 顆 PSF 副本在本輪資料夾。訓練資料只引用已核對的 R130 合成配對，沒有再次複製大型 payload。若後續正式長訓練，需另在本輪建置完整訓練／保存／中途接續與驗證入口，鎖定來源後才啟動；此原型的設定不應被當作已通過的最佳超參數。
