# R126 methodology

## Completion contract fixed before execution

1. Preserve R125 implementation, data, checkpoints, results and original R119 protected identities.
2. Reproduce the derivative and update path on a fixed newly rendered two-view 2D example. Measure actual native/latent reference error and each loss term before and after 128 updates; use final step only.
3. Four matched runs: A=image-only learned updates, B=learned plus observation updates, each with either only image loss or all R125 non-geometry losses. Same 64-channel/four-stage network, initialization seed1265001, AdamW1e-4/1e-5, gradient clip5. Geometry parameters frozen in all four. Gradients decomposed at initialization. An engineering learnability signal is >=20% native-reference MAE reduction, not proof of generalization; every result retained.
4. Render a diagonal boundary intersected by a small rectangle independently on an8x Float64 grid, fixed Gaussian sigma0.8native/radius3, integrate to native observations and4x latent references. Two physical shifts (0,0),(.375,-.25), independent sensor noise1.5gray and quantization; no target goes into forward. Native256 with center64 and96px context if sufficient, otherwise320 with128px context. Exact required model/loss context is checked before use.
5. After diagnosis, freeze the matched photometry follow-up before execution. Keep source geometry/optics/motion controlled and never use SEM answers to generate training targets. Compare all intended final candidates on the existing R125 panel with the same references and common valid population. No favorable-checkpoint selection.
6. Verify training ledgers, checkpoint reloading, numerical behavior, source integrity and actual real-image outputs before final reporting. Negative outcomes do not trigger rebaselining or auto-extension.

Existing real images are reused development evaluation. Instrument optics and optical/material edge correspondence remain unqualified; absolute physical truth, unseen success, full R123 execution or model adoption cannot be claimed here.
