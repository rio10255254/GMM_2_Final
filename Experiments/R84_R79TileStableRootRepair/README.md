# R84：R79 切片穩定根治

R84 是獨立研究線，不覆蓋 R79 或 R83。目標是移除 R79 對可見影像範圍與切片大小的依賴，同時保留其形狀、SEM 與位移能力。

本輪先完成結構根治，再進行短訓練。只有整張與切片一致性、獨立合成形狀、R73、R74、36 顆 SEM 與六組真實位移全部通過，R84 才能升級。

所有訓練仍只使用程式生成形狀，不使用真實顯微影像、SEM、HS100MG、舊影像或其他模型輸出作為標記。

## 最終狀態

R84、R85、R86 都能修掉切片不一致，但無法同時保住 R79 的輪廓與 SEM 優勢，因此都不升級。最終根治是保留精確 R79，並把來源推論與 ONNX 交付統一鎖定為單次完整影像重建。完整結案見 `reports/R79_ROOT_REPAIR_CLOSEOUT.md`。
