# R141 封裝驗證

本包完整性檢查核對 2054 個固定程式／資料／評估參照檔、768 個合成母場景、25 顆實測 PSF 與衍生模型；`verify_package.py --mode infer-ready` 通過。25→4 受控選擇測試、不同模糊條件的 64 張保留影像測試及完整 U-Net 的梯度測試均通過，原始紀錄在本資料夾三份 `*.log`。

使用已訓練 R140v2 非光學主網路的衍生權重，實際重建一張 1544×2064 實拍影像；四顆入選索引為 16、8、0、24，輸出有限，`.npz`、預覽 `.png` 及收據 `.json` 均已產生。與原 R140v2 相同影像的輸出 RMS 差為 `1.397 × 10⁻⁶` 個八位元灰階，最大絕對差 `1.520 × 10⁻⁵` 灰階。四次更新的訓練煙霧測試亦通過，明確標成不可作為正式模型。新增 `--data-root` 後，另以包外資料根目錄完成四次更新，並用暫存 `psf_index=[0,8]` 驗證標記讀取；原資料未改。

這些檢查證明包可執行與來源可核對，**不是新四候選模型的 8192 次長訓練或 930 張全驗證**。現有 25 顆實測 PSF 幾乎同形，衍生選擇器尚未在這批資料上證明有用；不要把新四候選輸出說成 R140v2 已發表的完整量測結果。
