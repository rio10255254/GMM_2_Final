# R121 四組短測的方法與修訂紀錄

本輪使用同一架構、相同資料形狀與位移安排、兩個獨立起點，以及每組 12 輪、512 個訓練場景、768 次更新。A 是 R120 已修正的物理序列控制；B 只加獨立亮度／對比；C 只加細節前後的位置要求；D 合併兩者。不同種子不混成同一次訓練。

原有 R118 陣列與 R120 物理序列只讀共用，不複製大型資料。固定物理序列仍作用於 R120 原本的 96 個指定場景，其餘保留原有兩視圖配置；本輪不宣称全部 512 場景已改成固定光學序列。

資料因子採正向線性亮度轉換。對比與亮度中點獨立抽樣，同一個來源與它的標準答案接受相同轉換。幾何標記、光學參數及真實位移不改變；感測雜訊在亮度轉換後加入，沿用原有絕對雜訊強度抽樣。沒有 SEM 推算的內縮標籤。

## 位置要求的 v1 問題與 v2 修正

v1 在每個靠近邊界的像素周圍計算局部位置誤差，雖然通過了膨脹、曝光、梯度與資料公平性測試，追加的純寬度反例仍揭露偏差：邊界不動、只將過渡寬度從 1.2 改成 1.8 或 3.0 時，v1 會誤報約 0.079–0.167 像素的位置差。

因此已中止 `probe_C_s1215001`，保留日誌、已有權重、當時狀態、interruption.json 與負反例。此 run 不算有效 C 組，也不參與候選比較。沒有修改它的舊程式或舊保護快照來讓它變成通過。

v2 將採樣位置先投影到標準答案的邊界，再沿法向對稱採樣，而不是在偏離邊界的像素上開視窗。每張訓練影像使用 128 個只由參考決定的點，每條剖面為 ±6 像素、25 個樣點。剖面位置計算剔除亮度增益與位移無關的亮度常數影響，參考資訊不足的區域由參考本身決定權重，不由模型控制開關。

同一反例在 v2 中，直線最大誤報小於 0.000001 像素，圓形最大誤報約 0.00222 像素；真正膨脹 0.4 像素仍被辨識。純曝光、正確答案、平坦區與反向傳遞亦通過。正式比較中的 C/D 都使用 v2，v1 完整保留作負結果。

位置要求同時作用於加入細節前的重建與最終重建，各權重 0.02。動作階段尚未開啟細節時，兩個位置項會相同；這是事先聲明的兩端檢查，不是兩份独立資訊。幾何階段不加入這兩項。所有活躍模型部分仍按原有阶段更新。

## 為什麼保留已完成的 A/B

A/B 不啟用新位置項，所以 v1 與 v2 的位置讀法差異不會作用於它們。另做了精確檢查：A/B 在兩套程式中的所有損失值，以及幾何、動作、細節三個輸出頭的梯度完全相同。

因此第一種子的已完成 A/B 保留作有效對照；C/D 以新 run_id 重跑。第二種子的四組全部使用 v2 執行器。最終八組還必須核對：同一種子四組的初始權重一致，兩種子的初始權重不同，每組均有 12 輪與 768 次更新。

## 評估順序與界線

1. 同一個 96 場景、192 視圖的既有開發集，按角色檢查影像、梯度與高頻誤差。
2. 既有 240 個物理控制條件與 100 個亮度控制條件，所有候選看相同 Raw 和參考。評估使用每條邊界 720 個剖面，不把失敗剖面當成零誤差。訓練的 128 點與評估的 720 點不是同一套採樣。
3. 12 曝光、36 顆柱子，共同接受歷史 SEM 與獨立全局柱距校正參考。沒有每顆重新縮放。
4. 只有兩個種子都通過事先聲明的輪廓、位移與細節条件，才進入原 Raw 選定的真實 LSC 比較。LSC 保留原鎖定方法的 64/96 點設定，不能為了套一般角度規則而改變既有量測契約。舊獨立步驟重抽樣不會被當成新的區塊不確定度證明。

本輪不使用已消耗的 144 個確認場景。這些比較是開發與短測，沒有新的未看過確認集宣告，也不因「跑完」而升級模型。
