# R140 穩定 U-Net 修正實驗

本輪獨立修正 R139 早期輸出飽和，保留三層 U-Net、抗混疊上下採樣、原圖參考與四次共享修正、V42 八候選 PSF 的半尺寸解碼接入位置。原 R139 的錯誤結果保留，不覆蓋 checkpoint、報告或校驗值。

具體修正：各像素只跨通道正規化，不取整幅影像統計；輸出頭增益0.1；主幹學習率最高0.0003；梯度限制1；PSF前兩循環關閉後逐步啟用，光學參數仍使用主幹5%學習率，beta投影防止負值死區。

先用相同合成資料、順序與噪聲做256次丟棄權重短測。前期logit、梯度與開發資料通過預先設定的門檻後，才正式從零訓練8192次；最後模型固定，再用同930張實拍及相同角落九顆ACM／LSC／SEM量測。**短測權重不會移入正式訓練。**

此輪大影像輸出位於 H 槽專用目錄，D 槽保存模型、checkpoint、表格及報告；`data` 指向R130原始合成陣列，不重複複製。所有舊結果與正式COMBO基準保留。詳見[執行條件](FORMAL_RUN.md)與[方法紀錄](reports/R140_METHODOLOGY.md)。
