# R140 正式訓練與驗證入口

使用相同512／128／128合成母場景，模型種子1309001、順序1309002、噪聲1309003，從零8192次、16循環、每128次保存、每512次固定開發檢查，最後128母場景生成測試。輸入原384裁320，中心128監督；損失仍為影像+0.2梯度+0.2配對殘差。所有來源按原始資料清單核對。

與R139不同：U-Net加入每像素跨通道正規化，輸出頭增益0.1；主幹最高學習率0.0003、最低0.000003，梯度限制1。PSF保留自動八候選與原有25顆校準資料，前2循環關閉後scale由0.12到0.28，光學參數學習率5%，beta原始參數投影到有效範圍。這是修正訓練失穩而有意更改，不能宣稱單一模組因果改善。

在任何正式更新前先看 `results/pilot_256.json`。正式訓練早期及PSF開啟後另檢查修正輸出飽和率、輸出頭梯度與固定開發誤差；門檻不通過就停止，不進入930張真實驗證。僅在固定最後checkpoint、8192次更新及生成檢查完成後開放真實影像。

執行中 `runs/formal_8192/status.json` 和 `runs/pipeline_status.json` 為現況；正式結果只能以報告與完整驗證檔為準，不能憑「完成」狀態宣稱模型有用。
