# R75：R61 架構純形狀從零訓練

R75 是一套獨立、可直接執行的實驗包。它保留 R61v16 的模型骨架，但不讀取任何舊權重，也不使用 SEM、HS100MG 或其他真實樣品的影像與輪廓。

## 最直接的使用方式

1. 打開 `training/train_r75.py`。
2. 在檔案最上方調整輪數、批次大小、學習率、裝置與隨機起點。
3. 按編輯器的執行鍵。

預設會使用正式資料從零訓練 100 輪，並每 5 輪重建一次固定的九宮格 pillar Raw 影像。正式設定已關閉會造成更新被跳過的半精度模式；若整輪沒有任何有效更新，程式會立刻停止。若只想檢查而不訓練，把 `ACTION` 改成 `"check_only"`；若只想建立資料，把它改成 `"build_data_only"`。

訓練完成後，把待重建影像放進 `data/inference_input`，再打開 `inference/infer_r75.py` 按執行。它只會自動選擇正式訓練得到的最新權重，不會誤用短測試權重。

## 這個資料夾裡有什麼

| 資料夾 | 用途 |
|---|---|
| `model` | R75 自己的模型骨架、影像工具與純數學生成功能，不依賴外層模型資料夾 |
| `training` | 可直接按執行的訓練入口；`runtime` 是本實驗鎖定的訓練核心 |
| `inference` | 可直接按執行的重建入口 |
| `data` | 小型測試、檢視版、正式 5,120 張資料、九宮格觀察影像與待重建影像 |
| `weights` | 每次完成訓練後集中匯出的權重，依正式／測試與隨機起點分開 |
| `runs` | 每次訓練的完整過程紀錄 |
| `tools` | 可直接建立資料或檢查執行環境的輔助入口 |
| `scripts` | 資料建立、來源檢查與訓練啟動的內部核心 |
| `config` | 資料規模、模型內容與訓練預設值 |
| `reports` | 設計理由、檢查結果與可視化證明 |

## 正式資料設計

正式版固定為 5,120 組，不再追求更大的數量：

| 用途 | 數量 | 是否更新模型 |
|---|---:|---|
| 訓練 | 4,096 | 會 |
| 驗證 | 512 | 不更新，只用來選擇訓練中的版本 |
| 內部測試 | 512 | 完全不參與訓練與選擇 |

它由 16 類形狀組成：圓、橢圓、矩形、圓角矩形、梯形、正多邊形、圓環、膠囊形、十字、L 形、T 形、雙圓、三圓、平行長條、圓環加圓，以及扇形。每類有 80 個不同本體，每個本體再產生 4 種成像，因此是 `16 × 80 × 4 = 5,120`。

成像變化包含一般模糊、方向性模糊、短拖影、失焦、光暈、重影、亮暗反轉、對比、照明漸層，以及兩類雜訊。切分時以「形狀本體」為單位，所以同一輪廓的不同成像不會分散到訓練與測試。

## 防鋸齒答案

每張 256×256 的答案不是直接在低解析度畫出。流程會先在 1024×1024 繪製完整形狀與亮度，再以面積平均縮成 256×256。邊界因此保留真實的部分像素覆蓋，不會把低解析度階梯狀邊界當成正確答案。

可直接查看：

- `reports/figures/r75_pilot_preview.png`：16 類形狀的 Raw、答案與遮罩總覽。
- `reports/figures/r75_antialias_edge_zoom.png`：把邊界放大到像素層級，對照低解析度硬邊界、4 倍繪製後縮小的邊界與最終答案。

## 資料隔離

- 訓練與模型選擇不使用 SEM 影像、SEM 外形、SEM 半徑或 SEM 衍生標籤。
- 訓練資料不使用 HS100MG、Basler 真實裁切或任何既有訓練影像。
- 不使用舊模型重建結果、舊權重或老師模型。
- 不使用量測得到的模糊核心；九個核心皆由數學公式生成。

每筆資料都有來源記錄，正式啟動前也會重新檢查。模型、影像工具與訓練核心都有固定內容指紋；若被意外改動，訓練會停止並指出問題。

固定九宮格 pillar 只在第 5、10、15……100 輪額外重建並存圖。它位於訓練資料包之外，不計算分數、不更新模型、不參與權重選擇，也不觸發訓練控制。
