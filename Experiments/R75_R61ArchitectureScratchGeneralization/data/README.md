# R75 generated data

All generated data stays inside this experiment folder:

- `r75_smoke_pure_primitives`: 160 pairs for complete end-to-end checks.
- `r75_pilot_pure_primitives`: 256 pairs for visual and data-contract review.
- `r75_formal_pure_primitives`: 5,120 pairs for the formal scratch run.
- `inference_input`: images waiting for reconstruction.

Every package contains its own manifest, source audit, analytic PSF bank, high-resolution-to-low-resolution anti-alias evidence, geometry files, and fixed train/validation/internal-test indices. No legacy or real-microscope package is imported.
