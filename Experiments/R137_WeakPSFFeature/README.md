# R137 弱 PSF 特徵測試

狀態：8192次訓練、930張重建與8370次圓量測已完成，2026-09-22另行核對全部7200筆四方法位移相符。

使用原25顆PSF正規化後平均，Wiener線索進入局部特徵，強度固定0.02；原圖不改寫。從零訓練8192次，沿用512/128/128合成資料及930張共同實拍驗證。訓練前必須驗證PSF有作用、可精確關閉、梯度與固定光學線索下分塊一致性。

自包含程式包，訓練資料以唯讀來源雜湊約束的目錄連接共用R130 data；不複製大型資料。大型重建位於H槽。舊PSF可能來自SEM校準，不宣稱獨立SEM確認；沒有重新指定25顆視野位置。

## 結果摘要

相對R130，短步平均差4.121→3.917nm，直徑重拍16.422→14.262nm，輪廓重拍18.579→17.710nm；平均直徑較SEM偏大219.409→222.383nm。長距離平均差未明確改善。PSF確實有作用，但不是所有指標都更好；保留研究版本，不自動更換正式基準。[完整結果](reports/R137_RESULTS.md)
