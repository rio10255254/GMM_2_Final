# R100

這個資料夾包含 R100 的完整獨立實驗。正式模型從隨機狀態開始，不會載入 R61、R99 或任何其他舊權重；訓練資料也不含 SEM、HS100MG 或其他真實樣品的影像與形狀。

## 開始訓練

直接雙擊根目錄的 `Start_R100_Training.cmd`。它只允許啟動一次正式訓練，並會同時開啟監控視窗。也可以在編輯器中打開 `training/run_full_training.py`，調整裝置與工作執行緒後直接執行。

正式設定為 40 輪。每輪保留權重，每 4 輪執行完整合成驗證與 5、20、50 倍真實影像預覽。訓練期間不要再啟動第二份正式訓練。

## 查看進度

執行 `scripts/monitor_training.ps1`。監控會顯示目前輪數、各階段尺寸、最近速度、單輪與整體剩餘時間、顯存、輪廓、細節、位移與拼接狀況。關閉監控視窗不會停止訓練。

## 單張重建

訓練產生權重後，執行 `inference/run_inference.py`，指定權重、輸入影像與輸出位置。預設使用適合大圖的分塊重建，輸入可以是 8 位元或 16 位元灰階影像。

## 資料安排

原有 1250 個程序場景與 5000 個觀測保持逐位元不變，標籤輪廓在 8 倍解析度繪製後縮小。R100 只在記憶體中增加少量程序材質恢復觀測；材質不接觸輪廓，驗證資料完全不變，也不會寫回原資料包。

## 重要限制

R100 正式訓練完成前只能稱為候選模型，不能先宣稱優於 R61。完成後仍需用 5、20、50 倍真實影像、位移序列、SEM 輪廓與整圖分塊一致性做獨立驗證。
