# R151：在 R148v2 補回自適應 FFT PSF 融合

日期：2026-09-28。

## 結論

圖示中的 FFT、PSF 銀行、權重估計、加權融合、殘差比例與原圖連接已全部補回，並保留 R148v2 的一次多尺度脈絡、三個獨立原尺寸階段、抗混疊、原圖參考與 512/24 分塊。

程式與實際前向計算已通過，但目前 25 顆 PSF 在既有合成影像中仍不足以讓模型可靠辨認。25 選一的隨機準度是 4%；多種探測的驗證準度仍約 3.6% 至 5.2%。因此本輪只完成可執行架構與失敗證據，不啟動 8192 次正式訓練，也不把它稱為已成功的自適應 PSF 模型。

## R148v2 當時為何移除

R140v2 的光學分支確實有接線並執行，但 930 張實拍的八個候選權重全部精確等於 0.125。原因包括：

1. 當時八顆候選幾乎相同，最低餘弦相似度仍為 0.999978。
2. 正規量 30、只處理低頻、最終有效殘差比例約 0.005981，候選差異傳到輸出後極小。
3. 權重估計器最後一層從全零開始，前層在起點沒有梯度；光學參數學習率只有主網路的 5%。
4. 訓練沒有提供每張影像對應哪顆 PSF 的直接教學。
5. 全圖平均只會給整張影像一組權重，不能處理同張影像內的局部差異。

R148v2 因此採用最新 25 顆的平均 PSF，只提供一次固定光學提示；主要目的在保留可追蹤的物理方向，並控制反覆修正的依賴範圍，而不是否定多 PSF 融合概念。

## R151 如何補回並修正舊問題

| 圖示部分 | R151 對應方式 |
|---|---|
| Input Feature | R148v2 一次 U-Net 的 16 通道脈絡特徵，加上輸入的徑向頻率統計 |
| Split | 特徵送往權重估計；影像送往 FFT 光學路徑 |
| FFT / PSF 1…k / iFFT | 使用最新 25 顆 101×101 PSF；先修正頻域原點，再建立 25 個受限反濾波器 |
| Weight estimation | 非零初始化、溫度 softmax；保留已知 PSF 編號與物理寬度／尾部描述的教學入口 |
| Weighted fusion | 先在頻域加權，再做一次 iFFT；數學上等同逐顆 iFFT 後加權，記憶體較低 |
| Residual scale beta | 限定 0.0025 至 0.03，初始 0.01，不可靜默變成完全關閉 |
| Residual connection | PSF 修正直接接回原圖，再由三個原尺寸階段做有界修正 |

保留的固定平均 PSF 仍用於 R148v2 原有的成像一致性提示與觀察損失；新自適應融合是新增路徑，因此能獨立開關與檢查。

## 權重是否真的能學會

### 原始影像估計

- 25 選一、512 次：驗證 top-1 4.0%，top-5 20.4%；等同隨機水準。
- 把 25 顆分成四個差異較大的群組，使用平衡損失 1024 次：平衡準度仍為 25%，模型只會選單一群組。
- 改為預測 PSF 徑向寬度、四階矩與尾部比例，1024 次後標準化均方差 0.99387 變成 0.99375，相關約 0.01 至 0.02；沒有有效學習。

### R148v2 脈絡特徵估計

- 脈絡特徵加直接 PSF 編號與物理描述教學，256 次後 top-1 為 4.0%，描述均方差 1.004；仍為隨機水準。
- 再加入徑向頻譜特徵，並以同一清晰場景重新用已知 PSF 製作完全配對資料：
  - 加 0.5 灰階雜訊時，受控驗證 top-1 4.0%、top-5 20.25%。
  - 完全不加雜訊時，受控驗證 top-1 4.5%、top-5 20.25%。

這代表目前問題不只是權重網路太弱或舊版全零初始化。對這些場景而言，25 顆 PSF 造成的可觀察差距仍被物體本身的頻率內容蓋過；強迫權重變尖只會製造沒有物理證據的選擇。

## 短訓練狀態

兩個較早的 128 次整網路探測都讓重建開發誤差下降約 11% 至 12%，但 PSF top-1 只由 3.1% 到 4.7%，仍接近隨機。最終架構另完成 32 次執行煙霧測試，保存點與日誌可恢復；32 次不足以作效果判定。所有短測權重皆標記為非正式模型。

## 是否應立即完整訓練

目前不應。完整訓練可能讓主網路改善影像，卻仍留下接近平均的 PSF 權重，最後只能再次證明「模組存在但自適應未成立」。這會削弱論文主張。

進入正式訓練前至少需要以下其中一項：

1. 取得差異高於實際雜訊的多狀態 PSF，且同一清晰場景能在多個 PSF 下重拍或可靠生成。
2. 推論時提供可驗證的拍攝狀態或視野編號，將它作為 PSF 權重的校準先驗，而不要求網路只看單張影像猜測。
3. 先在未見過的場景達到 top-1 至少 12%、top-5 至少 40%，或物理描述預測相關至少 0.3；再做兩個起點的 512 次重建短測。

通過後仍須完成 8192 次從零訓練、930 張實拍、8,370 顆圓、位移／直徑／輪廓與分塊接縫的完整驗證。R148v2 正式結果保持不變。
