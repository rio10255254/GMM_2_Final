# P08 shortlist visual review

Visuals were inspected at equal display range on the R119 LSC frame and the
common synthetic representative panel. The R119 B LSC frame preserves the
large-grid/line layout without obvious tiling seam or clipped border. The
synthetic panel contains Raw, R118-derived candidate, R109 reference and target
columns for each family; no output was selected from a favorable frame.

The visual check is supporting evidence only. ACM/SEM/LSC tables remain the
decision evidence, and difference images are not treated as visible ringing.

the largest measured difference was below 0.003 gray levels on the four Raw
preview images. This verifies stitching consistency, not universal fidelity.
