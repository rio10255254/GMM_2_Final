# R119 results guide

This folder contains the measured outputs of one complete execution. The
development bank and intervention results are diagnostic; the probe matrix is
the bounded A/B/D comparison; shortlist folders contain locked ACM, SEM and
LSC development validation; `formal_*` contains the B E42 run and endpoint
checks; `confirmation` is the one-time 144-scene evaluation.

The principal plain-language interpretation is in
`../reports/R119_RESULTS.md` and `../reports/CLOSEOUT.md`. Do not select a
checkpoint by filename or loss alone, do not overwrite a completed output, and
do not reuse the consumed confirmation set for tuning. Any future research
change must use a new round and a new confirmation set.
