# R93 原始來源、停止結果與 GitHub 重做審查（2026-10-20）

## 本輪實際做了什麼

R93 嘗試把「去掉感測雜訊」和「恢復成像中仍可辨識的細節」分開，同時保護本來已清楚的輸入、輪廓位置、位移與分塊一致性。它從零訓練，沒有繼承 R61、V42 或其他模型；COMBO 正式基準未改。

同一個程式生成場景保存清楚目標 T、無雜訊但已成像退化的 B、含感測雜訊的 S，以及遮罩、距離與退化記錄。後面各輪因此可以針對同一場景建立不同的校正目標，而不是各自另生成一批無法對照的圖。

| 後續輪次 | 共用資料後實際改的問題 |
|---|---|
| R94 | 依輸入中的證據分配不同校正路徑，同時保護清楚輸入與位移 |
| R95 | 修補清楚輸入、零校正與門控目標之間的矛盾 |
| R97 | 直接學習各階段實際施加的校正，並限制錯一個週期的位置錯誤 |
| R98 | 擴大細節表達與紋理練習，降低分支互相抵消，同時保留 R97 的位移與分塊約束 |

這些輪次的模型與損失不同；共用 R93 影像不代表它們是同一個實驗。

## 真正停止在哪裡、怎麼選模型

實際執行設計為 64 輪；使用者在完成第 60 輪後停止。完整訓練表保留 1–60 輪，沒有把未跑的四輪補成完成。原內部分析只比較已觀察的 32–60 輪，每兩輪一筆，共 15 個候選。

五個面向各自按候選範圍的最小／最大值換算差距，先找「最差面向也較平衡」的候選，再以平均差距處理同分。重算選出第 48 輪，與原停止分析一致。

| 目的 | 原分析選到的輪次 |
|---|---:|
| 綜合平衡 | 48 |
| 細節 | 44 |
| 清楚輸入改動／平均位移 | 52 |
| 輪廓／曝光 | 60 |

第 60 輪的輪廓與曝光繼續改善，但細節及位移尾端較早期最佳點退步；清楚輸入仍有改動。因此不能只保存最後一輪，或只展示變得銳利的圖。這次補回先前 GitHub 附件缺少的第 48 輪，並保存全部既存模型檔與影像歷程。

## 保存與選圖

新完整紀錄保存 600 個原位置：34 個模型檔（含正式與 smoke，以及原本的別名）、250 張比較圖／測試影像、完整原表、停止狀態、預覽紀錄和必要小型輸入；相同內容只存一份物件。正式過程共有 32 個模型檔，並非宣稱做過 32 次獨立訓練。

其中原 results 裡的 245 張圖全部保存，沒有只挑成功圖。GitHub 頁面另放 24 張原檔作快速查閱：實拍監看選 40、50、60 輪的同四個輸入，合成圖選 44、48、52、60 輪的細節、清楚輸入與位移案例。當時沒有保存第 48 輪實拍監看圖，本次沒有補造那張歷史影像。合成圖中標示的 RAW 是模擬輸入，不能叫作相機原始照片。

所有入選頁面影像均原位元組複製，沒有重新壓縮、調亮、重畫或替換成新模型結果；完整來源及內容核對碼見 [圖像來源表](../../../docs/reproducibility/r93_shared/FIGURE_PROVENANCE.json)。
