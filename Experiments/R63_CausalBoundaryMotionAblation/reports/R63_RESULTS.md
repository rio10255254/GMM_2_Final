# R63 MOSR 因果消融實驗報告

狀態：**實驗、重建、量測、統計與圖表驗證均已完成；論文正文尚未修改。**

## 一、先講結論

這輪實驗支持兩個層次不同的結論。

第一，**完整 MOSR 確實比原始影像更適合後端量測**。相對 Raw，50× 與 20× 的九顆 pillar 中位 CD 絕對誤差分別下降 18.48% 與 36.84%；四組位移序列合併後，逐步位移波動下降 27.03%，九顆 pillar 的位移不一致量下降 60.52%，命令位移絕對誤差下降 29.84%。兩個訓練種子方向一致。

第二，**不能把完整流程的全部改善歸因於任一單一損失項**。廣義幾何錨定、廣義相對位移一致性，以及各個細分損失的移除結果，大多不到預先設定的 10% 實質門檻，或兩個倍率／兩個種子方向不一致。這代表現有資料支持「整體 MOSR 方法有效」，但不足以宣稱某一個訓練損失單獨打破了 CNN 的位置偏移問題。

目前最可靠的兩個模組層級發現是：

1. **Raw-position anchor 是邊界安全裝置。** 移除後，20× CD 中位絕對誤差增加 88.94 nm（+73.97%），兩個種子一致，且 50×／20× 振鈴分別增加 246.16%／392.37%。推論時直接關閉它，兩組靜態 CD 影像甚至無法通過既定的徑向對比檢查。它的作用不是在每一個倍率都把 CD 數值推得更小，而是避免重建失去原圖的低頻位置與正常亮暗拓樸。
2. **ShiftSafe upsampling 對九顆 pillar 的相對位移一致性有幫助。** 換成一般上採樣後，四組序列合併的九宮格不一致量增加 0.977 nm（+14.31%，95% CI 0.213–1.714 nm）；50× 合併結果增加 0.610 nm（+14.47%）。然而逐步位移波動只增加 4.68%，合成次像素位移向量誤差也沒有一致改善。因此它最適合被描述為「降低不同空間位置間的相對位移差異」，而不是全面提升所有位移指標。

同時必須保留一個重要限制：完整 MOSR 在 50× 的外圍振鈴能量比 Raw 高 86.14%，雖然 20× 反而下降 26.47%。因此論文可主張邊界與量測改善，但不宜寫成所有倍率下都同時消除振鈴。

## 二、完整 MOSR 相對 Raw 的實際效果

### 2.1 靜態 CD 與邊界

表中數字為兩個訓練種子的平均。誤差、範圍與邊界寬度皆為越小越好。

| 指標 | 倍率 | Raw | Full MOSR | 改善 |
|---|---:|---:|---:|---:|
| 中位 CD 絕對誤差 | 50× | 96.34 nm | 78.54 nm | 18.48% |
| 中位 CD 絕對誤差 | 20× | 190.39 nm | 120.25 nm | 36.84% |
| 跨門檻 CD 上下界寬度 | 50× | 354.46 nm | 115.47 nm | 67.42% |
| 跨門檻 CD 上下界寬度 | 20× | 792.65 nm | 674.84 nm | 14.86% |
| 10–90% 邊界過渡寬度 | 50× | 837.36 nm | 595.81 nm | 28.85% |
| 10–90% 邊界過渡寬度 | 20× | 1198.86 nm | 916.56 nm | 23.55% |
| 外圍振鈴能量 | 50× | 0.0000718 | 0.0001336 | **惡化 86.14%** |
| 外圍振鈴能量 | 20× | 0.0001731 | 0.0001273 | 改善 26.47% |

這組結果說明 MOSR 的主要收益不是把所有像素差異降到最低，而是讓邊界轉折更集中，並降低 CD 對門檻選擇的敏感度。50× 的代價是更強的外圍亮暗振鈴，所以後續文字應把「邊界變窄」與「完全無振鈴」分開討論。

## 三、消融結果：哪個創新實際負責什麼

### 3.1 Raw-position anchor：防止邊界脫離原圖位置

這個模組保留原始影像的低頻位置與大尺度亮暗關係，同時允許模型修復較高頻的邊界細節。它不是把 Raw 直接加回去，也不是單純降低銳化強度；它的角色是限制模型不能任意把整體邊界推離輸入影像。

匹配重訓後，移除 Raw-position anchor 的結果為：

| 指標 | 50× 移除代價 | 20× 移除代價 | 解讀 |
|---|---:|---:|---|
| 中位 CD 絕對誤差 | −15.09 nm（−19.22%） | **+88.94 nm（+73.97%）** | 對倍率敏感；20× 明顯需要錨定，50× 單一誤差反而較小 |
| 外圍振鈴能量 | **+246.16%** | **+392.37%** | 兩倍率均出現大幅振鈴惡化 |
| 逐步位移波動（全序列） | −0.277 nm（−3.26%） | — | 沒有支持位移波動改善 |
| 九宮格不一致量 | 小幅且信賴區間跨零 | 小幅且信賴區間跨零 | 沒有支持位移穩定性的普遍因果作用 |

20× CD 的 +88.94 nm 代價在兩個種子分別為 +78.44 與 +99.44 nm，95% CI 為 49.29–125.29 nm，達到預設的方向、幅度與區間要求。可是 50× 的 CD 單一指標方向相反，所以最嚴謹的結論不是「Raw-position anchor 讓所有 CD 都更準」，而是：

> Raw-position anchor 能抑制重建的邊界與亮暗結構脫離輸入影像；其安全作用在 20× CD、兩倍率振鈴與失敗檢查中最明顯，但 CD 數值收益具有倍率依賴性。

推論階段直接關閉該模組時，0.08 pixel 合成位移誤差暫時下降 56.67%，但在 0.4、0.8、2 與 8 pixel 分別惡化 603.74%、411.27%、1312.88% 與 1058.18%。這表示沒有錨定的輸出可能在極小位移的單一指標上偶然較好，卻在更完整的位移範圍失去可靠性。`no_anchor` 與 `no_all` 的靜態 CD 輸出更因徑向對比不符合既定量測條件而被判為無效；本輪沒有放寬門檻去強行得到數字。

### 3.2 ShiftSafe upsampling：改善不同 pillar 之間的位置一致性

這一組比較只更換上採樣方式，兩側保留相同可訓練參數規模、相同初始權重、相同資料、相同訓練預算與相同光學先驗。報表中的「一般上採樣代價」為一般方法減去 ShiftSafe；正值代表 ShiftSafe 較好。

| 指標 | 一般上採樣代價 | 相對差異 | 95% CI | 判讀 |
|---|---:|---:|---:|---|
| 九顆 pillar 不一致量，四序列合併 | **+0.977 nm** | **+14.31%** | 0.213–1.714 nm | 支持 ShiftSafe |
| 九顆 pillar 不一致量，50× 合併 | **+0.610 nm** | **+14.47%** | 0.142–1.091 nm | 支持 ShiftSafe |
| 九顆 pillar 不一致量，20× 合併 | +1.344 nm | +14.24% | −0.089–2.799 nm | 同方向，但區間跨零 |
| 逐步位移波動，四序列合併 | +0.395 nm | +4.68% | −0.284–0.995 nm | 差異小，未支持 |
| 合成次像素位移向量誤差 | −0.00061 pixel | −4.59% | −0.00511–0.00067 pixel | 兩種子方向不一致 |

因此，ShiftSafe 的證據集中在「同一影格內，九顆 pillar 是否給出彼此一致的位移」，而不是「每一步的整體位移向量是否都更接近命令」。這正好對應本論文量測導向主軸中最合理的創新敘事：減少解碼上採樣造成的空間相位差異，讓不同視野位置的邊界移動更一致。

可以寫：

> 相較於一般上採樣，位移安全上採樣降低了真實序列中不同 pillar 的位移不一致量，四組序列合併改善約 14.3%，顯示其主要作用為維持跨空間位置的相對幾何一致性。

不應寫：

> 位移安全上採樣已證明全面提升所有次像素位移精度。

因為合成位移向量誤差與逐步位移波動沒有提供這麼廣的支持。

### 3.3 幾何與位移損失：目前沒有可獨立歸因的證據

本輪同時測試廣義幾何錨定、廣義位移一致性，以及形狀幾何、全域邊界位置、identity boundary guard、region boundary teacher、相鄰影格一致性、已知位移監督與一般平移等變性。判定規則要求兩個種子同方向、實質差異至少 10%、95% 配對區間高於零，且主要護欄不得惡化超過 15%。

| 比較 | 主要結果 | 判定 |
|---|---|---|
| 廣義幾何錨定 | 50× 移除代價 −1.19 nm（−1.52%），方向不利且護欄未過 | 不支持獨立因果主張 |
| 廣義相對位移一致性 | 全序列逐步位移代價 +0.061 nm（+0.72%），CI 跨零 | 差異可忽略 |
| 相鄰影格一致性 | +0.025 nm（+0.30%），CI 跨零 | 差異可忽略 |
| 形狀幾何、全域邊界、identity guard、region teacher | CD 效果小、倍率方向不一致或未達門檻 | 不支持 |
| 已知位移監督、一般平移等變性 | 位移效果小或區間跨零 | 不支持 |
| Boundary residual adapter | 移除後主要 CD 指標沒有一致惡化 | 不支持單獨歸因 |
| Quality gate | CD 與位移效果小且方向不一致 | 不支持單獨歸因 |

這不等於這些設計「沒有用」。更精確的含義是：在相同預訓練起點、有限 60-epoch 加強訓練與目前資料量下，其他共存機制可能已經補償被移除的項目，因此未能得到足以獨立歸因的差異。若要把其中任一項寫成主要創新並宣稱它單獨造成精度提升，仍需更大樣本或從隨機初始化開始的完整重訓證據。

## 四、為什麼完整 MOSR 很好，但多數單項消融不顯著

這兩個觀察並不矛盾。

1. **完整 MOSR 與 Raw 是整條方法鏈的差異。** 它同時包含重建網路、固定光學先驗、輸出保護與量測導向訓練，所以差距可以很大。
2. **消融比較只移除一個機制。** 其他損失與輸出保護仍然存在，模型也會在重新訓練中補償，因此單一移除差距通常較小。
3. **所有候選從相同穩定權重開始做匹配加強訓練。** 這個設計適合估計「保留某機制的邊際價值」，但不能等同於每一個架構都從零開始訓練。
4. **只有兩個訓練種子。** 配對重抽樣能描述 pillar、步驟與方向的變異，但對跨訓練重複性的推論仍然有限。

所以最安全的論文主軸是：完整 MOSR 在尺寸與位移量測上優於 Raw；Raw-position anchor 提供邊界安全性；ShiftSafe upsampling 改善跨 pillar 的位置一致性。其他訓練項保留為整體策略的一部分，但不逐一宣稱已完成獨立因果證明。

## 五、實驗設計與量測定義

### 5.1 比較條件

共 16 個條件、2 個固定種子，合計 32 次有效訓練：完整控制組、幾何／位移 2×2 因子設計、七個細分損失移除、三個輸出模組匹配重訓，以及 ShiftSafe／一般上採樣匹配比較。PSF 路徑、檔案雜湊、起始權重、固定資料切分、批次、更新次數與檢查點選擇規則在全部條件中一致；PSF 從未被移除。

每個條件原定 40 epochs；預先設定的收斂檢查觸發後，全部條件一律延長到 60 epochs。全域 1–60 epoch 中重新選擇最佳檢查點，避免只在延長段內挑選。最終 29 次訓練選到 epoch 60、2 次選到 epoch 56、1 次選到 epoch 24。

### 5.2 靜態邊界與 CD

- 每個倍率使用同一個中心九宮格，共九顆 pillar。
- SEM 提供的數值為半徑，本輪在建立參考直徑時只乘以 2 一次。
- 50× 與 20× 依實際拍攝方向分別使用既定 `flip_x` 與 `flip_y` 對應，避免將不同樣品擺放方向誤當成不同結構。
- 主要 CD 結果不是只看 50% 門檻，而是在 35%–65% 門檻、兩種極性處理下建立上下界與中位誤差；50% 單門檻只保留為診斷值。
- 邊界銳利度以 10–90% 過渡寬度表示；越小代表灰階跨越邊界所需距離越短。
- 振鈴以 pillar 外圍既定區域內的過量亮暗能量表示；越小越好。

### 5.3 真實位移

- 四組序列各固定 30 步，選擇完全由 Raw 的品質排序先決定。
- 每一步皆量九顆 pillar；模型結果不能改變被納入的影格。
- 逐步位移波動：同一序列中連續步長的標準差。
- 九顆 pillar 不一致量：同一步內，九個局部位移相對共同位移的分散程度。
- 命令位移絕對誤差：量測步長與實驗命令步長之差的絕對值。
- 合併 0.5 與 1.0 µm 序列時，先在各序列內減去自己的平均步長，再計算共同波動，避免把命令大小差異錯當成雜訊。

### 5.4 合成位移與統計

- 合成集合為九顆 pillar、五種位移量（0.08、0.4、0.8、2、8 pixel）、八個方向，共 360 個位移案例，另含九個參考案例。
- 0.08、0.4、0.8 pixel 為主要次像素層；2 與 8 pixel 為範圍檢查。
- 配對重抽樣 4,000 次；靜態 CD 以 pillar、真實位移以步驟、合成位移以案例為抽樣單位。
- 主要支持門檻：兩種子同方向、效果至少 10%、95% CI 完全高於零，且護欄沒有超過 15% 的惡化。
- 5% 以下視為可忽略；5%–10% 或只有一個倍率／種子一致時，只能視為趨勢。

## 六、資料品質、完整性與限制

### 已完成的檢查

- 32/32 次有效訓練完成，16 個條件均含兩個種子。
- 32 個檢查點均通過結構檢查；固定 PSF 與光學設定一致。
- 每個條件、種子的 571 張重建均完整，合計 18,272 張候選影像。
- 靜態 CD、四組位移與合成位移量測均完整；無效輸出被明列，未以放寬門檻補值。
- 分析規則與主要資料雜湊在候選重建量測前凍結。
- 15 項自動測試通過；兩個 MATLAB 製圖檔通過靜態檢查。
- 24 張圖均輸出 PNG 與 PDF，並逐張檢視字體、標籤、範圍與圖例。

### 必須保留的限制

1. **只有兩個訓練種子。** 因此 95% 區間主要描述 pillar／步驟／案例的條件變異，不等同大量獨立訓練的模型分布。
2. **多數最佳檢查點位於 epoch 60。** 固定預算比較是公平的，但不能宣稱所有候選都已達到漸近收斂。
3. **50× 靜態影像與合成位移集合在目前模型套件的資料清單中未被列為訓練資料；但更早期起始權重的完整祖先資料無法由現有檔案證明。** 因此這部分可稱為「現行套件清單未見」，不應寫成已證明完全跨樣品獨立。
4. **20× CD 與位移序列屬相同資料域。** 它們適合驗證量測鏈在本實驗域內的效果，不等同外部儀器泛化。
5. **50× 振鈴惡化。** 不能只展示 CD 或邊界寬度而完全忽略此取捨。
6. **細分模組比較未做多重比較校正。** 因此零散的小幅正向結果不能挑出來當成主要結論。
7. **外部 GMF 原始影像目前不存在。** 本輪沒有把舊模型重建圖冒充 Raw 重新評估。

執行期間曾發生三次顯示卡驅動層中斷；每次均以相同設定、同一檢查點與精確張數續跑，沒有更改分析條件，最終完整性檢查通過。這是執行稽核事項，不是模型量測結果。

## 七、建議如何放進論文

### 可以安全寫入

1. 完整 MOSR 相對 Raw 同時降低 CD 誤差、邊界過渡寬度、位移波動與九宮格不一致量，證明量測導向重建的整體可行性。
2. Raw-position anchor 的主要價值是防止邊界位置與亮暗拓樸脫離輸入；其保護作用由 20× CD、兩倍率振鈴與推論失敗檢查共同支持。
3. ShiftSafe upsampling 在真實序列中降低跨 pillar 位移不一致量約 14.3%，支持其維持空間相對幾何一致性的設計目的。
4. 50× 的銳利度與 CD 改善伴隨更強振鈴，顯示本研究不是單純以視覺銳化作為唯一判準，而是同時檢查量測收益與假影代價。

### 不建議寫入

1. 「每一個幾何損失都已被證明能提升 CD。」
2. 「相鄰影格一致性是位移穩定改善的唯一原因。」
3. 「ShiftSafe 已全面提升所有次像素位移精度。」
4. 「MOSR 在所有倍率都降低振鈴。」
5. 「消融實驗證明 CNN 的位置關係規則已被打破。」

較準確的替代語句是：本研究透過固定光學先驗、原始位置保護、量測導向監督與位移安全上採樣形成互補方法鏈；完整方法明顯優於 Raw，而消融結果進一步指出，原始位置保護主要防止邊界失真，位移安全上採樣主要改善跨位置一致性。
