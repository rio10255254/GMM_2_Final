# R83：R79 重度顯微條件補強

R83 已完成。結論不是產生一個比 R79 更好的新權重，而是保留原 R79，並整理出一個可選的保守輸出模式。

## 最後結論

- 預設模型仍是 R79 第 23 輪。
- 兩個乾淨重訓候選都沒有在困難顯微輪廓上超過 R79，因此沒有繼續正式訓練，也沒有升級任何新權重。
- 保守模式在最困難的 R74 輪廓測試改善約 23%，384 組保留合成影像、24 顆保留 SEM 與六組真實位移也都守住預設門檻。
- 但 R79 的結果會隨大圖切片尺寸改變；512 切片與整張輸出差異超過預先設定的限制。因此保守模式只能作為「整張影像推論」的選項，不能宣稱全面取代 R79。
- 專案正式基準沒有變更。

## 直接重建

打開 `inference/infer_r83.py` 後可直接執行。預設會自動使用整理好的 R79 權重，並採用最保守的 direct 模式。

- `INFERENCE_MODE = "direct"`：完全等同原 R79，建議作為預設。
- `INFERENCE_MODE = "safe"`：降低低品質影像中的過度重建，只建議整張影像使用。
- 預設不允許影像被自動切片。若影像超過整張推論上限，程式會明確停止並說明原因，不會偷偷改變結果。

## 訓練資料

- 共 5,120 組，包含 640 個互不混用的程式生成幾何。
- 4,096 組訓練、512 組內部驗證、512 組內部測試。
- 類型涵蓋基本形狀、非圓形、密集排列、多尺度、局部邊界消失，以及不應被模型擅自改動的近原圖案例。
- 所有標記先以 8 倍解析度繪製再縮小。
- 未使用 SEM、HS100MG、真實顯微影像、舊訓練影像或其他模型產生的標記。
- 另有 384 組獨立保留測試，訓練與選擇模型時都未使用。

## 資料夾用途

- `training`：可直接開啟與調整的訓練入口。
- `inference`：日常重建入口。
- `weights/selected`：最後保留的權重；內容與 R79 第 23 輪完全相同。
- `results/final_confirmation`：合成影像、輪廓、SEM、位移與切片一致性的完整結果。
- `reports/R83_RESULTS.md`：完整結論與數字。
- `reports/closeout_manifest.json`：關鍵成果的數量、大小與雜湊清單。
- `runs`：試跑與被排除的訓練紀錄；被排除的紀錄均有明確標記，未混入最終結果。

## 重新執行順序

1. `tools/prepare_dataset.py`：重建並檢查資料。
2. `scripts/prepare_r83_seed.py`：重建 R79 起始權重並確認完全一致。
3. `training/train_r83.py`：執行訓練試驗。
4. `inference/infer_r83.py`：重建影像。
5. `scripts/foreground_r83_monitor.ps1`：查看訓練狀態與即時驗證影像。
