# R83：替 R79 補強困難成像，最後只留下一個保守輸出選項

[研究時間線](<../../docs/research/TIMELINE.md>) · [起點 R79](<../R79_R75v3_DenseMicroscopyScratchGeneralization/FILE_GUIDE.md>) · [前一輪 R82](<../R82_R39R40CrossSceneGeneralizationBenchmark/FILE_GUIDE.md>) · [切塊問題 R84](<../R84_R79TileStableRootRepair/FILE_GUIDE.md>)

**一句話：** R79 第 23 輪在 SEM 和實拍位移很強，但困難成像（R74）比原圖差。2026-08-09 試著只微調 R79 的最後幾層、資料補上重度模糊與局部邊界消失的案例，兩個試跑都沒超過 R79，依事前規則停止。最後保留的是同一組 R79 權重加上一個「保守輸出」：只在輸入品質差時減少改動，R74 改善 23%、其他保留測試都守住門檻；但它跟 R79 一樣，切塊推論會改變結果，所以只能當整張推論的選項。

| | |
|---|---|
| 結果 | **未採用**（新權重沒有超越 R79；保守輸出只能用在整張推論） |
| 時間 | 2026-08-09 |
| 實驗條件 | 純合成資料訓練；確認用 384 組預先產生的保留合成、24 顆保留 SEM、六組實拍位移 |
| 起點 | R79 第 23 輪的平滑（EMA）參數精確複本 |

## 這輪在問什麼

只微調最後的重建層、修正資料分布，能不能保住 R79 的 SEM 與位移，同時改善重度困難成像？

## 怎麼做

- **資料：** 5,120 組程式生成，含 1,280 組重度邊界案例（每個幾何四張可還原、四張刻意不可辨認；不可辨認的用保守答案，不獎勵憑空補邊）、3,040 組回放、800 組「不修改」守門。
- **模型：** 先把未訓練的 R79 狀態存成可選的退路，R83 不能被迫選一個更差的微調結果；試兩種範圍（只調邊界轉接層，或再加最後的重建尾端），正式訓練上限 30 輪。

## 結果

**兩個試跑都沒有在 R74 超過 R79：**

| 候選 | R73 輪廓誤差 | R74 輪廓誤差 | SEM 開發組誤差 |
|---|---:|---:|---:|
| 原 R79 | 0.2733 px | 11.2185 px | 0.2469% 柱距 |
| 只調新增尾端 | 0.2730 px | 11.2531 px | 0.2465% |
| 調新增尾端與最後輸出 | 0.2706 px | 11.2224 px | 0.2517% |

**保守輸出（同一組 R79 權重）的確認：**

| 驗證 | 原 R79 | 保守輸出 | 變化 |
|---|---:|---:|---:|
| 384 組保留合成，中位灰階誤差 | 3.4074 | 3.1935 | 改善 6.3% |
| 160 組保留合成輪廓 | 0.3144 px | 0.3280 px | 增加 4.3%（門檻 5%） |
| R74 困難顯微輪廓 | 11.2185 px | 8.5908 px | **改善 23.4%** |
| 24 顆保留 SEM 輪廓 | 0.2467% | 0.2526% | 增加 2.4%（門檻 10%） |
| 實拍位移 | 6/6 | 6/6 | 無退化 |

**切塊一致性沒過：** 整張推論與 512 px 切塊推論的最大灰階差 53～55，門檻是 3；關掉 PSF 後差異仍在。原因是 R79 內部會依當前整塊影像重新調整特徵分布，這是架構限制，不是拼接接縫。

## 讀這些數字要知道的事

1. **有一次訓練被作廢。** 較早一次訓練看起來略有改善，檢查後發現它同時把 R79 原本的 PSF 強度一路降到零，所以整次訓練與輸出都標為無效；資料夾裡 `pilot_psf_lock` 的那幾次才是修正後的乾淨試跑。
2. **R73、R74 對 R83 是開發測試**，乾淨的確認是 384 組保留合成、保留 SEM 與實拍位移。
3. **選定的權重跟 R79 第 23 輪完全相同**，放在 `weights/selected`。
4. 這個切塊問題接著由 R84～R86 處理。
