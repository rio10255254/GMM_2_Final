# R108D Multiscale Normal Geometry Microprobe

This is a bounded causal experiment, not a delivery model. It tests whether
R108C failed because its edge specialist can only scale one fixed unsharp
basis. The new specialist starts from random initialization and predicts a
local mixture of four blur-removal scales plus two normal-shift terms.

Training uses only procedural, supersampled generic shapes. Real microscope
and SEM images are sealed evaluation inputs only. The R108C edge checkpoint is
loaded only after training as a frozen comparator and never supplies a target.
