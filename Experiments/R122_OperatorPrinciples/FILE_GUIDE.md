## 操作原理與單張影像的歧義

1. **位置與寬度可以分開，但像素插值不行。** 對連續單調剖面用 `J(c + g*(t-c-delta))`，中點移到 `c+delta`、寬度變 `1/g`。3,888 組測試裡，連續版本全部通過；直接在原始像素上線性插值，位置失敗 1,028 組、寬度失敗 3,120 組。
2. **估錯中心或加零均值細節都會移動中點。** 壓縮中心估錯 0.3 px，1.5 倍變窄就讓中點漂 0.1 px；總量幾乎為零的細節補償仍讓中點移動約 0.075 px。
3. **單張影像有三種歧義：** 物體移動 0.4 px 和光學中心偏 0.4 px 可以得到完全相同的影像；物體本身的邊緣寬度與光學模糊可以互換；不同細節經過像素積分可以得到一樣的像素值。
4. **位移量得穩不代表邊界位置對。** 360 組二維成像中，半徑 16 px 的圓位移誤差只有 0.00003 px，絕對邊界卻錯 0.29 px，共同偏差在相減時抵消了。第一版模擬本身有離散化問題（造成約 0.1 px 誤差），保留為失敗紀錄，正式解讀用改成面積積分的 v2。
