# R88：量測忠實的獨立從零訓練

R88 的目標是同時改善輪廓、ACM、位移還原、真實紋理保留與大圖分塊一致性。它不是接續 R61、R79 或 R87 權重，而是完全從隨機初始值開始的一次獨立實驗。

## 目前狀態

- 已於2026-08-11 00:08停止，完整完成87／100輪；[原停止紀錄](reports/R88_ABORTED_AT_E87.md)記載最後保存模型為第85輪。
- 真實50倍輸出接近原圖，沒有驗證輪次通過原先條件；原紀錄保留資料、位移裁切、輸出限制與驗收設計的共同問題。
- 本輪保留為失敗案例，不續跑、不續訓、不作為下一輪起始權重，也未升級正式COMBO基準。
- 先前已生成1,280正式場景／5,120觀察，另有384封存盲測場景。封存不等於已開啟驗證；訓練、選模與後續使用規則仍以原紀錄為準。
- 模型、訓練、推論與生成內容的原實作鎖保留。本次只更正閱讀入口，沒有改原程式、模型、原表或失敗判決。
- 原先停留在啟動時的首頁已按原位元組保存在[修正前歷史副本](../../docs/history/R88_README_BEFORE_STATUS_RECONCILIATION_20261021.md)。[方法、來源與保存範圍](../../docs/reproducibility/experiments/main__R88_MeasurementFaithfulScratch.md)。

## 這一輪如何避免過去問題

1. 輪廓先在 8 倍解析度繪製，再縮回正式尺寸，避免鋸齒標記。
2. 七種形狀與困難角色在訓練時取得相近曝光，不讓大量普通圖形淹沒難例。
3. 正向、反向與零位移影像使用相同成像條件，只保留每張獨立雜訊。
4. 近乎原圖的資料專門約束模型不要亂改；修正量受限，信心不足時保留原圖。
5. 大圖推論固定保留每邊 192 像素上下文，不靠接縫羽化掩蓋差異。
6. 選模只看合成驗證資料；SEM、真實顯微影像與封存盲測必須等權重固定後才能揭曉。

## 資料夾用途

- `config`：鎖定的實驗設計、通過門檻、執行授權與實作雜湊。
- `data`：煙霧資料、正式資料與封存盲測；大型內容不納入版本控制。
- `model`：R88 模型本體，不含其他輪次架構。
- `training`：可直接執行的訓練入口；預設只跑安全的煙霧測試。
- `inference`：正式分塊重建入口。
- `scripts`：資料生成、完整檢查、正式啟動與監看工具。
- `weights`：煙霧與正式權重，依執行編號分開。
- `runs`：每次執行的來源、進度、指標與錯誤紀錄。
- `results`：顯存與拼接壓測、訓練中合成重建預覽。
- `archive`：正式鎖定前的可回復舊煙霧產物，不參與任何正式流程。
