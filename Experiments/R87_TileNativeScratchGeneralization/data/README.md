# Data

- `r87_formal_scene_pairs`: fixed 1,280-scene / 5,120-view procedural package.
- `r87_smoke_scene_pairs`: small generator and loader wiring check.
- `live_validation`: real 5x, 20x and 50x frames used only for displayed reconstructions.

The formal package is built by `scripts/generate_dataset.py`.  Its manifest and
audit record exact seeds, splits, source isolation, file hashes and counts.
