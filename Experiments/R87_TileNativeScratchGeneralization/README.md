# Round 87 — Tile-Native Scratch Generalization

## 假說

若模型從一開始就只使用局部運算，並用同一個大型合成場景的兩種切法共同訓練，便能在不使用舊權重或真實樣品答案的前提下，同時學到顯微影像重建、輪廓與大圖拼接一致性。

## 設計

- 一個完全獨立的 100-epoch scratch run；禁止 checkpoint、teacher、pseudo-label 與任何舊模型輸出。
- 1,280 個 1536x1536 程式生成場景；每個場景兩種成像、每種成像兩個重疊視角，共 5,120 個實際訓練視角。
- 幾何先以 8 倍解析度繪製，再用面積平均降到目標解析度。
- 896 輸入視角的中央 512 區域作正式輸出，四周 192 像素只提供上下文。
- 同一場景、同一成像的兩個視角在重疊區直接比較，約束不同切法得到相同結果。
- 訓練只使用可還原的程式生成成像；SEM、HS100MG、真實顯微像素只在權重鎖定後驗證。

## 正式訓練

| Epoch | 輸入大小 | 中央有效區 | 每批獨立場景 |
