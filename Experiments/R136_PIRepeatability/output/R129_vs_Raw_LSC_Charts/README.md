# Raw與R129：LSC比較圖表

本圖集只含Raw與R129，使用已完成核對的全30次LSC資料。每方法930張、8370圓心；主要位移為9顆圓位移的中位數，名義尺度0.1725μm/px。

PNG為300dpi圖片，SVG可放大編輯。主結果僅限本批20倍樣品及LSC量法。
