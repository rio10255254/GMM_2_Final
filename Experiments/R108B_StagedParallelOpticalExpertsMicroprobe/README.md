# R108B Staged Parallel Optical Experts Microprobe

R108B is a small two-dimensional mechanism experiment.  It is not a formal
model round and cannot be packaged or promoted.  It uses new procedural
continuous scenes only, starts every arm from random initialization, and loads
no old checkpoint or teacher.

The probe compares:

- a direct parallel optical proposal;
- the same proposal trained jointly with an unsupervised output gate;
- the direct proposal frozen first, followed by a separately trained selector
  with a direct counterfactual adoption target.

The fixed action basis separates denoising, edge-profile sharpening,
source-phase texture and low-frequency radiometry.  Existing real microscopy
images are validation-only.
