# R146 — 真實 SEM 外框擬合的中心加淡尾 PSF 對照

**目前狀態：研究版 25 顆 PSF、768 組新配對、8192 次從零訓練、930 張實拍及 8370 顆圓量測均已完成，最終稽核通過。**本輪以使用者指定的 `PSF_20260924_SEM_core_halo_25_RESEARCH.mat` 做獨立實驗，不覆寫 R145、先前已交付 PSF 或正式基準。

## 目的與固定條件

將新研究版 PSF 同時用於 768 組配對影像的模糊製作，以及原 R141 架構的 25 顆模型銀行。沿用 R145 的同一批清楚場景、分組、位移、雜訊、逐場景 PSF 編號、模型架構、訓練種子與 8192 次更新；比較主要看 R146 對 R145，其餘 R143、R140v2、RAW 為固定參照。從零訓練後，用相同 30 趟／930 張實拍和 8370 顆圓量測短步、長距離、直徑與輪廓。

新 PSF 用已知編號的真實 P 類 SEM 外框估計成像模糊；這是合理的光學校準，**SEM 外框與尺寸沒有作神經網路的清晰答案**，清晰答案仍是原合成場景。對同九顆實物的 SEM 尺寸比較屬校準條件下的同樣本檢查，不是獨立絕對尺寸準確度驗證。研究版來源只證明在同九顆實物的留出視角及留出圓柱上，對這批拍攝較能預測外觀，尚非正式採用的系統 PSF。

## 結果

來源 PSF 的留出照片平均誤差 0.001791，優於原 BADS 的 0.002997 和單一高斯的 0.002105；但 R146 的短步 PI 差 **4.313 nm**、短步重拍 **4.459 nm**、直徑重拍 **23.082 nm**、輪廓重拍 **20.371 nm**，均不及 R145 的 **3.990／4.016／21.013／16.001 nm**。起點相對位移重拍波動 R146 **10.369 nm** 低於 R145 **11.216 nm**，但平均絕對差 R146 **18.220 nm** 並未優於 R145 **18.070 nm**。同九顆 SEM 外框點位參照的平均直徑差 R146 **+218.744 nm**、R145 **+207.186 nm**、RAW **+185.182 nm**；既有 Excel 表版本亦分開保留。

生成測試已知 PSF 首選僅 10/206；實拍 930 張全把同一顆排第一。模型原有光學分支的反推位置、尺度與弱作用問題沒有在本輪修正；12 張實拍關閉它時，逐顆直徑最大差僅 0.360 nm。因此來源 PSF 預測變好，沒有轉成這個架構下的短步、直徑或輪廓改善。詳見[完整結果](reports/R146_RESULTS.md)與[原因核對](reports/R146_CAUSAL_AUDIT.md)。研究 PSF 和模型均不自動升級正式用途。

針對「是否真的用新 PSF 製作與訓練」另做完整重算：768 組清楚答案與 R145 逐值相同；692 組被指定新 PSF 卷積，76 組按原設計保留清晰對照；全部 1536 張卷積前影像及加雜訊影像重播完全相同，8192 筆場景順序與從零訓練身分均通過。訓練入口每輪重抽雜訊亦抽查七種場景、三個訓練時段共 21 批逐值吻合。[完整資料與訓練鏈稽核](results/data_training_chain_audit.json)

在全部 8370 顆實拍圓上，R146 雖把邊界做得更窄，固定位置的邊寬重拍起伏卻由 R145 的 0.025 增至 0.090 像素；279/279 組位置與圓都較不穩。這是輪廓重拍退步的直接影像線索，詳見原因核對。

為能直接判斷這次換 PSF 的影響，本輪暫時保留 R145 已發現的模型光學分支缺陷：頻域原點錯位、半解析度尺度及弱作用設定均不修改。因此即使結果改善，也不能直接宣稱模型已學會有效反卷積或逐張選 PSF。完成標準事先寫在[驗證計畫](reports/R146_VALIDATION_PLAN.md)。
