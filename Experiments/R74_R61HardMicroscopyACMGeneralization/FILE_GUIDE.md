# R74：五種困難成像條件，先鎖定難度再看模型

[研究時間線](<../../docs/research/TIMELINE.md>) · [前一輪 R73](<../R73_R61ExpandedSyntheticACMGeneralization/FILE_GUIDE.md>) · [下一輪 R75](<../R75_R61ArchitectureScratchGeneralization/FILE_GUIDE.md>)

**一句話：** R73 的原圖太準了，R74 改做 100 張困難影像：極低對比、照明不均、非對稱模糊與光暈、局部邊界消失、混合困難，各 20 張，每組再平均放入五種形狀。**難度只用原圖校正並凍結，凍結之後才跑 R61。** R61 在照明不均上改善非常大（輪廓重疊 0.707 → 0.982），但局部邊界消失與混合困難兩組沒有改善，整體沒過門檻。

## 結果

**五種困難條件：**

| 條件 | 輪廓重疊率（原圖 → R61） | 平均邊界距離（原圖 → R61） | 兩項都改善 |
|---|---:|---:|---|
| 極低對比 | 0.818 → 0.850 | 10.69 → 9.68 px | 是 |
| 照明不均 | 0.707 → **0.982** | 20.51 → **0.57** px | 是 |
| 非對稱模糊與光暈 | 0.967 → 0.976 | 1.88 → 1.09 px | 是 |
| 局部邊界消失 | 0.788 → 0.753 | 12.35 → 13.83 px | 否 |
| 混合困難 | 0.881 → 0.882 | 7.24 → 7.67 px | 否 |

整體來看，六項指標的中位數都朝改善方向，但改善張數只有 50～63/100，沒有達到每項 60% 且不確定範圍為正的門檻；五種形狀中粗糙邊界一類沒有兩項都改善。

## 讀這些數字要知道的事

1. **天花板已經移除。** 原圖整體輪廓重疊率中位數 0.881，乾淨答案的 ACM 最低重疊率 0.993，評分工具可靠。
2. **流程有防呆：** R61 重建產生之後，執行程式會拒絕再重新產生資料。
3. **改善集中在少數條件。** 照明不均一組的改善遠大於其他組，局部邊界消失一組反而變差；報告沒有再拆解原因，只把結論限定在這五種設計好的干擾。
