# R107A 單張局部邊界幾何設計

## 核心假說

過去「細節變清楚」與「量測位置漂移」互相牴觸，不是物理上必然，而是模型在同一影像殘差中同時改變了邊界中心、過渡寬度、對比與光暈。若把這些量明確拆開，應能縮窄邊界而不搬動位置。

## 局部座標

每個候選邊界點建立兩個方向：

- 法線方向：跨越邊界，用來估計中心、寬度、極性與對比。
- 切線方向：沿著邊界，用來判斷局部一致性、角點、多重邊緣與材質，不直接參與第一階段銳化。

單張輸入先用多尺度方向梯度找到局部法線。沿法線取得一維灰階剖面，擬合單調 edge-spread profile：

- 中心位置 `c`：第一階段固定，不由生成器自由預測。
- 過渡寬度 `w`：允許縮小，但必須保持正值與合理範圍。
- 內外亮度 `a/b`：只作局部輻射校正，不能補償中心錯誤。
- 可靠度 `q`：可精確為零；角點、交叉、低對比、光暈或多重邊緣時拒絕修正。

輸出邊界由固定 `c` 的單調函數形成。這使清晰度主要由 `w` 控制，位置主要由 `c` 控制，兩者不再透過自由殘差互相代償。

## 第一階段分解

1. **Oracle normal**：使用程序真值法線，確認固定中心縮寬本身是否成立。
2. **Estimated normal**：改用影像梯度法線，量化方向估計造成的損失。
3. **Junction rejection**：以方向分散、多峰剖面與低對比判斷拒絕角點／交叉。
4. **Analytic render**：只在可靠 edge band 套用固定中心、寬度受限的單調修正。
5. **Tangential preservation**：切線方向高頻不由 edge operator 生成，防止暗邊與假紋理。

## 不先做的事

- 不預測完整 SDF 或物件拓撲。
- 不加入生成式材質。
- 不使用跨幀或多張影像。
- 不載入 R61、R103、R104 或 R106 權重。
- 不以影像 MAE／PSNR 單獨選方法。

## 反證順序

1. 程序未見形狀：中心、寬度、輪廓距離、光暈。
2. 不同曝光、極性、非對稱 blur、局部 shading。
3. 清楚輸入 identity。
4. 已知次像素位移與位置波動。
5. 完整／分塊一致。
6. 均華環形：中心與半徑不得受傷。
7. SEM 對照：只作鎖定後驗證，不進入訓練或調參。

## 進入完整模型的條件

只有當影像估計法線版本也能顯示：邊界寬度改善、中心與位移不退、光暈不增加、clear 不被修改，才建立 learned parameter estimator。完整模型仍輸出單張、同解析、tile-native 結果；學習器只預測局部參數與可靠度，不直接繪製任意像素殘差。
