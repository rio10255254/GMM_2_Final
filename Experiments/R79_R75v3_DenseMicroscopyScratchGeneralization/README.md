# R75-v3：密集與多尺度顯微形狀的全新訓練

這是一個完全獨立的新實驗。它沿用 R75-v2 的模型結構，但所有可學習權重都從隨機值開始，不載入 R61、V42、R75、R75-v2 或任何教師模型。

## 這次主要補強什麼

舊版對一般形狀已經有不錯能力，但在 5 倍影像的密集小格、細線與不同尺度同時出現時，容易把真實結構當成雜訊。這一版維持總量 5,120 張，將接近一半資料專門分配給 5–24 像素間距的密集排列與多尺度混合場景，並用大量「本來就不該修改」的細結構防止過度重建。

## 最常用的入口

1. `training/train_r75v3.py`：可直接打開，修改最上方設定後按執行。預設訓練 100 輪。
2. `inference/infer_r75v3.py`：訓練完成後的手動重建入口。
3. `tools/prepare_dataset.py`：只建立或檢查資料，不開始訓練。

## 一鍵執行與監看

- 背景訓練：執行 `scripts/start_r75v3_background.ps1`
- 前景訓練：執行 `scripts/start_r75v3_formal_training.ps1`
- 前景監看：執行 `scripts/foreground_r75v3_monitor.ps1`
- 單次查看狀態：執行 `scripts/check_r75v3_status.ps1`

## 正式資料分配

| 類別 | 張數 | 用途 |
|---|---:|---|
| 基礎幾何 | 640 | 保留一般形狀能力 |
| 非圓與細節形狀 | 640 | 保留凹口、窄頸、孔洞與不對稱輪廓 |
| 密集週期排列 | 1,600 | 學會辨認小間距圓點、方格、線條、缺件與間距漸變 |
| 多尺度混合場 | 800 | 同一張圖同時保留多種大小、方向、明暗與局部缺陷 |
| 局部邊界淡化 | 480 | 應付局部消失、光暈、陰影、模糊與雜訊 |
| 不修改／近乎不修改 | 960 | 防止把真實密集結構誤當雜訊或製造假細節 |
| 合計 | 5,120 | 訓練 4,096、驗證 512、內部測試 512 |

同一個原始形狀的全部版本只會落在訓練、驗證或內部測試其中一組，避免先看過答案。

## 資料界線

- 訓練資料只使用程式生成的基礎形狀，不讀取任何真實顯微影像或 SEM 結構。
- 不使用真實樣品的半徑、間距、輪廓或排列。
- 標準答案先以 8 倍大小繪製，再縮回 256×256，減少鋸齒。
- 5×、20×、50×真實影像只在每 5 輪輸出觀察圖，不參與訓練、停止或權重選擇。

訓練完成後仍需通過固定的真實倍率測試與獨立 SEM 形狀比較，才能考慮取代 R61。
