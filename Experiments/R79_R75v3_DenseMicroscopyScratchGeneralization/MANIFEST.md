# 資料夾導覽

| 資料夾 | 內容 |
|---|---|
| `config` | 固定實驗設定與模型完整性記錄 |
| `data` | 純生成訓練資料、三張固定觀察影像與待重建影像 |
| `model` | 與 R75-v2 相同的模型結構及固定解析核心 |
| `training` | 可直接按執行的訓練入口與本實驗專用訓練核心 |
| `inference` | 可直接按執行的重建入口 |
| `scripts` | 資料建立、正式啟動、背景訓練與進度監看 |
| `tools` | 環境檢查、固定觀察影像與準備報告 |
| `tests` | 資料隔離、分組、密集間距、標準答案及檔案完整性檢查 |
| `reports` | 設計理由、測試結果與訓練前檢查 |
| `runs` | 每次訓練過程及每 5 輪的三倍率重建 |
| `weights` | 訓練完成後匯出的權重 |
| `results` | 手動重建輸出 |

R75-v2、R78、R61 與其他舊實驗都在各自資料夾。本實驗不會覆蓋它們的資料、權重或結果。
