# R116 下一輪架構決策

## 一句話結論

R116 不再把「修不修、移多少、變多窄、補多少細節」塞進同一條路徑。
它先產生可量測的幾何底層，再只加入有原圖證據且局部平均為零的細節，
目標是在保留 R109 泛化、位移與分塊能力的同時，減少外部 GMF 所看到的
逐幀輪廓外觀漂移。

## 過去證據如何導向這個設計

### R109 必須保留的能力

- 單張輸入，不依賴特殊拍攝序列。
- 301 張真實影像、六組位移全部通過。
- 5 倍幾乎保持原圖，20 倍與 50 倍才逐步加強。
- R73、R74 困難輪廓明顯改善。
- SEM 暗曝光、最差曝光與周長優於 V42 的部分結果。
- 局部架構與固定 halo，能安全處理大圖。
- 沒有肉眼黑環，原圖以外的新強邊比例很低。

### R109 不能照搬的部分

- 最終影像的低頻改動比例遠高於 V42；外部模板會把外觀變化誤判為位置或縮放。
- `necessity` 實際固定為 1，`support` 也幾乎不隨場景改變，沒有真正完成「何時該修」。
- 寬度與法向位移是逐像素輸出，同一條物理邊界可能出現局部跳動。
- R113 證明固定二維平滑雖可改善 SEM，卻會破壞未見形狀，因此不能直接模糊參數圖。

### R114、R115 留下的限制

- 可用的 bounded profile action 確實存在，問題主要是模型不知道何時、何處、做多少。
- 2D local selector 無法可靠判斷 action 正負收益。
- profile 學習若碰到共享 geometry backbone，會污染原本安全的 base output。
- 新增 200 張針對性資料能加快早期學習，卻沒有提高上限；正式主資料仍應用 R109 原始 5,000 張。
- 沿法線的九點剖面是有效資訊來源，但不應只拿來對 R109 的 action 做 ±15% 微調。

## R116 的根本改動

### 1. 直接建立預測座標系

邊界分支同時預測邊界可信度與局部 signed-distance。法線剖面不再以錯誤的
真值座標訓練、再用另一套預測座標推論；訓練與推論都以模型當下預測的
零交界作取樣中心。這直接處理 R114B/C 的座標錯配。

此外，零位移時採直通梯度：正向輸出仍逐位等於原圖，但不使用會切斷位移
分支學習訊號的硬分支。架構驗證已把「零位移仍可學」列為必要檢查。

### 2. 寬度、位移、細節完全分路

三條作用路徑只共享固定、不可學的局部影像線索，不共享可學 backbone。
寬度訓練不能改變位移特徵，細節訓練也不能改變幾何底層。正式訓練採交替
更新，不做一個同時混合所有目標的總梯度。

寬度與位移都先由同一對程序 source/target 的法線剖面直接量出目標與可信度，
各自接受直接參數監督；最終影像誤差只作共同結果檢查，不能再成為唯一訊號。

### 3. 不再設一個包辦所有事情的 need gate

每條作用路徑直接輸出「作用量」與「該作用量的座標可信度」。中性標籤就是
位移 0、寬度倍率 1、細節係數 0；可信度只負責在資訊不足時降低不可靠作用，
不再重複抑制同一訊號。這避免 R114/R115 的全關閉失敗。

初始作用仍保持很小，但不再把寬度作用量與可信度同時初始化到近乎零。
架構 smoke 會要求四條路徑的梯度不只「存在」，還必須高於可學下限。

最終實作再進一步：初始寬度倍率正向精確等於 1、初始位移精確等於 0，
因此初始輸出逐位等於 Raw；兩者使用直通梯度，不能以精確 identity 為理由
切斷反向學習。

### 4. 只沿輪廓方向維持連續

位置與寬度會沿局部切線收集鄰近值，但權重同時考慮邊界可信度與法線方向。
角點、窄間隙或鄰近另一條邊界時，方向不一致會自動降低互相影響。這不同於
已證明會傷害 R73 的固定二維平滑。

### 5. 幾何錨點先於細節

原圖先依連續的法向位移形成 `geometry anchor`。之後的單調寬度修正只保留
其中的局部高頻部分；低頻亮度仍由幾何對齊後的原圖提供。這吸收 V42 Raw
anchor 的優點，但不把未位移的 Raw 直接混回去破壞幾何。

### 6. 細節只能來自原圖已有的頻帶

細節分支只能調整三個固定局部高頻頻帶的係數，最後再移除局部平均並限制
最大灰階變化。它沒有自由 residual，因此不能從無訊號區域憑空畫出孔洞、
粗糙邊或黑環。

## 為什麼這有機會同時改善自家位移與 GMF

- 自家位移：直接監督預測座標、已知合成位移與對齊後的一致性，讓同一物體
  在不同曝光或噪聲下回到同一幾何位置。
- GMF：外部工具看到的低頻亮度與輪廓底層較穩定，不再直接暴露每張影像不同
  的局部亮度重畫。
- 細節：高頻仍可增強，但來源必須存在於輸入，且不改變局部平均。
- 泛化：形狀動作仍是局部法線座標，不假設圓形或固定 pillar。
- 分塊：所有計算都是固定範圍局部運算，正式輸出一律走一次外框 padding、
  halo、core-only 的 canonical 路徑。

## 訓練策略

1. 邊界與預測座標。
2. 寬度與位移分開交替學習。
3. 同一潛在形狀的多個合成觀測共同約束位移與曝光一致性。
4. 完全凍結幾何後，才訓練 evidence-only detail。
5. 最後只交替做低學習率校準，不允許一次總梯度同時改全部路徑。

訓練可以同時看到同一程序形狀的多個合成觀測，但正式推論仍只輸入一張。
真實 SEM、HS100MG、均華與外部 GMF 影像不進訓練答案。

## 在完整訓練前必做的驗證

### 無訓練外部 GMF 反事實

1. R109 關閉 normal shift。
2. Raw 低頻錨點加 0.5 倍 R109 高頻殘差。
3. geometry anchor 加 0.5 倍局部零平均細節。

這三者先跑相同 101 張、相同模板、相同 Flow。內部 surrogate 已證明不能替
外部 GMF 排名，因此不允許用 surrogate 選最後方向。

### 架構檢查

- 初始輸出接近 Raw，所有作用有限且輸出不越界。
- 四組參數彼此獨立、沒有漏參數或共享污染。
- 細節加入後相對 geometry anchor 的低頻殘差接近零。
- 不含 GroupNorm、BatchNorm、全域 pooling 或 FFT。
- 兩種 canonical tile grid 的共同區域一致。
- 整數平移後的共同內部區域保持相同答案。

## 模型升格條件

不做單一綜合分數，也不因為視覺更銳利就升格。順序是：

1. 鎖定 LSC 位移的步距波動、同柱重複性與尾端誤差真正改善。
2. SEM 一般／暗曝光與 R73/R74 每一類都沒有用平均掩蓋失敗。
3. identity、黑環、假邊與 tile parity 安全。
4. 外部 GMF 至少不再出現 R109 對 V42 的大幅落差；企業交付時必須正式通過。
