[355] heading 1 理論背景

[356]  本章由純量繞射與傅立葉光學出發，說明點擴散函數、像差與系統解析能力的理論基礎，並介紹本研究使用的U-Net架構與BADS最佳化工具。後半部聚焦於平移等變性，說明理想卷積何以保留位移關係，以及下取樣、上取樣、內插與邊界處理如何引入定位誤差，作為第四章重建模型與位移一致性設計的理論基礎。

[357] heading 2 3.1 向量光學與純量光學 [6]

[358]  在描述顯微成像時，光場可採向量形式或純量近似加以處理；前者保留偏振等向量特性，後者則在特定條件下以純量波動模型近似，得以大幅簡化推導與計算。

[359] heading 3 3.1.1 格林定理與克希何夫積分定理

[360]  令 U(P)與 G(P)為任意兩個複數函數，並設 S為包覆體積 V的封閉曲面。若 U(P)與 G(P)的一、二階導數在 S上皆為單一值且保持連續，則可利用格林定理（Green’s theorem）將體積積分與曲面積分建立對應關係，其形式可寫為

[361] TABLE 5
VU∇2G-G∇2U dv=SU∂G∂n-G∂U∂n ds | (3-1)

[362]  其中 ∂∂n表示沿曲面法向量方向之偏微分。 

[363]  在此基礎上，克希何夫積分定理（Kirchhoff integral theorem）指出：齊次波動方程在任意觀察點的解，得以由包圍該點之任意封閉曲面上的場值，以及其一階（法向）導數共同決定。具體而言，令觀察點為 P0，並取一封閉曲面 S使其包覆 P0，則P0處之擾動可表達為曲面 S上擾動分佈的積分表示。為完成該表示，通常選取以 P0為中心、單位振幅之球面波作為輔助函數，藉此把觀察點的場量回寫成曲面上的場量與其法向導數之組合。 

[364]  

IMAGES ['media/image6.png']

[365] Figure Caption 圖 3-1 格林定理欲進行面積分示意圖與各參數 [6]

[366]  因此，若選取以 P0為中心展開之單位振幅球面波作為輔助函數，則其在任意空間點 P1的形式可寫為

[367] TABLE 6
G(P1)=eikr01r01 | (3-2)

[368]  其中 r01表示由 P0至 P1的直線距離，而 r01則對應於 P0→P1的位移向量。為使格林定理得以嚴格成立，G 及其一階、二階偏導數需在被積分之體積內保持連續；然而式 3-2在 P0位置存在不連續（奇異）行為。基於此，於進行擾動推導前，先以 P0為球心劃定半徑為 ϵ的小球面 Sϵ以排除該奇異點，並令格林定理施用於原封閉曲面 S與 Sϵ之間所夾出的體積 V'。此時，積分邊界可視為由兩曲面構成之複合封閉曲面 S'，其關係為

[369] TABLE 7
S'=S+Sϵ. | (3-3)

[370]  在此 V'的封閉區域內，輔助擾動函數 G需滿足亥姆霍茲方程（Helmholtz equation），亦即

[371] TABLE 8
(∇2+k2)G=0. | (3-4)

[372]  將滿足亥姆霍茲方程之 U與 G代入格林恆等式（原格林定理之形式）後，可得

[373] TABLE 9
V'U∇2G-G∇2U dv=-V'UGk2-GUk2 dv=0. | (3-5)

[374]  進一步整理上式，即可化為僅含邊界項之曲面積分表示

[375] TABLE 10
S'U∂G∂n-G∂U∂n ds=0. | (3-6a)

[376]  由於先前已得到在複合封閉曲面 S'=S+Sϵ上之邊界積分為零，因此可將曲面積分拆解為外曲面 S與內小球面 Sϵ兩部分，並將內外曲面的貢獻移項整理，得到

[377] TABLE 11
SU∂G∂n-G∂U∂n ds=-SϵU∂G∂n-G∂U∂n ds | (3-6b)

[378]  接著需明確化輔助函數 G及其沿法向之導數形式。對曲面上任意點 P1，球面波輔助函數可寫為

[379] TABLE 12
G(P1)=eikr01r01 | (3-7a)

[380]  其法向一階偏導可表示為

[381] TABLE 13
∂G(P1)∂n=cos⁡(n,r01)ik1r01eikr01r01 | (3-7b)

[382]  其中 cos⁡(n,r01)為法向量 n與位移向量 r01之夾角餘弦。特別地，若 P1位於內小球面 Sϵ上，因 Sϵ作為 V'的內邊界，其外法向方向與 r01相反，故 cos⁡(n,r01)=-1，並可令 r01=ϵ。此時式 3-7可化為

[383] TABLE 14
G(P1)=eikϵϵ,∂G(P1)∂n=eikϵϵ1ϵik | (3-8)

[384]  當 ϵ取為相對極小值並令 ϵ→0時，內球面 Sϵ上的積分可用 P0附近之近似值進行評估；由於 Sϵ面積為 4πϵ2，可得

[385] TABLE 15
lim⁡ϵ→0SϵU∂G∂n-G∂U∂n ds =lim⁡ϵ→04πϵ2U(P0)eikϵϵ 1ϵik-∂U(P0)∂neikϵϵ=4πU(P0) | (3-9)

[386]  將式 3-9代回式 3-6b，即可把觀察點 P0的場量以外封閉曲面 S上之邊界值表達為

[387] TABLE 16
U(P0)=14πS∂U∂neikr01r01-U∂∂neikr01r01 ds | (3-10)

[388]  式 3-10即為亥姆霍茲–克希何夫積分定理（Helmholtz–Kirchhoff integral theorem）。其核心意義在於：只要掌握任意封閉曲面上之場值與其法向導數，便能重建曲面所包覆區域內任意點（例如 P0）之場分佈；因此，該定理在純量繞射理論之後續推導（例如針孔繞射與成像模型建立）中扮演基礎性的角色。

[389] heading 3 3.1.2 經平面繞射的克希何夫積分與索默菲德輻射條件

[390]  在本小節中，將進一步應用上述積分表示以計算光通過針孔後任意觀察點 P0的光場。令 S1為緊貼針孔之後的平面，並取 S2為以 P0為中心、半徑為 R的球面，則封閉曲面 S可由 S1與 S2組成。

[391]

[392] Figure Caption 圖 3-2 平面繞射的克希何夫積分示意圖 [6]

[393]  在前述幾何設定與邊界構造成立的前提下，可直接將條件代入亥姆霍茲–克希何夫積分定理，將觀察點 P0的場表示為由封閉曲面 S1+S2所決定之邊界積分形式：

[394] TABLE 17
U(P0)=14πS1+S2G∂U∂n-U∂G∂nds | (3-11)

[395]  其中選用之輔助函數為球面波型式

[396] TABLE 18
G=eikr01r01 | (3-12)

[397]  接著考慮球面 S2的半徑 R逐步放大時的極限行為。當 R→∞時，幾何上有 r01→R，因此式 3-12在遠場可改寫為

[398] TABLE 19
G=eikRR,∂G∂n=ik1ReikRR≈ikG | (3-13)

[399]  將此遠場近似回代至式 3-11，可把 S2上的積分項整理為以 G乘上括號中的輻射型組合量：

[400] TABLE 20
U(P0)=14πSG∂U∂n-U(ikG)ds=ΩG∂U∂nikUR2 dω | (3-14)

[401]  其中 Ω表示點 P1相對於 P0在球面 S2上所對應之立體角，dω 為立體角微元。由於在 S2上 ∣RG∣的量級受限，故當 R→∞時，沿球面 S2的面積分可收斂至零，因而導出一個必須滿足的遠場條件：

[402] TABLE 21
lim⁡R→∞R∂U∂nikU=0 | (3-15)

[403]  式 3-15即索默菲德輻射條件（Sommerfeld radiation condition）。其物理意涵在於：當擾動場 U至少以不慢於發散球面波的衰減速率趨近於零時，上述極限成立，從而保證在無窮遠邊界上僅保留向外傳播的發散波分量；若存在入射波成分，則在 R→∞的極限下，S2 上的積分未必消失，將破壞上述收斂推導。

[404] heading 3 3.1.3 菲涅耳–克希何夫繞射（Fresnel–Kirchhoff diffraction）

[405]  在針孔繞射的典型成像幾何中，觀察點 P0與孔徑之距離 r01往往遠大於波長（可達數十至數百倍波長量級），因此可視為 k≫1/r01。在此近似下，式 3-7b中的 ik1r01可由 ik主導，故球面波輔助函數的法向導數可簡化為

[406] TABLE 22
∂G(P1)∂n=cos⁡(n,r01)ik1r01eikr01r01≈ikcos⁡(n,r01)eikr01r01 | (3-16)

[407]  再將式 3-4與式 3-16併入克希何夫邊界條件（Kirchhoff boundary condition），即可得到觀察點 P0的場之積分表示：

[408] TABLE 23
U(P0)=14πΣeikr01r01∂U∂n-ikUcos⁡(n,r01)ds | (3-17)

[409]  其中 Σ表示孔徑所在之積分曲面。若進一步假設針孔之照明可視為由點光源 P2發出的球面波，則孔徑平面上任意點 P1的入射場可寫為

[410] TABLE 24
U(P1)=Aeikr21r21 | (3-18)

[411]  當 r21同樣相對波長足夠大時，可對傳播項作相同型式之遠場處理，並整理得

[412] TABLE 25
U(P0)=AjλΣeik(r21+r01)r21r01cos⁡(n,r01)-cos⁡(n,r21)2ds | (3-19)

[413]  式 3-19即菲涅耳–克希何夫繞射公式（Fresnel–Kirchhoff diffraction formula），其推導假設對應於照明來自單一點光源的情形，因此適用範圍亦以此類單點球面波照明為主。

[416] heading 3 3.1.4 惠更斯–菲涅耳原理

[417]  在純量繞射框架下，觀察點 P0的光場可被寫成由遮蔽屏幕（或孔徑平面）上整體入射場及其法向導數所決定的邊界積分；亦即，只要掌握曲面 S1上的 U與 ∂U/∂n，便能表達 U(P0)：

[418] TABLE 26
U(P0)=14πS1G∂U∂n-U∂G∂nds | (3-20)

[419]  使式 3-20成立所仰賴的前提可歸納為：其一，純量理論（scalar theory）在此情境下可用；其二，U 與 G皆為齊次純量波函數；其三，解需滿足索默菲德輻射條件（Sommerfeld radiation condition），以確保遠場邊界僅保留向外傳播之發散波成分。

[420]  然而，克希何夫（Kirchhoff）理論在遮蔽屏幕上往往需要同時對 U與 ∂U/∂n施加邊界條件，這在數學上容易導致不一致。為化解此問題，可考慮對克希何夫理論中所採用的格林函數 G作「可控的修正」：在不破壞先前推導步驟有效性的同時，額外令 G或其法向導數 ∂G/∂n在特定邊界上為零。如此一來，便不必再於整個 S1上同時指定 U與 ∂U/∂n，從而消除克希何夫模型中的不一致性。Sommerfeld 指出，滿足此類要求的格林函數確實可以構造。

[421]  Sommerfeld 的作法可用「鏡像點光源」來描述：除了位於 P0的點光源外，再引入一個位於遮蔽屏幕鏡像位置的點光源 P0。令兩者波長同為 λ，且相位差為 180∘，則可得到一個差分型格林函數

[422] TABLE 27
G-(P1)=eikr01r01-eikr01∼r01∼ | (3-21)

[423]  並導出對應的光場表示式

[424] TABLE 28
UI(P0)=-14πΣU∂G-∂n ds | (3-22)

[425]  此結果即第一類瑞利–索默菲德解（First Rayleigh–Sommerfeld solution）（示意如圖 3-4）。

[426]  

IMAGES ['media/image9.png']

[427] Figure Caption 圖 3-4 瑞利–索默菲德繞射示意圖（依據[6]重繪）

[428]  在此設定下，G- 的法向導數可寫為

[429] TABLE 29
∂G-(P1)∂n=cos⁡(n,r01)ik1r01eikr01r01-cos⁡(n,r01∼)ik1r01∼eikr01∼r01∼ | (3-23)

[430]  若 P1∈S1，且 P0與 P0到 P1的距離相同、兩者在水平方向的分量互為相反，同時滿足 r01≫λ的條件，則式 3-23可近似化簡為

[431] TABLE 30
∂G-(P1)∂n=2ikcos⁡(n,r01)eikr01r01 | (3-24)

[432]  由式 3-24可看出，此結果等同於克希何夫格林函數之正向導數的兩倍，因此第一類瑞利–索默菲德解可改以克希何夫推導形式重寫為

[433] TABLE 31
UI(P0)=-12πΣU∂G∂n ds | (3-25)

[434]  同理，若令兩點光源相位差為 0∘，則可構造加總型格林函數

[435] TABLE 32
G+(P1)=eikr01r01+eikr01∼r01∼ | (3-26)

[436]  並得到第二類瑞利–索默菲德解（Second Rayleigh–Sommerfeld solution）：

[437] TABLE 33
UII(P0)=14πΣ∂U∂nG+ ds | (3-27)

[438]  在相同近似與假設下，亦可用克希何夫格林函數寫成

[439] TABLE 34
UII(P0)=12πΣ∂U∂nG+ ds | (3-28)

[440]  進一步地，將第一類瑞利–索默菲德解的光場形式（式 3-25）帶回式 3-20的結構，可整理得到觀察點 P0的光場為

[441] TABLE 35
U(P0)=1iλS1U(P1)eikr01r01cos⁡(n,r01) ds | (3-29)

[442]  式 3-29即惠更斯–菲涅耳原理（Huygens–Fresnel principle）。若將其用於光場傳遞並改寫為直角座標系（Rectangular coordinates），同時令cosn,r01=zr01,

[443]  則可得到

[444] TABLE 36
U(x,y)=ziλΣU(ξ,η)eikr01r012 dξdη | (3-30)

[445]  其中

[446] TABLE 37
r01=z2+(x-ξ)2+(y-η)2 | (3-31)

[447]  且 ξη平面與 xy平面彼此平行，兩平面之法向間距為 z。

[450] heading 3 3.1.5 菲涅耳繞射與夫朗何斐繞射

[451]  為了將惠更斯–菲涅耳原理之傳遞積分化為更易分析與計算的形式，可先從幾何距離 r01的近似著手。對式 3-31中的 r01進行二項式展開，並捨去二次以上之高次項，則可將距離項改寫為

[452] TABLE 38
r01=z12+x-ξz2+y-ηz2≈z112x-ξz212y-ηz2 | (3-32)

[453]  將式 3-32代回式 3-30後，觀察平面上的場可整理為

[454] TABLE 39
U(x,y)=eikziλz-∞∞U(ξ,η)exp⁡ik2z((x-ξ)2+(y-η)2)dξdη | (3-33)

[455]  式 3-33即菲涅耳繞射（Fresnel diffraction），亦常稱為近場繞射；其關鍵在於距離展開時忽略了更高次項，因此必須限制被捨去項所造成的最大相位誤差。為避免近似使結果顯著偏離真實解，通常要求高次項引入之最大相位變化小於 1弧度，亦即

[456] TABLE 40
kz8x-ξz2y-ηz22≪1rad | (3-34a)

[457]  或等價地可寫為

[458] TABLE 41
z3≫π4λ[(x-ξ)2+(y-η)2]2 | (3-34b)

[459]  由式 3-33的結構可直接看出，其可被視為輸入場 U(ξ,η)與一個固定核函數之卷積，因此亦可改寫為

[460] TABLE 42
U(x,y)=-∞∞U(ξ,η) h(x-ξ,y-η) dξdη | (3-35)

[461]  其中對應的卷積核為

[462] TABLE 43
h(x,y)=eikziλzexp⁡ik2z(x2+y2) | (3-36)

[463]  另一方面，式 3-33亦可透過重排相位項而轉寫成傅立葉轉換（Fourier transform）型式：

[464] TABLE 44
U(x,y)=eikziλzexpik2z(x2+y2)-∞∞[U(ξ,η)expik2z(ξ2+η2)]exp-ikλz(xξ+yη)dξdη | (3-37)

[465]  若在菲涅耳繞射的基礎上再引入更強的遠場假設，使得二次相位項相對於主相位可忽略，即

[466] TABLE 45
z≫k(ξ2+η2)max2 | (3-38)

[467]  則式 3-37中與 ξ2η2相關之相位因子可省略，進而得到

[468] TABLE 46
U(x,y)=eikziλzexpik2z(x2+y2)-∞∞U(ξ,η)exp -i2πλz(xξ+yη)dξdη | (3-39)

[469]  式 3-39即夫朗何斐繞射（Fraunhofer diffraction），亦即遠場繞射之標準結果。

[471] heading 3 3.2.1 薄透鏡理論

[472]  考慮一均勻圓形透鏡（如圖 3-6），其在主軸處具有最大厚度 t0，而在橫向座標 xy位置的局部厚度記為 t(x,y)。若以波數 k與透鏡折射率 n描述光在介質與空氣中的傳遞，則光束穿越該透鏡所引入的相位延遲可寫為

[473] TABLE 47
ϕ(x,y)=knt(x,y)+k[t0-t(x,y)] | (3-40)

[475] TABLE 48
ϕ(x,y)=eikt0eik(n-1)t(x,y) | (3-41)

[519] heading 3 3.2.2 漢克爾轉換

[520]  當二維函數具備徑向對稱（radial symmetry）時，其在極座標表示下僅依賴半徑而與角度無關，故可採用傅立葉–貝索轉換（Fourier–Bessel transform），亦即漢克爾轉換（Hankel transform）以簡化分析。若函數 f(x,y)具有圓對稱性，則可寫為

[521] TABLE 65
f(r,θ)=fr(r) | (3-57)

[522]  其二維傅立葉轉換為

[523] TABLE 66
F(fx,fy)=-∞∞f(x,y) e-i2π(fxx+fyy) dxdy | (3-58)

[524]  將空間域與頻域同時改寫至極座標：

[525] TABLE 67
r=x2+y2,x=rcos⁡θ | (3-59a)
θ=arctan⁡yx,y=rsin⁡θ | (3-59b)
ρ=fx2+fy2,fx=ρcos⁡ϕ | (3-59c)
ϕ=arctan⁡fyfx,fy=ρsin⁡ϕ | (3-59d)

[526]  則可把傅立葉轉換寫成

[527] TABLE 68
F(ρ,ϕ)=0∞rfr(r)02πe-i2πrρcos⁡(θ-ϕ) dθdr | (3-60)

[528]  又第一類零階貝索函數（Bessel function of the first kind, zero order）可定義為

[529] TABLE 69
J0(a)=12π02πe-iacos⁡(θ-ϕ) dθ | (3-61)

[530]  因此將式 3-61代回式 3-60，即可得到

[531] TABLE 70
F(ρ,ϕ)=2π0∞rfr(r) J0(2πrρ) dr | (3-62)
