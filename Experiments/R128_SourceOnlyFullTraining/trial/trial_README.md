# 單一模型試用入口

> 這份原本放在專案根目錄，2026-10-28 重整時移到這裡。它是同資料夾 [README.md](README.md) 較早的一份，少了最後一段結構檢查；以 README.md 為準。

這個入口固定使用目前唯一保留的第四個版本，不需要選模型，也不會重新訓練。用途是觀察正常拍攝條件下的修復效果；尚不是可直接信任量測數值的正式模型。

目前接受原始8位元灰階BMP或PNG光學顯微照片。請使用完整影像，並先確認曝光正常；自動判断照片是否过暗的功能尚未建立。SEM影像留作對照，不是此入口已驗證的輸入用途。

在PowerShell執行以下一行，將兩個範例位置換成原圖與新的結果資料夾：

    & 'C:\Users\Rio\anaconda3\python.exe' 'Experiments/R128_SourceOnlyFullTraining/trial/restore.py' --input 'D:\你的照片\原圖.bmp' --output-dir 'D:\你的照片\本次修復結果'

結果資料夾已存在時，程式會停止，避免覆寫先前結果。資料夾內：

- reconstruction.png：可直接查看的修復照片。
- output_float.npz：保留較完整數值的研究輸出。
- run_record.json：原圖、模型、結果與使用範圍紀錄。

原圖不會被修改。輸出維持原尺寸；照片外圍缺少足夠資訊的部分按原定方式保留原圖。

相近三張亮度照片的尺寸比對都改善，但它們是同一批36個物件的重複拍攝，不代表其他正常照片或不同樣品都已通過。原本清楚的控制影像被改動、細節保真與量測依據仍有待驗收。正式使用範圍與結果見 [正常拍攝應用範圍](../reports/R128_APPLICATION_SCOPE.md)。
