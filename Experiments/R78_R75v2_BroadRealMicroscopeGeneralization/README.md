# R78 真實顯微影像廣泛泛化驗證

這個資料夾回答兩個不同問題：

1. 重建後的形狀準不準：沿用 36 顆柱、12 個曝光與 SEM 真實外框，以 ACM 取得輪廓後比較。
2. 換倍率、位置與位移量後是否仍穩定：使用 301 張真實拍攝影像，涵蓋 5x、20x、50x，以及 0.5 µm、1.0 µm 位移。

主要比較固定為 Raw、R61v16、R75-v2 第 100 輪。影像、區域、相鄰配對與排除規則都在看 R75-v2 新輸出前鎖定。追加的 5 倍大區塊測試是在主要結果發現異常後才做，報告中明確標為追加確認，不和原先門檻混在一起。

## 現在的結論

- R61 與 R75-v2 在六組位移保持檢查都通過。
- R75-v2 在 20x、50x 有競爭力，但原本 512 像素重建區塊會讓全部 100 張 5x 影像遺失大量細節。
- 改成 1024 像素區塊可大幅減少方塊狀異常，仍只能保留約三分之二細節。
- SEM／ACM 的主要外框接近 R61，但細小非圓形細節仍未過關。
- 因此 R61 仍是目前廣泛場景基準，R75-v2 暫列 20x／50x 候選。

## 資料夾角色

- `config`：事先固定的主要規則，以及事後明確標記的 5 倍追加確認規則。
- `inputs`：301 張原圖的鎖定入口；使用硬連結，不另外複製一份影像內容。
- `scripts`：完整重建、比較、5 倍追加確認與切圖大小檢查。
- `results/reconstructions`：R75-v2 對 301 張影像的完整重建結果。
- `results/tables`：每個固定區域的原始數字與彙整表。
- `results/figures`：位移、SEM 輪廓、異常警訊與固定影像對照圖。
- `reports`：可直接閱讀的繁體中文結論。
- `tests`：交付前自動核對張數、配對、數字重現、結論與圖檔。

## 手動重跑

在 PowerShell 進入這個資料夾後執行：

```powershell
.\run_validation.ps1 -Stage Test
```

這會只檢查目前成果。要重跑主要分析可使用 `-Stage Primary`；完整重跑使用 `-Stage All`。
