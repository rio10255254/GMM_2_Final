# R132：原圖保留帶是不是太寬

[研究時間線](<../../docs/research/TIMELINE.md>) · [起因 R131](<../R131_RecurrentStepValidation/FILE_GUIDE.md>) · [被測的 R129](<../R129_OpticalPriorHybrid/FILE_GUIDE.md>) · [下一輪 R133](<../R133_SizeMechanismDiagnosis/FILE_GUIDE.md>)

**一句話：** R129 最後會在距影像邊界 80 px 內保留原圖、再用 16 px 過渡。2026-09-14 固定同一權重與四次修正，只改這個保留帶：80、64、32、16 px 與完全不保留。結論是 80 px 太寬，明顯犧牲外圍柱的形狀；改成 16 px 後細形狀差距減少約一半，但尺寸差距反而變大。縮小保護帶讓模型本身的尺寸偏大更完整地顯露出來。

## 結果

**SEM（36 柱，nm）：**

| 保留寬度 | 細形狀差距 | 形狀相關 | 非圓起伏差距 | 尺寸差距 |
|---:|---:|---:|---:|---:|
| 80 px | 16.40 | 0.692 | 62.65 | 96.38 |
| 64 px | 14.08 | 0.741 | 44.19 | 97.74 |
| 32 px | 8.68 | 0.889 | 11.27 | 101.00 |
| **16 px** | **8.41** | **0.889** | **9.27** | 102.23 |
| 0 | 8.49 | 0.889 | 8.87 | 102.18 |

中間 16 顆在五種設定下完全不變；變化全部在外圍 20 顆：20/20 顆細形狀改善，同時 20/20 顆尺寸差距增加。

**位移（固定 120 對）：** 80→16 px，步距波動 6.991→6.929 nm，柱間不一致 4.204→3.808 nm。完整 194 對的橫向偏移則從 7.974 增加到 8.069 nm，不是每項都更好。

## 讀這些數字要知道的事

1. **大範圍混回原圖會讓尺寸數字變小**，但那不代表模型學會了正確尺寸。報告只描述數值效果，不推定原設計有掩飾的意圖。
2. **16 px 不是經未知樣品確認的最佳值。** 它跟完全不保留的表現接近，又留下最外側一點保護，所以當作有限範圍的研究選項。
3. **裁切測試：** 同一顆中央柱、量測窗口外不留額外內容時，保護前輸出與完整視野的平均差最多約 0.19 灰階；多留 16 px 就降到 0.005。80 px 保留在窄邊距下反而讓同一顆的細形狀差距跳到 21.3 nm。這只有一顆柱、三個曝光。
4. **舊比較用的是 80 px 規則**（R131、R130 乾淨 V42 對照），不能把 16 px 的 R129 直接插進舊表宣稱勝過其他模型。
