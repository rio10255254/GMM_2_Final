# R94：按成像順序分工

R93 的細節、輪廓、保持原圖與位移目標會互相牽制。R94 把感測雜訊、亮度、局部對比衰減、對稱邊界與材質紋理分開學，另以兩套獨立控制判斷是否需要修正、原圖是否仍有足夠證據。各分支有自己的可學參數，使用固定局部量測與幾何輔助條件；邊界由對稱濾波組成，紋理有幅度限制。

seed 940041；2,303,717 參數。計畫 48 輪，完整保存 1–8 輪；第 9 輪已進入計算，但在提交該輪之前由記憶體估算保護停止，沒有第 9 輪模型。

停止原因是當時保護程式估算剩餘 -0.48 GiB，不能把這個估算寫成實測顯卡剩餘量。R95 前置診斷另發現需求目標的微小常數底值、過度關閉的控制、早期平均權重及快取重複計算等問題；訓練失敗與方法機制分別記錄。早期預檢／空的正式啟動目錄及失敗也完整保存。
