# R45 分族邊界校正模組

## 目的

R45 用來驗證一件事：能不能維持「單一模型入口」，但在模型內部加入很小的分族校正模組，把 R44 之後分散在不同模型上的能力收回來。

這一版不是要正式升級模型，而是先回答：

- 凍結目前最穩的 R44B from R42 主模型後，小模組能不能改善大區塊與混合場景邊界。
- 非目標類型是否可以完全不被改動。
- 位移能力是否能守住。

## 設計

- 主模型：R44B from R42，保持凍結。
- 小模組：只在 `large_regions` 與 `mixed_fields` 啟動。
- 對外仍是一個重建入口；內部依資料族群決定是否套用校正。
- 訓練資料：R44 motion train 中的大區塊與混合場景。
- 驗證資料：R44 motion_val_unseen 七類全部重建與評分。

## 初步門檻

- 大區塊與混合場景合併形狀錯誤需比 R44B from R42 改善至少 3%。
- 整體位移誤差不可比 R44B from R42 退步超過 10%。
- 未達成則判定為研究負結果，不進一步做外部 GMF。

## 結論

第一版輸出端小校正模組沒有比 R44B from R42 更好。位移幾乎守住，但目標形狀分數沒有改善；縮小校正強度後仍無法通過門檻。完整紀錄見 `reports/R45_RESULTS.md`。

R45B 後續診斷確認：能力分散是真的，逐張 oracle 可把大區塊/混合形狀錯誤從 `0.3384` 降到 `0.2253`，但固定分族 oracle 只能到 `0.2968`，而且多數老師在邊界像素殘差方向上不乾淨。因此下一步不應再做輸出端校正或全圖蒸餾，應改成中間特徵層小分支與局部選擇器。
