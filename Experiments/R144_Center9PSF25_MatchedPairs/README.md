# R144 — 新拍攝中心九顆 PSF 配對資料與完整訓練

**狀態：中止並保留。** 使用者最初指定的 MAT 在本輪開始後，被原 PSF 校準流程移到 `diagnostics_prior_orientation/`，並按修正後的 SEM 圓柱方向重新擬合。R144 用的是搬移前的檔案；在第 160 次更新停止，最後完整保存點是第 128 次。它不是可用的訓練結果，也沒有進行 930 張驗證。精確來源、步數和中止原因在 `runs/formal_8192/ABORTED_SOURCE_SUPERSEDED.json`。此包只保留為來源沿革，後續應另用修正後正式 PSF 建立新一輪。

## 目的

依使用者提供的 `PSF_20260924_center9_25_normalized.mat`，同時替換訓練配對的模糊來源與模型內的 25 顆 PSF，從零完整訓練，沿用既有 30 趟／930 張實拍方法驗證位移、輪廓、尺寸與 PSF 選擇。

## 設計與來源

- 自包含研究實驗。新 MAT 的 5×5 核依拍攝列優先順序編成 0–24；每顆 101×101、總和為 1。來源 MAT、25 張原拍攝及擬合檢查保留原處；本包持有相同數值的 NPZ 及 SHA-256 來源鎖。
- MAT 標示 20×、物面每像素 0.1725 µm，與本次量測設定相符；擬合亮度係數與純 PSF 形狀分開，配對卷積只使用正規化核。
- 使用與 R143 相同的 512／128／128 個清楚母場景、位移、目標、噪聲方式與每一場景的 PSF 編號，保留 52／12／12 個無模糊控制。每對影像共用一顆。新資料只因 25 顆核替換而改變。
- 模型程式、四次共享修正、逐張選四顆、訓練初始種子及 8192 次更新規格與 R143 一樣，從零訓練。R143 的已訓練權重不載入；舊資料、模型、930 張結果全部保留。
- 這批 PSF 使用已知的九顆 SEM 直徑來校準系統成像模糊，這是合理的光學校準。神經網路的訓練答案仍是合成場景的清楚影像，沒有將 SEM 直徑當作訓練標籤。之後若拿同九顆、同一張 SEM 表檢查尺寸，應稱為**校準所用參照的同樣本對照**，不是獨立尺寸準確度驗證。PI 位移結果與此尺寸參照分開判讀。
- 為了直接比較新舊 PSF 銀行，R143 的模型光學分支仍在半解析度特徵上使用 101×101 核；資料製作在原尺寸影像使用 101×101 核。此物理尺度差異保留作本輪限制，不把本輪說成完全精確的局部光學反演。

## 操作與結果

`calibration/BANK_LOCK.json` 記錄來源與順序。`data/manifest.json` 記錄 768 個新配對。`scripts/preflight.py` 對照 R143 的清楚答案、分組、PSF 分配和程式身分。完整訓練由 `scripts/launch_r144.py` 啟動，完成後以 `scripts/run_evaluation.py` 驗證。單張推論入口為 `infer.py`。結果與限制見 `reports/R144_RESULTS.md`，驗證項目事先寫在 `reports/R144_VALIDATION_PLAN.md`。

`results/reconstruction/` 連至 H 槽保存完整浮點實拍重建；程式、資料、權重、量測與報告留在本包 D 槽。獨立來源與保留規則見 `MANIFEST.md`。
