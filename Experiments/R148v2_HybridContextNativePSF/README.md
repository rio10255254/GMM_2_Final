# R148v2 — 多尺度脈絡與原尺寸邊界分工

## 假說

保留一次多尺度脈絡分析，但不讓它直接輸出銳利邊界；再由三個職責獨立、作用範圍受控的原尺寸階段完成位置與邊界，可同時避免R148反覆大範圍依賴及R147的縮圖相位問題。

## 設計

- 多尺度編碼／解碼只運行一次，產生低強度脈絡特徵，不直接加到影像。
- 三個原尺寸階段各有自己的參數，不共享同一個完整網路；每階段半徑20像素。
- PSF提示只從輸入照片計算一次，不在三階段反覆擴大依賴範圍；最後保留小權重成像一致性。
- 使用完整384像素訓練，中央96像素接受影像、梯度、跨外觀位置及已知材料邊界要求。
- 邊界答案來自獨立生成幾何的有號距離近似，模型仍須透過輸出影像的亮暗梯度接受量測，不設另一個幾何答案頭。

共享R148已核對的3072視圖資料，不複製、不修改。SEM、PI與實拍仍不作訓練答案。

## 狀態

完整依賴範圍、生成邊界、兩個起點各512次匹配短測及學習後位置門檻均通過。混合版平均開發誤差比純原尺寸低1.05%。正式8192次固定混合版正在背景訓練；第128次第一個保存點已落盤並核對雜湊，仍須第8192次與完整實拍驗證才有正式模型。[實作與短測](reports/R148v2_IMPLEMENTATION.md)
