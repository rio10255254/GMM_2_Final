# 資料夾導覽

| 資料夾 | 內容 |
|---|---|
| `config` | 固定的實驗設定與模型架構指紋 |
| `data` | 訓練資料、九宮格觀察影像與待重建影像 |
| `model` | R75／R61 相同模型架構與固定解析核心 |
| `training` | 可直接按執行的訓練入口與固定訓練核心 |
| `inference` | 可直接按執行的重建入口 |
| `scripts` | 自動建立資料、檢查、前景或背景啟動 |
| `tools` | 日常資料準備與環境檢查 |
| `tests` | 資料隔離、分組、曝光、標準答案與檔案完整性檢查 |
| `reports` | 設計理由、資料檢查結果與圖像預覽 |
| `runs` | 每次訓練的完整過程與每 5 epoch 九宮格重建 |
| `weights` | 訓練完成後匯出的權重 |
| `results` | 手動重建輸出 |

舊 R75 位於另一個資料夾，本實驗不會覆蓋舊資料與權重。
