# R75-v2：多場景純合成重新訓練

這是一個與舊 R75 完全分開的實驗資料夾。模型架構維持 R75／R61 相同版本，權重從隨機值開始，不載入 R61、V42、舊 R75 或任何教師模型。

## 最常用的三個入口

1. `training/train_r75v2.py`
   - 日常手動訓練入口。
   - 可以直接在編輯器打開，修改最上方設定後按執行。
   - 預設為 100 epoch、每 5 epoch 重建一次固定九宮格影像。

2. `inference/infer_r75v2.py`
   - 訓練完成後的手動重建入口。
   - 把影像放進 `data/inference_input`，直接按執行。

3. `tools/prepare_dataset.py`
   - 只建立或檢查資料，不開始訓練。
   - 預設正式資料為 5,120 張。

## 一鍵執行

- 前景執行：在 PowerShell 執行 `scripts/start_r75v2_formal_training.ps1`
- 背景執行：在 PowerShell 執行 `scripts/start_r75v2_background.ps1`
- 查看進度：在 PowerShell 執行 `scripts/check_r75v2_status.ps1`

## 正式資料分配

| 類別 | 張數 | 要解決的問題 |
|---|---:|---|
| 基礎幾何 | 896 | 維持基本形狀與一般退化能力 |
| 非圓與細節形狀 | 1,152 | 凹口、窄頸、孔洞、粗糙與不對稱輪廓 |
| 多物件與多尺度 | 768 | 陣列、密集場景、大小物件同時出現、裁切邊界 |
| 五段曝光序列 | 1,280 | 亮暗範圍與物體黑白不再綁定 |
| 局部邊界淡化與混合困難 | 512 | 局部消失、偏向一側的光暈、陰影及多種退化同時出現 |
| 不修改／近乎不修改 | 512 | 防止模型對本來已經好的影像製造光暈或假細節 |
| 合計 | 5,120 | 訓練 4,096、驗證 512、內部測試 512 |

同一個原始形狀的所有曝光與退化都固定放在同一組，避免訓練時先看過同一形狀。

## 資料限制

- 不使用真實顯微影像像素。
- 不使用 SEM 輪廓、樣品半徑、真實排列或裁切模板。
- 不使用 R61、V42、舊 R75 輸出當答案。
- 標準答案先以 8 倍大小繪製，再縮回 256×256。
- 精確輪廓另外保存，輪廓訓練不依賴模糊亮度邊界。

## 主要輸出位置

- 正式資料：`data/r75v2_formal_diverse_primitives`
- 訓練過程：`runs`
- 完成權重：`weights/formal`
- 手動重建結果：`results/inference_output`
- 資料檢查與設計紀錄：`reports`

R75-v2 在通過新的外部合成輪廓測試與獨立真實影像確認前，仍是研究候選模型，不自動取代 R61。

## 100 輪完成後的狀態

- 正式訓練已完成 100 輪。
- 合成驗證資料選出的正式權重是第 84 輪。
- 第 100 輪在 36 顆真實 SEM 柱的整體輪廓距離上略優於第 84 輪，並且在 12 個曝光下更穩定。
- 兩個權重都改善了輪廓重疊、位置與面積，但周長與非圓細節仍未通過，因此目前仍不取代 R61。
