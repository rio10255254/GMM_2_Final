# R115：用獨立的法線剖面證據，決定 R109 動作做多少

[研究時間線](<../../docs/research/TIMELINE.md>) · [基礎 R109](<../R109_StagedMidpointWidthScratch/FILE_GUIDE.md>) · [前一輪 R114](<../R114_ConfidenceGatedRecoverableScratch/FILE_GUIDE.md>) · [下一輪 R116](<../R116_CoherentGeometryAnchorScratch/FILE_GUIDE.md>)

**一句話：** 影像動作完全沿用 R109（法線中點位移與單調寬度），另加一條完全獨立的法線剖面證據線，沿法線取 −12 到 +12 px 的九點剖面，只能決定 R109 兩個動作採用多少，不能重畫影像，梯度也進不了幾何主體。2026-08-31 的短探針中，前兩版讓新分支決定 0～100% 採用率，結果全部關掉或不穩定；第三版改成以 R109 為中心、最多 ±15% 的調整才穩定。但在 R74 上仍略差於 R109，正式 48 輪沒有啟動。

| | |
|---|---|
| 結果 | **中止**（兩版因採用率不穩停下，正式 48 輪沒有啟動） |
| 時間 | 2026-08-31 |
| 實驗條件 | 程式資料：A＝R109 原始 5,000／512；B＝R114 的 240 張替換版；另有 C、D 兩種混合 |
| 起點 | 正式模型一律隨機初始化；R109 第 48 輪只用於訓練前的短探針 |

## 結果

**四組資料的同種子短測（固定驗證的改善，灰階，越大越好）：**

| 組 | 最佳輪 | 一般改善 | 補充資料改善 | 清楚影像改動 |
|---|---:|---:|---:|---:|
| A：R109 原始 | 5 | **0.0323** | **0.0557** | 0.00054 |
| B：R114 替換版 | 6 | 0.0313 | 0.0534 | 0.00071 |
| C：A＋全部 200 張新資料 | 5 | 0.0291 | 0.0483 | 0.00036 |
| D：A＋100 張新資料 | 3 | 0.0273 | 0.0450 | 0.00048 |

新資料讓早期學得較快，但沒有提高六輪內的最佳上限；報告建議日後重開時用 R109 原始資料，40 張新驗證資料保留為封閉的困難測試。

**鎖定 ACM（第三版，A 組）：** 第 2 輪 R73 邊界距離 0.165（略優於 R109 的 0.166），R74 2.514（略差於 R109 的 2.499），R74 五類中四類略差；內部最好的第 5 輪也不是外部最好的。

## 讀這些內容要知道的事

1. **全關閉的捷徑又出現了一次。** 第一版負例代價讓模型全部關閉退回原圖；第二版降低負例權重仍不穩。
2. **報告建議的下一步：** 先找出低對比類別的作用方向錯誤，或把法線剖面只當訓練時的密集中點與寬度監督，而不是推論時的動作調整。這接到了 R116。
