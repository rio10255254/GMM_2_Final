# R108A Evidence Manifest

This folder contains only new diagnostic code, controlled probes, frozen-model
outputs and derived evidence.  No existing experiment file or checkpoint is
modified.  R61/R79 checkpoints are used only for frozen transfer probes.

The canonical decision is `results/final_decision.json`; the plain-language
result is `reports/R108A_RESULTS_ZH.md`.  `EXPERIMENT_STATE.json` records the
lifecycle state and `FILE_MANIFEST_SHA256.csv` hashes the complete package.
