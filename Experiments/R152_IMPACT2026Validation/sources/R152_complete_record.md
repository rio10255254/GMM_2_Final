# R152 模型架構與完整實驗資料紀錄

**版本：**R152-R148v2-SafeAdaptivePSF  
**紀錄日期：**2026-09-29  
**狀態：**8,192 次擴充訓練、128 組合成測試、930 張實拍／8,370 顆圓、30 趟配對比較與最終稽核均完成。  
**角色：**保留 R148v2 已驗證的重建行為，補入論文架構中的多 PSF 頻域加權融合模組。R152 是研究延伸版，未取代既有正式基準。

## 1. 本輪要回答的問題與完成判定

使用者希望把「FFT → 多顆 PSF → 權重估計 → 加權融合 → 受限殘差比例 → 原圖連接」補回，同時盡可能保留 R148v2 的位移、直徑與輪廓效果。對本輪而言，**模組有載入、接受訓練並參與輸出即可**；不把正確辨認某一顆 PSF 設為必要門檻。

完成前固定的保留策略：原 R148v2 全部權重凍結；新增修正有獨立倍率，倍率 0 必須精確回到 R148v2；在合成開發集對倍率 `0、0.25、0.5、0.75、1` 逐項檢查，影像、梯度、配對、邊界及成像一致性均不得比原版高超過 0.5%，再選整體要求最低者。最後以同一 30 趟實拍作完整量測，不用實拍結果回頭挑倍率。

**最終判定：**模組存在且交付倍率為 1；R152 和 R148v2 的實拍量測數值極接近，沒有可稱為實質改善的幅度。最差直徑偏移微增 `0.000053 nm`，速度和記憶體也有成本，因此不能寫成「全部指標都進步」。

## 2. 模型身分與架構總覽

| 部分 | R152 的實際設計 | 是否受本輪訓練 |
|---|---|---|
| R148v2 原模型 | 一次多尺度 U-Net 脈絡、三個獨立原尺寸邊界階段、抗混疊、原圖參考、有界輸出及既有平均 PSF 提示 | **完全凍結** |
| 新 PSF 權重估計 | 讀取凍結脈絡特徵及輸入影像的 16 組徑向頻率統計，為 25 顆 PSF 產生一組 softmax 權重 | 訓練 |
| 新頻域光學支路 | 25 顆中心對齊 PSF 各產生受限反濾波器；依權重加總後反轉換，形成微量影像修正 | PSF 固定；權重網路訓練 |
| 新殘差連接 | 將受限 PSF 修正乘上模組內比例及安全倍率，接到 R148v2 已完成的影像上 | 兩個比例受訓練；交付倍率固定為 1 |

資料流如下。`y_base` 是原 R148v2 輸出；新光學支路只在它**之後**附加修正，沒有插回 U-Net 的中間層，也沒有改寫三個原尺寸階段。這是保留既有效果的關鍵設計取捨。

```text
輸入影像 x ──> 凍結 R148v2：平均 PSF 提示 + 一次 U-Net 脈絡
       │                        └─> 三個獨立原尺寸階段 ──> y_base
       │
       ├─> 頻率統計 ─┐
       ├─> FFT ──────┼─> 25 顆 PSF 的加權受限反濾波 ─> iFFT ─> 微量修正
       └─> U-Net 脈絡┘                                  │
                                                        └─> 接在 y_base 上 ─> R152 原生輸出
```

簡寫為 `y_R152 = clip(y_base + d × s × (x_PSF − x), 0, 1)`。交付倍率 `d=1`；安全比例 `s=0.0138008`；`x_PSF` 是經模組內比例 `β=0.0119699` 和修正幅度限制後的輸入影像。兩個比例相乘約 `0.00016519`，故模組有作用，但有意控制得很弱。倍率 `d=0` 時，與 R148v2 的輸出逐像素完全相同。

### 2.1 原 R148v2 主體的具體結構

- 脈絡 U-Net 通道為 `24 → 40 → 64 → 40 → 24`，輸出 16 通道脈絡特徵，只執行一次。
- 降採樣前與雙線性升採樣後使用固定二項式抗混疊濾波；正規化在每個像素的通道間進行，不跨整張影像計算空間平均。
- 三個原尺寸階段各有獨立參數，均為 64 通道；每階段殘差區塊的膨脹距離依序 `1、2、4、2`。
- 三階段學得的步幅分別為 `0.0777563、0.0739913、0.0711947`；每一步上限 `0.25`，累積殘差限制 `±0.35`，最後保留 `0–1` 亮度範圍。
- 既有 PSF 提示在推論時使用 25 顆的平均核，並保留合成訓練時的既有成像一致性讀法。
- 原主體參數 **1,194,406** 個；R152 完全凍結這些參數。這次只訓練新增的 **12,699** 個參數；合計 **1,207,105** 個。

### 2.2 新 PSF 模組的具體設定

| 設定 | 數值與行為 |
|---|---|
| 銀行 | 最新研究版 25 顆、每顆 `101×101`、非負且總和正規化為 1 |
| 權重範圍 | 25 顆全部參與；每張影像估計**一組**權重，不是同張影像各位置分別選 PSF |
| 估計器 | 16 通道 R148v2 脈絡特徵，24 通道卷積特徵，影像徑向頻譜 16 格，最後輸出 25 個權重；softmax 溫度 1 |
| 頻域處理 | PSF 中心先移至頻域原點；反濾波正規量 `0.03`，只在規定低頻半徑 `0.25` 內套用，反向增益上限 `2.0` |
| 加權融合 | 先加權頻域候選濾波器，再做一次反轉換；由反轉換的線性性可得與逐顆反轉換後加權等價 |
| 單次修正限制 | 反轉換結果相對輸入先限制在 `±0.25` 正規化亮度內 |
| 模組內比例 β | 設定範圍 `0.0025–0.03`，初值 `0.01`，交付值 `0.0119699` |
| 外部安全比例 | 最大 `0.25`，初值 `0.01`，交付值 `0.0138008` |
| 部署倍率 | 預先指定五個候選，最後選 `1.0`，因此附加支路保持開啟 |

由固定比例和修正上限可算得單像素的理論最大附加幅度約 `0.01053` 個八位元灰階；實際抽查三張影像的最大值為 `0.00552–0.00738` 灰階。這是 R152 原生輸出中的一條支路，沒有額外的輸出後置修正。

| 最早影像 | 0.039581 | 0.040370 | 3.218857 | 0.001340 |

## 3. PSF 與 SEM 來源界線

使用的研究版 PSF 銀行 SHA-256 為 `efc9d70d6427d82ba84f1371f71b6423f1491a815956412f8d6a627b72b1f843`。其原始擬合檔 SHA-256 為 `0d85d63c08a943a56d6fd74d2ce250b0d656d1170e7ab185e95d2ff369a797e6`。25 顆依 5×5 拍攝順序排列，任意兩顆正規化核的最低餘弦相似度約 `0.987620`。

PSF 擬合使用實物 P 類 SEM **外框幾何**協助了解光學模糊；沒有用 SEM 表中的直徑數字決定 PSF，也沒有將這些實拍九顆的 SEM 直徑當成神經網路清晰答案。神經網路的清晰目標仍來自合成場景。由於同一批實物輪廓曾參與 PSF 校準，後述同九顆 SEM 尺寸／輪廓比較是**校準條件下的一致性檢查**，不構成完全獨立的絕對尺寸準確度驗證。

## 4. 訓練資料、目標與程序

### 4.1 合成資料

R152 以唯讀方式引用 R148v2 已封存的合成資料。共有 **768 個母場景**：訓練 512、開發 128、最後測試 128；每個母場景四個視圖，合計 **3,072 個視圖**（訓練 2,048、開發 512、測試 512）。同一母場景的視圖維持在同一資料分組。場景包括曲線、角點與線、近距物體、紋理邊緣、平坦與原樣對照。各視圖可有已記錄的位移、對比、亮度、噪聲及 PSF 編號；噪聲依固定種子在每次訓練循環重產。

合成影像的模糊由既有研究版 25 顆 PSF 製作，另含少量原樣／無 PSF 對照；乾淨目標和幾何邊界由合成場景提供。PSF 編號可用於新增支路的**寬度與尾部描述**教學，但 R152 沒有把「25 顆分類答對」當成損失或驗收條件。原 R148v2 的觀測項於訓練時有 25% 機率使用已知 PSF，其餘使用平均 PSF；正式實拍推論使用平均核作原主體提示。

| 最佳化 | AdamW；最高學習率 `3×10⁻⁴`，最低 `3×10⁻⁶`，前 128 次暖身，其後餘弦下降；權重衰減 `1×10⁻⁵` |

## 5. 固定實拍驗證與統計定義

使用同一 30 趟、每趟 31 張、合計 930 張 `1544×2064` 的單色影像。每張固定測九顆圓，合計 8,370 顆。所有方法共享相同的像素比例 `0.1725 μm/px`、PI 回授、九顆追蹤目標、主動輪廓粗定位、法線方向最大梯度取邊及最小平方法圓心／半徑讀法。進入量測的是模型**原生 FP32 輸出**，沒有額外銳化、移動或調整直徑。

- **短步位移平均絕對差：**每趟30組相鄰影格，共900組，九顆圓位移取中位後對照 PI 回授。
- **起點相對長距離差：**每趟後30個位置各與起點比較，共900組。
- **重拍波動：**同一相對位置的30趟有號誤差標準差，再對30個位置取平均；不把900組當成900次獨立重拍。
- **直徑／輪廓波動：**相同位置、相同圓在30趟間的散布；輪廓以每顆64點邊界重採樣至720個徑向方向後統計。
- **去尺寸形狀：**每條輪廓先扣自身平均半徑，再量跨趟形狀散布；不代表平均直徑正確。
- **配對區間：**以完整30趟為單位重抽樣2,000次，不把圓、位置或徑向點誤作獨立樣本。

8,370 顆圓逐一對位，R152 相對 R148v2 的圓心移動平均 `0.000114 nm`、99 百分位 `0.000176 nm`、最大 `0.000240 nm`；直徑絕對變化平均 `0.000325 nm`、99 百分位 `0.000430 nm`、最大 `0.000508 nm`。這些是**同一影像兩個模型的讀值差**，不能當作模型相對真值的絕對誤差。

## 8. 與 SEM 表及 SEM 輪廓的關係

### 8.1 同九顆 SEM 表的平均直徑

SEM 表九顆平均直徑為 `2629.737382 nm`。本批光學影像的平均量測直徑及與表的平均絕對差如下：

| 方法 | 光學量測平均直徑 nm | 對 SEM 表平均絕對直徑差 nm |
|---|---:|---:|
| RAW | 2799.620660 | **169.883278** |
| R140v2 | 2842.878055 | 213.140673 |
| R148v2 | 2834.018265 | 204.280883 |
| R152 | 2834.017939 | 204.280557 |

R152 比 R148v2 僅低 `0.000325 nm`，仍比 RAW 高約 `34.397279 nm`。因此不能因波動低、邊界較銳利或 PSF 模組存在，就主張尺寸比原圖更準。

### 8.2 從 SEM 輪廓點重算的另一種尺寸參照

另以 SEM 輪廓點重擬合，九顆平均直徑為 `2614.438543 nm`，與上表的 SEM 工作表參照不同；兩者不可混成一個數字。相對此輪廓參照的平均絕對直徑差：RAW `185.182117 nm`、R148v2 `219.579721 nm`、R152 `219.579396 nm`。R152 在此參照下仍高於 RAW 約 `34.397279 nm`。

同九顆 SEM 輪廓的方向對應保留兩個候選，沒有為 R152 再挑有利方向：

| 指標 nm | R148v2 | R152 | R152 減原版 |
|---|---:|---:|---:|
| 方向1，全徑向差 | 110.286981 | 110.286820 | −0.000161 |
| 方向1，去尺寸形狀差 | 31.745403 | 31.745380 | −0.000023 |
| 方向2，全徑向差 | 110.904768 | 110.904608 | −0.000160 |
| 方向2，去尺寸形狀差 | 18.286737 | 18.286709 | −0.000028 |

差距仍是實務上的原版水準。SEM 幾何曾參與 PSF 校準，故這些結果不能延伸為獨立外部真值主張。

## 9. 分塊、時間與記憶體

### 9.1 分塊方式與交付權重的一致性

沿用原 R148v2 的原尺寸階段分塊：核心 `512×512`，四周額外讀取 `24` 像素；只保留各塊中央核心，不做重疊平均。U-Net 脈絡、原有平均 PSF 提示及新增 25 顆 PSF 的頻域融合仍看**整張影像**，因此這不是整個模型都切成小圖。

在與正式驗證相同的 FP32、TF32 關閉設定下，交付權重的三張固定實拍整張／分塊比較：平均絕對差約 `0.00000158–0.00000161` 灰階，最大差不超過 `0.000076` 灰階；接縫區與一般區域的平均差比約 `1.23–1.33`，絕對差仍極小。這支持既定設定下的分塊輸出近似整張。若更換精度、顯示卡或運算程式，需重做此檢查；不宣稱逐位元完全相同。

### 9.2 運算成本

三張固定實拍、同張 RTX A6000、相同 FP32 設定、每張預跑一次後各量五次：三張中位數的中位為 R148v2 `1.5284 秒/張`、R152 `1.5619 秒/張`，R152 約慢 **2.2%**。兩模型在各自獨立程序、同一張影像量得的顯示卡已配置峰值為 R148v2 約 `2.44 GiB`、R152 約 `2.78 GiB`，後者多約 **0.34 GiB**。新增的整張頻域核快取帶來主要常駐記憶體成本。

930 張 R152 正式流程本身記錄的模型前向中位為 `2.262 秒`、含讀寫中位為 `2.687 秒`；這與上面的三張同條件比較屬不同測時範圍，**不可**拿另一時段的 R148v2 930 張秒數直接計算架構速度差。
