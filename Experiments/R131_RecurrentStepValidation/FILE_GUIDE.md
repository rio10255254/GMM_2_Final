# R131：同一個 R129，修 0～4 次各有什麼得失

[研究時間線](<../../docs/research/TIMELINE.md>) · [被測的 R129](<../R129_OpticalPriorHybrid/FILE_GUIDE.md>) · [下一輪 R132](<../R132_BoundaryPolicyStudy/FILE_GUIDE.md>)

**一句話：** 2026-09-14 不重新訓練，把 R129 延續訓練第 8,192 次的權重分別停在第 0、1、2、3、4 次修正，量 36 顆柱的 SEM、201 張連續影像的 LSC，以及速度。第四次仍帶來細部形狀收益（三次到四次 33/36 顆改善），但尺寸偏大從第一次就開始出現；三次在固定 120 對的部分位移摘要反而較好，又省約 25% 時間。同一天也查清楚展示圖「半邊清楚、半邊模糊」的原因：是最後的 80 px 邊緣保護把原圖混回去。

## 讀這些數字要知道的事

1. **第 0 次不等於原圖。** 它仍保留光學融合與最後的原圖參照處理。
2. **這是截斷一個已訓練好的四次模型，不是重新訓練一至三次的模型**，不能說四次就是最佳，也沒測五次以上。
3. **半邊模糊的原因。** 一直拿來展示的第 18 顆在影像左側，展示裁切有 58.65% 落在 80 px 保留區、14.42% 在過渡區，只有 26.92% 完整採用模型。保護前模型其實有改動那一區（平均約 3.3 灰階），套用保護後就跟原圖逐像素相同。36 顆裡只有中間 16 顆的量測範圍完整由模型處理，這也是 R132 去研究保留帶寬度的起因。
4. 中間 16 顆單獨看：細形狀差距從 0 次的 25.8 降到 4 次的 8.7 nm，但尺寸差距從 88.6 變成 102.6 nm。
