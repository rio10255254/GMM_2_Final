# R133：尺寸偏大是光學、學習還是最後輸出造成的

[研究時間線](<../../docs/research/TIMELINE.md>) · [前一輪 R132](<../R132_BoundaryPolicyStudy/FILE_GUIDE.md>) · [被拆解的 R129](<../R129_OpticalPriorHybrid/FILE_GUIDE.md>) · [下一輪 R134](<../R134_DirectStateRepair/FILE_GUIDE.md>)

**一句話：** 2026-09-14 固定 R129，把流程拆開來看尺寸在哪一段變大：只做光學、網路輸出、最後原圖參照，以及幾種替代的輸出方式。最關鍵的對比是：在已知尺寸的合成圓上，模糊會讓量到的圓偏小，R129 往外修正剛好拉回來；但真實照片相對 SEM 參考本來就偏大，模型再往外修就加大了差距。所以最優先要處理的是「訓練時的成像、實際光學邊界、SEM 材料參考」三者的對應，而不是換掉某一行輸出公式。

## 結果

**已知尺寸的圓（16 種條件的中位數，正值是量到的直徑偏大）：**

| 模糊程度 | 原圖偏差 | R129 偏差 |
|---:|---:|---:|
| 0 | +0.002 px | +0.002 px |
| 1 | −0.033 px | +0.011 px |
| 2.2 | −0.149 px | +0.011 px |
| 4 | −0.352 px | −0.080 px |

64 個條件中 41 個改善、23 個退步，最差的絕對偏差仍有 0.71 px。在合成資料上，模型並沒有普遍把尺寸畫大。

**真實 SEM，尺寸在哪一段改變**（同柱同曝光配對的中位數）：

| 階段 | 尺寸讀值的變化 |
|---|---|
| 只做光學（相對 Raw） | 約 −7.2 nm，34/36 顆變小 |
| 網路輸出（相對只做光學） | 約 **+18.9 nm**，36/36 顆變大 |
| 最後原圖參照（相對網路輸出） | 約 +0.7 nm |
| 整體 Final（相對 Raw） | 約 +12.1 nm，36/36 顆變大 |

這幾個是不同的配對中位數，不能直接相加成嚴格的分解。關掉光學或換成兩種新的差量輸出方式，整體尺寸差距都還在 101～102 nm。

## 讀這些數字要知道的事

1. **訓練目標其實看得到尺寸。** 用 R129 實際的訓練要求做反例：把半徑 18 改成 19 px，影像與邊緣要求會給出往縮小方向的梯度（約 +4.746）；但兩張一樣偏大的移動影像，配對一致性要求是 0。位移穩定不等於絕對尺寸正確。
2. **舊的輸出方式有一個數學缺陷。** 它把網路影像的高頻加回原圖；網路影像如果剛好等於原圖，仍會再加一份原圖的高頻（在隨機圖上平均改動 14.6 灰階）。新做的兩種差量接口在「沒有修正」時精確等於原圖、梯度也正常，但直接套到舊權重上，生成測試的影像誤差從 1.83 變成 2.68 或 4.38 灰階，所以不能原地替換。
3. **內部的「網路影像」不是已復原的乾淨照片**，它跟乾淨答案差約 29 灰階，是配合後端輸出的信號。
4. **沒有查清楚**真實材料回應、SEM 尺度、取邊定義各占多少；也不能拿這 36 顆柱的 SEM 差異反推一個固定內縮量去訓練。

## 下一步設計（R133 修正方案）

報告提出的順序：先對齊材料、光學目標與讀法；讓訓練成像反映正確的邊界關係；保留 R129 的單張輸入、四次共享修正與改善放大，但重整輸出契約（原圖是起點、直接輸出被訓練的影像或差量、中性時精確等於原圖）；最後才加由實際輸出計算的幾何要求。並設計了一個 2×2 短測（新成像規則 × 新輸出契約）。這接到了 R134。
