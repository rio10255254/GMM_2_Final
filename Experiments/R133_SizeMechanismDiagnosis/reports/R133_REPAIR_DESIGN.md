# R133 底層修正方案：先對齊物理問題，再修模型接口

2026-09-14。這是經R133反例與實測約束後的下一版方案。已實作並測試中性輸出及限定條件的幾何要求原型，**尚未建立、訓練或驗證完整替代模型**。

## 1. 先把三種答案分清楚

每個資料項目需要獨立記錄：

| 資料欄位 | 意義 | 不能混稱的東西 |
|---|---|---|
| 材料幾何 | 真正物體輪廓、尺寸與位移 | SEM影像上的任一亮邊不自動等於材料邊界 |
| 目標光學影像 | 指定參考成像下應重建的亮度影像 | 不直接拿SEM灰階當光學答案 |
| 感測影像 | 實際鏡頭、材料回應、曝光、像素積分及雜訊後的輸入 | 不能假設所有實拍都只是中心對齊Gaussian模糊 |
| 量測結果及適用範圍 | 從上述目標影像讀出的輪廓位置，並記錄其對材料幾何的偏差 | 演算法能穩定返回數字，不等於物理位置已正確 |

先用現有原始SEM、相機與校準紀錄覆核共同尺度與取邊定義，保留R127指出的不同來源尺度差。仍缺的材料／光學對應需由獨立校準樣品補足。不得按這36顆的輸出誤差，給每顆調尺寸、調光學中心或統一縮小一圈。

可使用新且獨立的配對標準答案作訓練／校準；必要條件是原始樣品與所有衍生影像先分清訓練、開發、確認。訓練有標準答案是正常的；把同一評估答案混入训练再宣稱未知能力才是問題。

## 2. 資料設計要反映實際錯誤方向

R133理想控制中的模糊經常讓圓的讀值偏小，R129向外修能拉回；真實照片卻已比既有SEM參考大，向外修增加差距。這支持檢查成像／參考對應，不足以單獨決定究竟是光學材料回應、尺度還是讀法占主要比例。

新的資料應依独立校準決定正確的邊界形成方式，記錄何時位置讀值偏內、偏外或本來正確，再做已知幾何下的成像。不能只擴大Gaussian寬度，更不能任意加入未知位置偏移，要求單張影像猜出不可辨認的物理答案。

保留：一般非圓形、細頸／間隙／角落、密集圖案、材質紋理、亮暗兩種物體、清楚與平坦例子。平移仍在光學及像素積分之前發生；同一運動對使用相同光學條件。場景、材料幾何、相機與光學中心的真值各自記錄，不讓模糊中心吸收真實尺寸錯誤。

每個場景與物體的有效邊界貢獻要正規化，避免再次由少數密集圖案主導。清楚／模糊資料要同時報告，不能用大量不改圖例子壓掉修復學習，也不能讓大量去噪例子淹沒細節。

## 3. 保留R129有用的主體，讓影像狀態有明確意義

下一個對照原型保留單張輸入、原尺寸輸出、四次共享局部修正、較細內部網格與改善放大的運算。改的是責任與連接：

**原圖作影像初值 → 接收實測光學提示 → 四次更新同一影像狀態 → 直接形成要評估的輸出 → 清楚標示小範圍邊界處理。**

具體要求：

- 原圖是影像狀態起點。實測光學資訊仍要實際使用，可作修正的條件或提案，不必對任何輸入都強制改寫基底。是否保留原强制融合，另立單因素比較，不偷偷刪掉論文設計。
- 最後應輸出被訓練的影像狀態或明確的影像差量。停止把另一張圖的高頻再固定加回原圖，卻把那張內部圖稱為已還原的乾淨影像。
- 「沒有修正」時，輸出必須精確等於輸入，而且仍有可學習的梯度。中性前向不能用切斷梯度的分支假裝可學。
- 若某個內部量本來就是修正訊號，應如此命名及評估；若宣稱是重建影像，必須直接與相同定義的目標影像比較。不能只保存四張中間圖就宣稱每步物理正確。
- 最外側保護與量測區准入分開。R132的16像素研究設定可保留作共同部署對照，但仍須完整物件／窗口在有效區；不能把半個物體混回Raw後稱完全重建。

R133已有兩種差量輸出原型及零修正、非零梯度、數值導數檢查。直接換到舊權重的結果不佳，所以**不得原地替換正式輸出**；這些原型是新匹配短訓練的材料，不是完成修復的模型。

## 4. 訓練應直接檢查最後影像的幾何

保留影像、邊緣與已知運動要求；新增幾何約束時，須由實際最後影像計算，不另設一個可以獨立答對的形狀分支來替重建自證。

已實作的限定原型是：當前景／背景亮度與材料覆蓋的關係已知時，由輸出影像換算材料覆蓋，檢查局部形狀與面積。暗物體、亮物體的尺寸梯度方向均實測正確。它不假設物體是圓；但目前實跑的是簡單已知剖面，**不能直接套到任意實拍、SEM亮帶、未知紋理或照明**。

在完整接入前必須補完：非圓形／窄間隙、純平移、單純變寬、正負極性、清楚圖、低對比無法辨認等反例。各作用的單位、位置正負號及梯度都要檢查；邊界位置與寬度不得再次混稱。

不同要求的強度先按有效場景、已知噪聲及位置精度正規化，實測各自梯度，再固定設定。不能只看損失數值大小動態放大某個分支，也不能讓共同目標使已可用的幾何路徑停止學習。

兩張影像的一致性仍有用，但必須與每張各自的幾何答案同時成立。每張都偏大一樣多，不能靠位移穩定拿到成功判決。

## 5. 下一個短訓練比較如何保持可歸因

先補資料與讀法的資格檢查，再做下列二乘二短比較。這是四個研發對照，不是四個交付模型。

| 組別 | 影像形成資料 | 輸出／影像狀態契約 |
|---|---|---|
| A | 原生成規則 | 原R129契約 |
| B | 有獨立依據的新成像規則 | 原R129契約 |
| C | 原生成規則 | 新中性、直接影像契約 |
| D | 有獨立依據的新成像規則 | 新中性、直接影像契約 |

各組同一幾何來源、同一抽樣次序、兩個匹配的新初始化，每個起點固定512次更新；先維持同一影像／邊緣／配對要求，使資料因素和接口因素可分開看。不是聲稱相同運算時間。模型不同的新增參數、共同初值與實際讀到的資料必須逐項核對，不只用相同亂數種子作證。

之後，只有在材料／輸出幾何對應與限定幾何要求已通過反例時，才把新增幾何要求作另一個獨立對照。不能第一輪就把資料、接口、目標、容量及選點全改掉，最後只知道分數有差。

每個固定終點都直接看同一真實面板，不只憑合成成績決定是否看實拍。記錄有號尺寸、細形狀、實際輸出位移、最差失敗、清楚圖改動和時間。驗收容差需在該比較結果揭曉前，按用途與參考不確定度訂定；不能事後為贏的一組補規則。最後的未知樣品結論另需獨立新樣品。
