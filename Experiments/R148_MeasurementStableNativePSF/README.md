# R148 — 量測穩定的原尺寸 PSF 重建

## 假說

把決定位置與邊界的主幹改成全原尺寸運算，並讓同一生成物體跨 PSF、對比、亮度、雜訊與 0.25–8 像素位移，能降低 R147 對取樣格與拍攝外觀的敏感性，同時保留其直徑重拍收益。

## 設計

本輪是自包含實驗。模型以原尺寸擴張卷積取得大範圍資訊，沒有縮圖或放大；四次共享修正均接受清晰影像、梯度、成像一致性、跨外觀位置一致性與邊界矩的直接監督。PSF 使用 R147 同一份研究25顆銀行；生成時使用已知個別 PSF，模型訓練多數情況只使用固定平均，避免假設實拍已知逐張 PSF。推論固定使用25顆平均。

資料由 R147 已鎖定的 768 個獨立生成母場景及其4倍清晰潛圖重製，不使用實拍、PI或SEM答案。SEM真實外框仍只參與研究PSF的上游光學校準和訓練後比較。

## 完成標準

前置檢查須證明：資料祖源與形成順序可重播；PSF中心、亮度和移動正確；一像素整數移動在中央區域的額外差低於0.001像素；尺寸與位置要求有非零且方向正確的梯度；短測能降低保留生成資料誤差。通過後以固定最後第8192次權重作正式模型，不用930張實拍選步長、架構或保存點。

## 狀態

完整實作、資料形成與64次短訓練門檻已通過；首次正式程序留下62次紀錄，但未到第一個保存點。程序停止後的架構核對發現，四次網路與重複PSF運算的累積依賴範圍大於訓練中央答案的邊界，因此此鎖定版本不續跑、不算正式模型。[架構核對](results/architecture_audit.json)。原 R147 與所有歷史模型不覆寫。
