# R80：R79 第 23 輪與第 100 輪擴大驗證

這個資料夾只做驗證，不修改 R79 的訓練資料、程式或權重。

固定比較範圍：

- R79 內部保留、未參與訓練與驗證的 512 張形狀。
- R78 已封存的 301 張 5×、20×、50×真實顯微連續影像。
- R73 的 100 張新形狀與 R74 的 100 張高難度顯微合成影像。
- 36 顆中央柱、12 個曝光的 SEM 真實輪廓。
- 兩組 5×影像另用 512 像素分塊重跑，檢查分塊設定敏感度。

主要入口是 `scripts/run_r80.py`。它會依序做來源核對、重建、內部真值比較、真實影像穩定性、ACM 輪廓以及結果整理。所有輸出只寫入本資料夾的 `results` 與 `reports`。

這是訓練完成後的權重比較。R73、R74 與 R78 的失敗模式曾影響 R79 的資料設計，因此它們屬於擴大開發驗證，不被包裝成全新盲測。
