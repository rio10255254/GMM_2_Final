# Ablation External GMF Verdict — 4 個方法元件的因果歸因

Last updated: 2026-05-27

## 一句話結論

**4 個 ablation 對 main claim 因果歸因強度不對等,且影響範圍各不相同**:

- **EDGE(邊界微分)→ 三尺度全方位最重要**(σ̂ external 8px +115% / 0.8px +96% / 0.08px +45%)
- **SEQ(多幀一致性)→ 主要在 8 px 宏觀位移忠實度**(σ̂ external 8px +131%,但 0.8px 沒退步)
- **FREQ(頻域可行性)→ 中等影響,主要在 8px 跟細節 b**(σ̂ +10-19%,0.08px |b| +30%)
- **EQ(平移等變性)→ external 上幾乎沒效果**,可能跟 SEQ 互補被涵蓋

**論文 4.5 / 4.6 對方法元件的因果論述需要修正,從「四個元件互相封鎖」改成「兩個 anchor(EDGE / SEQ)+ 兩個輔助(FREQ / EQ)」**。

## 每個 ablation 的 verdict 跟論文意涵

### Ablation A — NO_SEQ(對應論文 4.6 多幀一致性)

**External σ̂ 影響**:
- 8 px:**+131%**(0.155 → 0.357)← 巨大退步
- 0.8 px:**−2.8%**(0.132 → 0.128)← 沒退步,甚至略好
- 0.08 px:+8%(0.100 → 0.108)← 小幅退步

**判定**:**多幀一致性對 8 px 宏觀位移忠實度是強因果驅動,但對 0.8 px 主戰場 σ̂ 並非主要貢獻者**。0.8 px 上 NO_SEQ σ̂ 0.1279 跟 COMBO 0.1316 在外部 GMF 的可分辨度內接近——可能 0.8 px σ̂ 已逼近 CRB(Tier 1 C5 結論),沒有上推空間;0.8 px 的型態轉換是別的方法元件達成的。

**對論文 4.6 寫法的修正**:
- 從「多幀一致性是分離 σ̂/b 的關鍵,讓 0.8 px 主戰場可以同時改善」
- 改成 **「多幀一致性的主要因果效應在跨大尺度位移的長期穩定度(8 px),即將 macro drift 從 NO_SEQ 的 0.357 壓回 0.155;在 0.8 px 主戰場 σ̂ 上,多幀一致性的貢獻被其他元件(主要是邊界微分殘差)涵蓋」**

### Ablation B2 — NO_EDGE(對應論文 4.5.3 邊界微分一致性)

**External σ̂ 影響**:
- 8 px:**+115%**(0.155 → 0.333)
- 0.8 px:**+96%**(0.132 → 0.258)← 巨大退步,接近 R42 research-only 等級的 0.256
- 0.08 px:**+45%**(0.100 → 0.145)

**判定**:**邊界微分一致性殘差是三尺度全方位最重要的物理殘差**——是 MOSR 框架裡單一最不可拿掉的元件。這也跟 internal 8 px(NO_EDGE σ̂ +50%)跟 k=2 CV 跨尺度退步的訊號完全一致。

**對論文 4.5.3 寫法的修正**:
- 從「邊界微分一致性是三類殘差之一」
- 改成 **「邊界微分一致性殘差是 MOSR 框架的核心 anchor:它在 0.8 px 主戰場上獨立支撐 σ̂ 從 NO_EDGE 的 0.258 壓回 COMBO 的 0.132(降幅 49%),拿掉它後模型退步到 R42 research-only 等級。其他兩類物理殘差(等變性、頻域可行性)的因果效應在這個 dataset 上明顯弱於邊界微分」**

### Ablation B3 — NO_FREQ(對應論文 4.5.2 頻域可行性)

**External σ̂ 影響**:
- 8 px:+19%(0.155 → 0.184)
- 0.8 px:+10%(0.132 → 0.145)
- 0.08 px:+10% σ̂ + **|b| +30%**(b 從 −0.025 翻成 +0.026,系統偏差改方向)

**判定**:**頻域可行性殘差有中等貢獻,主要在 8 px σ̂ 跟 0.08 px b 的結構**。0.08 px b 翻向是個有趣的訊號——拿掉頻域殘差後系統偏差不只是變大,而是**改變方向**,代表頻域殘差確實在約束 b 的方向結構,不只是壓幅度。

**對論文 4.5.2 寫法**:可保留現有 framing,但補一句「頻域殘差在最細尺度(0.08 px)上對 b 的方向有明顯約束效應」。

### Ablation B1 — NO_EQ(對應論文 4.5.1 平移等變性)

**External σ̂ 影響**:
- 8 px:**−4.7%**(0.155 → 0.147)
- 0.8 px:+5%(0.132 → 0.138)
- 0.08 px:**−1.7%**(0.100 → 0.098)

**判定**:**等變性殘差在 external 上幾乎沒獨立效應**——3 尺度 σ̂ 都跟 COMBO 接近。唯一明顯訊號是 0.8 px lag-1 autocorr 從 COMBO 的 −0.518 降到 −0.381(絕對值小 27%),代表序列結構性減弱,但這個影響在 σ̂/b 主訊號上看不到。

可能解釋:
1. SEQ 已涵蓋等變性的功能(序列一致性 implicit 要求模型對平移有穩定回應)
2. 這個 dataset 上等變性問題不顯著(可能因為 PSF Wiener 前置處理已經處理掉大部分平移敏感性)
3. EQ_PROB=0.25 本來就偏小,拿掉影響有限

**對論文 4.5.1 寫法的修正**:
- 從「等變性殘差是三類之一,互相封鎖退化解」
- 改成 **「等變性殘差在實證上的獨立 σ̂ 貢獻較弱,主要表現在序列 lag-1 autocorr 的結構性(從 COMBO 的 −0.518 到 NO_EQ 的 −0.381),意味著它跟序列一致性訓練存在功能性互補但部分被涵蓋」**

或者更積極的寫法:**「等變性殘差設計目的雖明確,但在 σ̂ 主指標上沒有獨立貢獻,可在未來工作中考慮簡化或合併到序列一致性訓練中」**——這個是誠實的 ablation 結論,而不是硬撐論文 4.5.1 的原始 framing。

## 主軸的進一步精緻化

從 Tier 1(C1-C5)+ Ablation 結果合起來,論文 main claim 可以**進一步深化**為:

> **「神經重建在精密位移量測情境下的本質作用是誤差型態轉換器。這個轉換主要由兩個 anchor 驅動:**
> **(1) 邊界微分一致性殘差(三尺度全方位壓低 σ̂,讓誤差能在所有位移幅度上結構化),**
> **(2) 多幀序列一致性訓練(將跨大尺度位移的長期 drift 壓回 capacity 上限內)。**
> **物理一致性的其他殘差(頻域可行性、平移等變性)提供輔助 constraint,但獨立 σ̂ 貢獻較弱。**
> **σ̂ 在 0.8 px 主戰場已逼近資訊理論下限(CRB),無論拿掉哪個元件都仍維持在 0.13-0.26 範圍內;進一步壓縮需要的不是現有殘差設計的延伸,而是改變誤差的結構性類別。」**

這個版本比論文目前寫的更精緻、更可被 falsify、也更跟 ablation 一致——**不是「四個元件互相封鎖」的對稱論述,是「兩 anchor + 兩輔助」的因果層級論述**。

## 對論文骨幹修改的具體 implication

跟 `TIER_1_FINAL_VERDICT.md` 已提的修改清單合併:

1. **第 1.3 三大貢獻金字塔**:不變(誤差型態轉換是主貢獻,MOSR 框架 + 多幀一致性是支撐)。但**支撐 B(多幀一致性)的論述要精準化**——主要因果在 8 px 宏觀,不是 0.8 px 主戰場
2. **第 4.5 三類物理殘差**:重新組織成「核心 anchor(邊界微分)+ 輔助(頻域)+ 邊際(等變性)」**三層結構**,不是平列三項
3. **第 4.6 多幀一致性**:聚焦在「跨大尺度宏觀 drift 控制」,從 ablation 證據改寫
4. **第 4.8 falsification criterion**:新增 C6「方法元件因果歸因」——ablation NO_EDGE 在 0.8 px 退步 >50% 是 4.5.3 主張的硬訊號
5. **第 6.3 方法歸因**:用本 verdict 的表格直接搬

## 限制跟 follow-up

**這個 ablation 的限制**:
- **只跑 single seed**(沒做 multi-seed 平均);0.8 px 上 NO_SEQ vs COMBO 差距小,可能在 seed 變異範圍內。如果要嚴謹,應跑 3-5 seed 平均
- **沒做 PSF ablation**(留作 future work);如果要支撐論文 4.3 PSF 章節的因果歸因,需要補
- **EQ 結論「沒效果」的解釋有兩種可能**(EQ 真的沒效果 / EQ 跟 SEQ 互補被涵蓋),要區分需要做 ablation **拿掉 SEQ 同時保留 EQ**——這是個 follow-up 實驗,不是當前 4 個 ablation 能回答的

**對 PI 資料的期待**:
- PI XY 雙軸資料到位後,**用 PI 真值重做 NO_EDGE 的 σ̂ 對比**——如果 PI 真值也顯示 NO_EDGE 0.8 px σ̂ +96%,那是「不可推翻」級證據,論文 4.5.3 的核心地位 cement
- PI 資料也可以驗證「NO_SEQ 在 0.8 px 沒效果」是真的還是 GMF 工具的特性
