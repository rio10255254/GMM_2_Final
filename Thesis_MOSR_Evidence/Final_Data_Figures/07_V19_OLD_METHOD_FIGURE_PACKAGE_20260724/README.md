# 論文 v19 圖表整理包

本資料夾集中整理第六章後續可能新增、取代或沿用的圖表。目前尚未修改論文 Word。

## 使用原則

- 位移量測統一採用原有的最大梯度邊界定位方式。
- 所有位移序列只呈現實際選取的 30 步，橫軸固定為 1–30。
- 位移改善、消融實驗與多模型比較分開呈現，不合併成同一組結果。
- 新繪圖表不放圖內標題或解釋性句子，只保留座標名稱、圖例與必要的參考線。
- 圖表說明文字集中放在論文圖說；建議圖說已整理於 `V19_FIGURE_INDEX_zh-TW.md`。
- Raw、Wiener、MOSR 與比較模型使用固定顏色，字型、線寬、圖例位置及輸出尺寸保持一致。

## 輸出格式

新繪的 35 張數據圖均同時保存為：

- PNG：插入 Word 及快速預覽。
- PDF：保留向量品質，適合最終排版。
- FIG：日後可在 MATLAB 中直接修改。

原始顯微影像及既有素材目前保留為 PNG，不重複轉成無意義的 FIG。
