# 圖表索引與建議圖說

所有新圖均同時保存 PNG、PDF 與 MATLAB FIG。圖內沒有標題或說明段落，正式使用時請將下列文字放在圖名後方。

## 一、位移改善實驗

| 編號 | 圖檔主題 | 建議圖說 |
|---|---|---|
| 01 | 50 倍、0.5 µm 逐步位移 | 50 倍物鏡下，Raw、Wiener 與 MOSR 對 0.5 µm 平台位移的 30 步量測結果；虛線為 PI 平台實際回授位移。 |
| 02 | 50 倍、1.0 µm 逐步位移 | 50 倍物鏡下，Raw、Wiener 與 MOSR 對 1.0 µm 平台位移的 30 步量測結果。 |
| 03 | 20 倍、0.5 µm 逐步位移 | 20 倍物鏡下三種方法的 0.5 µm 位移量測；MOSR 降低第 14 步附近的明顯低估與整體波動。 |
| 04 | 20 倍、1.0 µm 逐步位移 | 20 倍物鏡下三種方法的 1.0 µm 位移量測。 |
| 05 | 各序列平均絕對誤差 | 四條序列的位移平均絕對誤差；數值越低表示越接近平台回授。 |
| 06 | 各序列逐步位移標準差 | 四條序列的逐步位移標準差；相同目標位移下數值越低表示逐步波動越小。 |
| 07 | 各序列九宮格離散度 | 九顆 pillar 位移結果的穩健離散度；數值越低表示同一影格內不同結構的一致性越高。 |
| 08 | 各序列跨門檻敏感度 | 30% 至 70% 等強度輪廓所得位移的差異；數值越低表示結果較不受灰階門檻選擇影響。 |
| 09 | 倍率合併平均絕對誤差 | 將 0.5 µm 與 1.0 µm 序列依倍率合併後的位移平均絕對誤差。 |
| 10 | 倍率合併九宮格離散度 | 將兩種目標位移依倍率合併後的九宮格位移離散度。 |

誤差棒為 95% 抽樣區間。縱軸正值代表移除或替換該設計後數值增加，也就是完整設計較好。

| 編號 | 圖檔主題 | 建議圖說 |
|---|---|---|
| 01 | 抗混疊上取樣的九宮格離散度效果 | 一般上取樣相對抗混疊上取樣造成的九宮格位移離散度變化；20 倍、1.0 µm 序列呈現最明顯增加。 |
| 02 | 抗混疊上取樣的逐步標準差效果 | 一般上取樣相對抗混疊上取樣造成的逐步位移標準差變化。 |

| 05 | 位移相關設計的逐步標準差效果 | 相鄰影格一致性、已知位移監督與平移等變限制的逐步位移標準差效果。 |
| 06 | 位移相關設計的九宮格離散度效果 | 三項位移相關設計對九宮格內一致性的合併效果。 |
| 07 | 邊界相關設計的九宮格離散度效果 | 各邊界相關設計移除後的九宮格離散度變化；Raw 位置錨定效果最大。 |
| 08 | 邊界相關設計的跨門檻敏感度效果 | 各邊界相關設計移除後的跨門檻敏感度變化。 |

## 三、多模型比較實驗

既有新版圖表位於多模型比較資料夾，共 20 張、每張均有 PNG、PDF 與 MATLAB FIG。其內容依序包含：

1. pillar 四條序列的 Raw、NAFNet、EDSR-x1 與 MOSR 逐步位移；
2. via 四條序列的四方法逐步位移；
3. 50 倍與 20 倍的誤差、九宮格離散度及方法差值；
4. 五種局部門檻下的位移敏感度；
5. 已知合成位移下舊量測法與新版量測法的誤差比較。
