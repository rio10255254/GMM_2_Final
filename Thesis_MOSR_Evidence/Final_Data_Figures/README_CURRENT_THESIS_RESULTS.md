# 論文正式圖表與結果入口

這個資料夾只保留目前論文需要的三條證據線。閱讀順序如下：

1. `03_PSF_EXPERIMENT_RESULTS`：先說明實驗系統的 PSF 擬合、參數敏感度與重複性。這一部分證明本研究具備 PSF 建模與驗證能力，但不把獨立擬合的實驗 PSF 說成 V42 成效的直接原因。
2. `01_CURRENT_THESIS_RESULTS_V42_CENTER9`：論文目前唯一使用的模型結果。先看中心九顆圓柱的 CD，再看同一組圓柱的 50x/20x 位移。
3. `02_V42_E120_SOURCE_MATERIAL`：V42 epoch 120 正式推論所使用的必要重建影像與執行紀錄，只負責追溯來源，不另外提出結論。

## 目前可以寫入論文的結論

- 在這張 100MG 靜態影像的中心九顆圓柱中，Raw 平均絕對 CD 誤差為 92.99 nm，V42 為 78.18 nm；九顆全部更接近 SEM，但仍有整體偏大的誤差，不能寫成已完成準確的絕對 CD 量測。
- 位移比較固定使用相同的中心九顆圓柱，入選步數只根據 Raw 拍攝時間與二維移動狀況決定，名單鎖定後才比較 V42。
- 在四組 Raw 篩選後、與平台命令一致的步數中，V42 的位移波動與九圓柱局部不一致程度都比 Raw 小；50x 改善最明顯，20x 改善較小。
- 這些結果支持「重建後的邊界量測在這四段篩選序列中較穩定」，不代表模型讓平台本身變穩，也不代表絕對位移準確度已由獨立真值證明。

## 必須同時揭露的限制

20x、0.5 µm 的完整49步若不排除平台未完成水平移動且同時出現垂直偏移的三步，Raw 波動為 74.45 nm、V42 為 75.66 nm，V42略差。正式候選結果排除的是 Raw 本身已確認的第15、45、46步，而且規則在查看V42比較前已鎖定；論文中必須把這項限制放在篩選結果旁邊。

所有舊模型、中途權重、舊檢測方法、被取代的報告與未採用倍率，均已移出本正式閱讀路徑並保存在外部歷史歸檔。
