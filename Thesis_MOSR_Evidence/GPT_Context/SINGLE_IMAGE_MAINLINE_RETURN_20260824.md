# 單張主線回歸決策

日期：2026-08-24

## 決定

多觀測重建不再作為 MOSR 下一代通用模型主線。它保留為受控拍攝下的選配研究功能：同位置 N=2 可繼續研究降噪與位移穩定；跨位置 N=4 暫停神經網路訓練，除非非學習式資訊上限或新的刻意微位移拍攝證明存在可恢復的額外相位資訊。

正式 baseline、approved alternates、V42 論文模型與 R61 研究／交付候選角色均不改變。完整 R106、ONNX 與外部 GMF 包均不啟動。

## 依據

- R105A 證明理想輪廓可以生成清楚影像，但模型估錯輪廓時，直接生成會放大位置錯誤。
- R105B 證明具有充分互補資訊的多觀測在程序上可改善幾何，但其早期可信度方法失敗。
- R105C 證明均華影像可穩定分組與跨位置對齊；同位置雙張位移中位數 0.091 px，跨位置最近整數相位差中位數只有 0.161 px。
- R106A 在同一鎖定權重下，N=2 改善輪廓距離；N=4 繼續降低影像誤差與位移尾端，卻不再改善輪廓與邊界中心，曝光穩定性反而變差。
- 均華真實 N=4 幾何安全，但沒有獨立真值證明比 N=2 更準；現有單張 R61 已在相同固定 GMF 流程上有直接外部實測支撐。

## 回歸後的模型期待

新主線必須保持：

1. 單張影像即可使用，不依賴序列或拍攝協定。
2. 大圖原生分塊一致，輸出固定錨定輸入座標。
3. 邊界位置、邊界寬度、亮度與材質細節分開表示，不再用整體銳化同時承擔所有目標。
4. 清楚輸入可精確不修改；低證據區域可確實關閉修正。
5. 真實 SEM 輪廓、5x／20x／50x、位移、曝光、full/tile 與外部 GMF 分別驗證，不以單一平均分數宣布成功。

## 下一個方法

下一個短探針為 `R107A_SingleImageEdgeGeometryProbe`。它不先訓練完整影像到影像網路，而是把單張邊界寫成局部法線座標：

- 邊界中心由輸入影像的局部梯度／相位證據估計並鎖定。
- 模型或分析器只估計過渡寬度、局部對比、極性與可靠度。
- 第一階段只允許以固定中心縮窄單調邊界，不允許自由搬動全局輪廓。
- 切線方向材質與平坦區紋理保持獨立，避免邊界銳化製造暗邊或抹除材質。

只有當非學習式／小型參數探針能在不移動中心的前提下改善邊界寬度與 ACM，才允許建立完整 scratch 模型。
