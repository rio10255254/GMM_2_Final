## 為什麼可以確定

1. 目前資料夾的 18 張 TIFF，與當年 MATLAB 對位資料夾的 18 張 TIFF，逐張完全相同（18/18）。
2. 當年的 `SEM2img_v2.m` 明確寫下 P-01～P-09、V-01～V-09 各自放回光學 3×3 網格的位置。
3. `via_pilar.xlsx` 的 `SEM data` 工作表保留了中央 36 顆的 6×6 編號排列。
4. 影像本身都是規則的四顆圓柱，只靠形狀不足以可靠辨識順序；原始對位紀錄才是決定性依據。
