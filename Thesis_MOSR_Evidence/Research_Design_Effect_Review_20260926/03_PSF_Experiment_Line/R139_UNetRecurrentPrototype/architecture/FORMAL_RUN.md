# R139 U-Net 正式訓練入口

**本文件優先於早期 README 的「架構原型」狀態。** R139 原型已通過資料與影像尺寸前置檢查；依使用者要求，正式版本將用 GPU 從零訓練，之後自動完成全部真實影像量測。

## 與近期實驗一致的條件

| 項目 | 固定條件 |
|---|---|
| 合成資料 | 與 R130／R137／R138 相同的 512 訓練、128 開發、128 生成測試母場景；陣列由同一資料夾讀取，每筆按雜湊核對 |
| 種子 | 模型 1309001、順序 1309002、噪聲 1309003 |
| 訓練預算 | 16 循環，共 8192 次；從零開始，不載入任何歷史神經權重 |
| 裁切 | 原384；320輸入，中心128監督 |
| 損失 | 影像 + 0.2 梯度 + 0.2 位移配對殘差；沿用既有程式原值 |
| 優化 | AdamW、最高0.001至最低0.00001、128次暖身後餘弦、權重衰減0.00001、梯度限制5 |
| 選模型 | 預先固定最後第8192次，不用真實結果挑選 |
| 數值 | FP32、TF32關閉、確定性設定；RTX A6000 |
| 真實驗證 | 同30趟×31張，共930張正常拍攝；同角落九顆、同追蹤／ACM／最大梯度／最小平方圓／LSC與兩個SEM方向候選 |

## 本代刻意改變

主幹改為真正三層下採樣、上採樣及跳接的 U-Net，保留原圖參考及四次共用修正。V42 八候選 PSF 接在半解析度解碼位置，僅在最末次修正使用一次。光學分支前兩個訓練循環關閉，其後從0.12逐步到0.28；光學參數學習率為主幹5%，每次更新後把 beta 原始值保留在可恢復區間。**因此結果同時包含新主架構與光學訓練方式改變，不能稱為單獨 U-Net 消融。**

## 自動流程與監控

`START_R139_GPU.cmd` 可手動啟動同一完整流程，勿在已有訓練時重複啟動。`MONITOR_R139.cmd` 只顯示進度，關閉監控不會中止訓練。Codex 前景監控會顯示步數、損失、PSF beta 與後續930張重建進度。

正式訓練前建立新來源鎖；原型鎖及前代模型保持原值。checkpoint 每128次保存，若程序中斷，先保留未保存尾段的完整紀錄再從最近保存點重跑尾段。進度與完成標記不是量測結果；必須核對8192次、930張、8370圈、10800筆六方法位移及來源後，才寫 `reports/R139_RESULTS.md`。

大型重建數值放 H 槽本輪專用資料夾，D 槽保存程式、checkpoint、表格及圖。`results/reconstruction` 為指向本輪 H 槽的目錄連接。
