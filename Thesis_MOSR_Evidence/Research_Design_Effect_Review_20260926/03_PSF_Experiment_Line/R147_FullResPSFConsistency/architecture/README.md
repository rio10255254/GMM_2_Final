# R147 — 原尺寸 PSF 成像一致性修正

**目前狀態：8192 次從零訓練、930 張實拍／8370 顆圓與最後稽核完成；2026-09-26 的模型內部深度診斷亦完成。**[完整結果](reports/R147_RESULTS.md) · [內部剖析與歷史對照](reports/R147_INTERNAL_AUDIT.md) · [下一版改良計畫](reports/R147_OPTIMIZATION_PLAN.md)。本輪保留 R146 指定的研究版 25 顆 PSF 與全部 768 組清晰／模糊配對，只改模型怎樣使用 PSF；R146、R145 及原交付 PSF 均不覆寫。

## 目的與取捨

前兩輪雖使用真實 PSF 製作模糊配對，舊光學分支卻在半解析度非線性特徵上做位置錯位且作用極弱的反推，逐張 PSF 選擇器在已知合成標籤上也接近隨機。本輪先採 **25 顆研究 PSF 的固定平均**，不宣稱逐張自適應。它在相機原尺寸影像上計算「目前重建再模糊後，與拍到的影像相差多少」，把這個差及其 PSF 回投結果提供給原四次共享修正網路，並做有界的物理一致性修正。已知圓柱、平坦影像和測試點的計算與獨立卷積相符，中心不再移到角落。

這不是輸出後處理；這一步在模型每次運算內，最終保存的浮點影像就是模型原生輸出。資料、分組、雜訊、初始種子、8192 次更新、影像／梯度／配對位移訓練目標維持 R146 規格；模型通道與 PSF 使用方式為這輪明確變更。原資料內雖有合成 PSF 編號，本輪固定平均模式不訓練舊選擇器。

原尺寸運算先通過[物理檢查](results/native_psf_operator_validation.json)：對照獨立卷積的最大差低於 0.000001、平坦亮度不變、中央點留在中央，已知模糊的成像差往正確方向下降。四次物理步長起始值 0.3，只用 40 組合成保留場景事先選定，沒有看 930 張實拍來挑；[合成預先檢查](results/optical_step_preflight.json)中 40/40 組的清晰影像差下降。

## 固定完成標準

在第 8192 次的完整權重上，執行與 R146、R145 相同的 30 趟／930 張、九顆圓和 PI 軸讀法，分開比較短步、長距離、直徑、輪廓、相同 SEM 參照及速度；核對 8370 顆圓、單張重播、光學分支開關和全部收據。事先計畫見[驗證計畫](reports/R147_VALIDATION_PLAN.md)。研究版來源及本輪模型不自動升級正式基準。

正式訓練與結果透過本包 `runs/formal_8192/`、`results/` 連至 H 槽，D 槽保留程式、資料與正式報告。先前磁碟滿載期間的 H 槽可執行驗證副本亦保留；D 槽正式文件已在空間恢復後同步。來源身分見[MANIFEST](MANIFEST.md)。分支：`sandbox/r147-fullres-psf-consistency`。
