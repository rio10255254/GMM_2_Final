# 快速導覽

## 如果只想知道目前哪一版適合什麼

- 短步位移：先看R140v2。
- 直徑重拍穩定：先看R137；R147次佳且提供不同PSF機制證據。
- 輪廓與去尺寸形狀重拍：先看R145。
- SEM平均直徑差：R143數字最小，但它是整體收縮且重拍變差，不當作普遍尺寸準確模型。
- 最新改良：R148v2仍在訓練，尚未排名。

这些用途排名都是同一批30趟、930張、九顆圓的研究比較。正式基準仍由專案治理文件決定，研究排名不會自動替換正式基準。

## 如果想理解為什麼PSF更準卻沒有更好

依序閱讀：R145限制分析 → R146原因核對 → R147內部剖析 → R148架構重新判斷。核心答案是：PSF只描述成像模糊；網路如何使用、訓練資料覆蓋、輸出邊界反應和量測目標是否一致，才決定最後量測。

## 如果想設計下一版

依序閱讀：R122原理 → R131反覆次數 → R133尺寸機制 → R137原尺寸主幹 → R140v2穩定U-Net → R148／R148v2。

## 名詞界線

- 重拍穩定：同一位置在30趟之間的波動。
- 平均差：模型量得的平均與PI或SEM參照的差。
- 尺寸準確度：還需要獨立尺度、材料邊界與來源獨立的真值；不能由重拍穩定或同九顆SEM平均差單獨證明。
- 模型原生輸出：正式比較使用浮點模型輸出，預覽圖不參與量測。
