# R140v2 訓練與驗證固定規格

R139 的 U-Net 於第 128 次更新前發生修正輸出飽和，最後退化成幾乎直接輸出原圖。R140 初版加入像素內跨通道正規化、縮小學習率與輸出增益，256 次拋棄權重短測通過；但正式啟動前發現複製的資料讀取及損失程式只有文字相同、位元組與 R130 原件不同，來源鎖定因此拒絕。R140 沒有正式訓練更新。R140v2 另立資料夾，對兩份程式逐位元複製並重新執行短測；不得修改舊鎖定檔以通過檢查。

固定 512／128／128 個合成母場景、同 R130 的資料和損失、模型／順序／噪聲種子，從零訓練 8192 次、16 輪，每 128 次保存、每 512 次固定開發檢查，最後 128 個母場景生成測試。原圖 384 裁切 320，中心 128 監督；損失為影像 + 0.2 梯度 + 0.2 配對殘差。正式訓練不使用實拍、SEM 或 PI 答案。所有既有模型、舊結果及其來源校驗保留。

模型保留三層 U-Net 編碼解碼與跳接、抗混疊上下採樣、同一修正網路反覆四次、原圖參考。對照 V42 的正規化思想，在每個像素的通道內正規化；輸出頭增益 0.1，主幹最高學習率 0.0003、最低 0.000003，梯度限制 1。25 顆既有實測 PSF 的固定八顆候選，於半尺寸解碼層、最後一次修正使用。前兩輪關閉 PSF，其後權重比例由 0.12 升至 0.28，光學參數學習率為主幹的 5%。這一輪同時改動數項穩定性措施，不把效果歸因於某單一措施。

正式啟動條件：256 次短測的固定生成資料誤差及輸出飽和門檻通過；完整影像初始等值前向通過；資料、程式、舊證據、實拍測量資料全部核對。正式訓練在第 32、128、256、1025、1152、1536 次另做停止門檻。只有固定最後一步模型通過 8192 次和生成檢查，才執行 930 張真實顯微影像重建及共同輪廓／位移比較。沒有未見保留集；既有 SEM 對照可能與光學校準來源相關，不作獨立絕對準確度宣稱。

執行時看 `runs/formal_8192/status.json`、`runs/pipeline_status.json`；最終只依完整結果報告、影像和量測核對判斷是否有用。正式基準不自動替換。
