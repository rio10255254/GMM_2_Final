# R134 直接影像狀態修正

雙擊 **STATUS_R134.cmd** 查看當下進度。[當前結果與限制](reports/R134_RESULTS.md)會隨實際執行階段更新。

A/C兩個設計、兩個全新起點各512次短訓練已完成，兩個C起點都通過正常實拍SEM及12對位移篩選。全部201張影像已完成並恢復核算，20項條件有1項未通過；沒有建立獨立長訓練包，也沒有開始長訓練。

本輪已停止後續推進。原先設計的程序會依次檢查完整影像資格、製作本代獨立包、實跑資料核對及搬移重建、測試暫停續訓、開始8192次延續訓練，最後再做完整實拍比較。任何失敗都保留記錄，停止後續推進。關閉此狀態視窗不會停止背景程序。

每個值得長訓練的代別各自一包，不混合不同模型。合格的R134 C預定放在既有Model_Packages下；實際建立後，本頁的狀態工具會顯示位置，包內START_R134.cmd提供手動操作。這個新包尚未建立時，工具會明確顯示。

B/D新成像規則仍缺獨立材料校準，尚未執行。原R129與資料保留；A/C短訓練未使用舊神經模型權重或SEM評估答案。全部實拍比較為重用的開發資料，不是新未知樣品驗證。
