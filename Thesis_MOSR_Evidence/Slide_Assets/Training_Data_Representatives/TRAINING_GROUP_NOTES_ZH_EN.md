# Training-data category notes for presentation

## Shared training flow

All examples are paired data. The **Source** image is given to the model and the **Label** image is the target it learns to reconstruct. The V42 run grouped the data by role, target dataset, magnification, and shape family, then balanced the groups so that a large category would not completely overwhelm smaller SEM-referenced categories. In the recorded V42 run, the main backbone was retained from the previous model and the quality, boundary-correction, and output portions were refined using these paired examples.

所有案例都是成對資料：**Source** 為模型輸入，**Label** 為模型學習重建的目標。V42 訓練時依資料角色、目標資料集、倍率與形狀分組，再進行分組平衡，避免大量資料完全蓋過數量較少的 SEM 參考資料。實際 V42 訓練保留前一階段已建立的主幹能力，主要針對品質、邊界修正與輸出部分進行微調。

## 1. Mixed boundary fields — R55 foundation data

**Scale:** 3,700 pairs within the 6,000-pair R55 scratch-training set.  
**How it is made:** The source images contain complex edges, corners, checkerboard-like fields, non-uniform backgrounds, and different blur patterns. The label retains the grayscale style of the source rather than being converted into a purely black-and-white mask. When a label was repaired, earlier CAD or label images were used only to identify the edge band; they were not copied directly as the output target. Boundary, centreline, and distance maps were also preserved for each pair.

**Training purpose:** This is the basic visual-language stage. It teaches the model that a boundary can appear at different orientations, contrasts, and local backgrounds, and that a useful reconstruction should clarify the transition without turning every edge into an artificial binary contour.

**Chinese slide sentence:**  
以複雜邊界、角點與非均勻背景建立基礎的邊緣辨識能力，避免模型只適應單一規則圖形或單一模糊型態。

**English slide sentence:**  
Complex boundaries, corners, and non-uniform backgrounds establish fundamental edge recognition without restricting the model to one regular shape or blur pattern.

## 2. Multi-shape fields — R61 universal synthetic data

**Scale:** 4,096 pairs.  
**How it is made:** A known geometry is rendered as circles, ellipses, rectangles, thin bars, polygons, annuli, or mixed fields. Each geometry is rendered in both bright-on-dark and dark-on-bright appearances, then blurred and corrupted with controlled noise. The label is the known underlying geometry, with controlled sub-pixel boundary offsets included across the dataset.

**Training purpose:** The category separates geometry from appearance. It teaches the model that the same boundary should remain meaningful when contrast polarity, shape family, blur, or noise changes. The annular examples are particularly useful as a bridge to via-like structures.

**Chinese slide sentence:**  
以多種形狀與明暗極性訓練模型分辨真正的幾何邊界，而非記憶特定的亮暗外觀。

**English slide sentence:**  
Multiple shape families and contrast polarities teach the model to recognize geometric boundaries rather than memorize a specific bright or dark appearance.

## 3. Textured motion — R61 motion-texture data

**Scale:** 4,800 images, organized as 2,400 two-frame motion pairs.  
**How it is made:** A synthetic geometry is first blurred and given a procedural camera-like texture. A second frame is generated by applying a known horizontal and vertical shift to the same scene, followed by controlled frame-level texture variation. The label for each frame is shifted by the same known amount, and the displacement is recorded with the pair.

**Training purpose:** This category teaches that a reconstruction should preserve the relative position of a feature when the image moves. It is not only an edge-sharpening example; it provides a known positional relationship under texture and noise.

**Chinese slide sentence:**  
在紋理與雜訊存在時，以已知位移關係訓練模型保持結構位置與輪廓的一致性。

**English slide sentence:**  
Known displacements under texture and noise train the model to preserve both structural position and contour consistency.

## 4. Step-motion guard — R61 step-like motion data

**Scale:** 3,200 images, organized as 1,600 two-frame motion pairs.  
**How it is made:** This set uses the same paired-motion concept as textured motion, but the displacement follows a predefined step-like cycle. The source contains a procedural texture and the second frame is generated from the same geometry using the recorded step. The labels undergo the identical shift. This is a controlled synthetic set; it does not use real stage-motion images.

**Training purpose:** The purpose is to make the model conservative about discrete movement. Because the correct change in position is explicitly known, the model is discouraged from changing the apparent location or shape more than the input displacement warrants.

**Chinese slide sentence:**  
以已知的離散步進位移限制重建結果，降低模型在影格間自行改變結構位置的傾向。

**English slide sentence:**  
Known discrete motion steps constrain reconstruction, reducing unnecessary changes in apparent feature position between frames.

## 5. SEM-referenced patches — real microscope anchors

**Scale:** 1,400 pairs.  
**How it is made:** Real HS-100MG microscope crops containing pillars or vias are used as sources. For each crop, the associated SEM reference geometry provides the target radius and the corresponding training label. The record retains the measured optical radius, SEM radius, target radius, location, and neighbouring features.

**Training purpose:** This is the geometry anchor. Its number is smaller than the synthetic sets, but it ties reconstructed optical boundaries to an independent size reference, which is why it is important for later CD-related interpretation.

**Chinese slide sentence:**  
以真實顯微影像搭配 SEM 幾何參考，將重建邊界連回可量測的 pillar 與 via 尺寸。

**English slide sentence:**  
Real microscope patches paired with SEM geometry anchor reconstructed boundaries to measurable pillar and via dimensions.

## 6. Sequence consistency — conservative real-image correction

**Scale:** 1,200 pairs.  
**How it is made:** The source is a real HS-100MG pillar or via crop. The target is not forced directly to the SEM geometry. Instead, it applies a 50% correction from the optical radius toward the SEM reference: for example, a pillar may be partly shrunk or a via partly expanded. This conservative target keeps the correction direction while avoiding an excessive one-step geometric change.

**Training purpose:** This category suppresses frame-to-frame over-correction. It teaches the model to move an uncertain boundary in the right direction while retaining a stable, realistic morphology instead of forcing every image to the same hard target.

**Chinese slide sentence:**  
以朝向 SEM 參考的半量修正，兼顧邊界改善與影格間形貌穩定，避免過度校正。

**English slide sentence:**  
A half-step correction toward the SEM reference balances boundary improvement with frame-to-frame stability and avoids over-correction.

## Unshown but important: clean synthetic motion

The R61 package also contains 4,800 clean synthetic motion images, organized as 2,400 paired frames. It uses known shifts but without camera-like texture. It is not shown in the current slides because the textured-motion examples communicate the idea more clearly, while the clean-motion set serves the same positional-learning principle in a simpler visual setting.

R61 另外包含 4,800 張乾淨的合成位移影像，也就是 2,400 組雙影格配對。它同樣具有已知位移，但不加入相機紋理。投影片未優先展示此類別，單純是因為含紋理位移的視覺意義更完整；兩者在位置學習上的核心原理相同。
