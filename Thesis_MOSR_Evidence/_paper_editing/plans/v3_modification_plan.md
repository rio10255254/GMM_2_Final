## 為什麼不用 tracked changes

docx tracked changes 對 XML 操作風險高(包 `<w:del>` / `<w:ins>` block 容易破壞文件結構,如果中間 cell/run formatting 複雜會 corrupt 整個 docx)。**改採直接修改 + 完整 diff 報告**做 audit trail,讓你打開 docx 看到的是乾淨的最終版,要 review 改動就看 diff 報告對照。

如果你後續要 tracked changes 版本:Word 內可用「審閱 → 比較 → 比較文件」功能,選 v2 vs v3 自動產出 tracked changes 版,完全不依賴我寫進 XML。
