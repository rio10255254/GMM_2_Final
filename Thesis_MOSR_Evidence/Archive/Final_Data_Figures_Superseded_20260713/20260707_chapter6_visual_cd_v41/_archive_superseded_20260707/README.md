The main thesis-use path is the parent folder, not this archive.

- `figures_legacy/`: old center-9 figures, old single-line profile figures, unclipped or combined draft maps, and the old cross-section overlay.
- `tables_legacy/`: old center-9 tables, single-profile tables, and the old asset manifest.
- `tables_profile_raw_samples/`: bulky raw per-sample profile CSV files that can be regenerated from the active scripts.
- `reconstruction_duplicate_runtime/`: duplicated reconstruction runtime folders, logs, intermediate raw output copies, and old GMF-path helper files.
- `logs_and_empty/`: old prepare logs and empty source-copy folders.
- `scripts_legacy/`: old single-line profile generation script superseded by the separated cell and edge-aligned profile figures.

Nothing here is needed for the current main thesis evidence figures or tables.
