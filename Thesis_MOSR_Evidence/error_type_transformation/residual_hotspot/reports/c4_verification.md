# C4 驗證報告 — 邊界殘差熱點集中度

Last updated: 2026-05-26
腳本:`scripts/collect_k2_hotspot.py`(共用 collector,跟 k=2 同源)
資料來源:`Experiments/R38v2SeqFixed/results/720angle_analysis/<cand>/<pitch>/sequence_summary.json`

## 結論

**C4 通過,而且模型重建會「製造」邊界熱點。**

- **Input(raw)的熱點集中度幾乎為零**(persist_fraction ~ 0.000-0.003)——raw 影像的邊界殘差是隨機分散的
- **Output(model recon)的熱點集中度跳到 0.05-0.12**——所有候選都把分散的殘差**製造**成集中於少數固定角度的熱點
- **訓練程度越深的候選,熱點越集中**(R30 < R33 < R38v2 ≈ COMBO,熱點 amplification 22-40 倍)

## 為什麼 hotspot 是「型態轉換」的直接證據

論文 4.8.5 第三項判準:**「邊界殘差熱點從零散分佈轉為少數固定角度的穩定分佈」**。

具體量化:`persistent_angle_fraction_gt50pct` 是「在 >50% 的幀都顯示熱點的角度比例」。如果殘差是隨機散布,這個值應該接近 0(沒有任何角度在大多數幀都熱)。如果殘差被結構化成「特定角度反覆出現」,這個值會明顯非零。

**Input 跟 output 的對比是 C4 最乾淨的呈現**——同一份 raw 序列,經過模型重建後,熱點從散變集中,證明模型「製造」了結構性偏差。

## 主軸支撐解讀

論文 main claim 的關鍵主張之一是:**「隨機誤差被重新分配為結構性偏差,結構性偏差表現為邊界殘差集中於少數固定角度」**。

C4 結果直接證明:
- **Input raw 影像沒有結構性熱點**(persist_fraction ≈ 0)
- **Model recon 製造出熱點**(persist_fraction 0.05-0.12)
- **訓練越深(R33/R38v2/COMBO 比 R30)熱點越集中**

這個證據鏈非常乾淨——熱點不是 raw 影像本來就有的,是**模型重建過程中**從隨機殘差**結構化**出來的。**這完全對應論文 main claim**。

## 為什麼「熱點集中」是好事而非壞事

讀者乍看可能覺得「熱點集中」聽起來不好(誤差跑到固定角度)。實際上對量測應用而言,**熱點集中是 good news**:

- **隨機分散的誤差**:每幀位於不同角度,**無法後處理校正**,只能用 SNR 改善降低
- **集中於固定角度的熱點**:**可以後處理識別並補償**,屬於可校正的系統性偏差

論文 4.8.5 跟 7.2 對 metrology 的意涵這樣寫:**「σ̂ 逼近 CRB 後,b 變成後處理可補償的標的」**。C4 就是這個論述的直接證據——熱點集中代表 b 結構化,而結構化的 b 是「可補償的」,不是「沒辦法處理的」。

## C4 falsification check

**C4 通過判準**:output persist_fraction > input persist_fraction(模型製造熱點而非消除)
- 24 個 (candidate × scale × boundary) cell 中**全部 24 個都通過**

**沒有候選的 output 熱點 < input**,所以 C4 完全沒被任何候選推翻。

## 限制

- **input 在所有候選共用**(raw 影像相同),所以 input persist_fraction 沒有候選間差異,主軸論證來自 output 的差異
- **R30 的熱點集中度也明顯高於 input**——這代表「模型製造熱點」是所有重建模型的共通特性,不只是 R33+ 後訓練的功勞。論文要寫清楚這個 nuance,避免讀者誤以為「熱點集中是某個訓練技巧獨有的」
