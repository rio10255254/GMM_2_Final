## 已實際重算的範圍

使用原`generate_absolute_spectra.py`內兩個未改動的FFT函式，以兩張相機原拍裁切、兩張既存V42輸出裁切及兩份Wiener完整小數陣列為輸入，核對兩份原NPZ的16個欄位，共458832個數值，全部逐值相同。相機裁切仍是裁切，不能冒稱完整相機原圖；V42輸出明確標為模型結果。

計算保留原振幅與dBFS定義，不去均值、不加視窗、不各圖重新拉高峰值。圖上低於-80 dBFS的區域雖同為最暗色，NPZ仍保留原完整數值。這是已保存來源到頻譜的核對，不是重新擬合PSF、重新執行V42或重跑訓練。

九份必要小型原件合計約5.1MB，連同[原件身分與角色](SPECTRUM_SOURCE_FILES.json)納入一般GitHub程式版本，讓讀者能從小型下載直接重算。兩張現存圖與兩張較早圖也分別保存。沒有自動決定論文應採用哪一版。

取得本次固定程式版本並安裝NumPy、SciPy與Pillow後，在專案根目錄執行：

```powershell
python Tools/replay_psf_spectrum_sources.py --root . --report spectrum_replay.json
```

程式先檢查九份原件，再只執行原來的兩個計算函式。它不執行原圖表寫入入口，不改論文影像；任何原件或參照數值不符都會停止。較早圖的讀取核對與目前數值重算，分別記錄於[圖版本對照](../project_completion/SPECTRA_IMAGE_VERSION_REVIEW.json)及[目前重算收據](SPECTRUM_REPLAY_VERIFIED.json)。GitHub實際下載後的核對另以取回收據記錄，沒有用本機通過代替遠端取回。
