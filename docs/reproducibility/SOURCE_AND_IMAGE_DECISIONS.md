# 必要來源與影像的保存判斷

程式可以重新產生某些訓練影像，卻無法重新拍出當年相同的相機照片。因此共用實拍、平台紀錄、SEM原圖、固定光學數值與無法精確重做的早期幾何標記都要保存實際檔案。

## 各類來源的用途

| 來源 | 保留內容與理由 | 解讀限制 |
|---|---|---|
| 2026-09-03位移重拍 | 全930張原始BMP與30份原始CSV；原始ZIP、凍結清單與取得脈絡一起保存 | 平台讀值是原實驗參考，不等於已完成獨立物理校正 |
| Step | 完整788張相機照片，保留原檔名、時間順序與各分析的選取紀錄 | 從同一來源裁切出的影像仍有共用來源關係 |
| 5／20／50倍連拍 | 原拍攝資料與301張固定分析輸入均保留，重複內容只存一次 | 位移與細節穩定性不能取代同樣本SEM尺寸真值 |
| 六組外部位移照片 | 保留原始實拍與同位置重拍順序，包含較短步距與兩個方向 | 相鄰輸出若共用來源，不能算作獨立證據 |
| SEM與成對光學圖 | 18張P/V原圖、原工作表、36顆排列、兩個固定方向候選、完整輪廓參照與原配對程式 | R61等模型曾使用相關SEM答案；來源關係隨分數一併保留。裁切版光學圖與原SEM各自標示 |
| R61固定早期來源 | 繼承的3,400組影像與10,200份幾何檔；其餘16,896組可由固定配方重做，已核對全檔案集合 | 只留種子會漏掉當時繼承的幾何結果 |
| R93／R118等共用生成資料 | 多輪直接沿用的固定來源整套保存，不將「有生成程式」等同於「本次已證明每輪精確重做」 | 留出資料的歷史封存、開啟與使用規則保留，不重新替它取得獨立資格 |
| 固定模型 | 正式、比較、失敗、初始化與方法明確引用的中途模型；內容相同者不重複保存 | 最後完成的模型不一定是當年被選用的模型 |

## 哪些影像放進一般倉庫

一般倉庫保存報告實際引用的比較圖、必要示意與少量原尺寸示例。完整相機資料與大型必要來源放在GitHub版本附件，讓讀者能下載真正的原檔，避免把大量可重新計算的逐張重建塞進一般版本歷史。

選圖必須能解釋該輪結論。除了原圖／答案／重建同區域對照，也要保留暗曝光、較差尺寸、失敗輪廓、錯誤方向、停止訓練與切片設定造成的變化，不能只挑最好看的輸出。

例如R75v2在5倍影像上抹平細網格，因此保留512、768、1024切片與原圖的共同視野。R139只產生固定亮度偏移的失敗，與它的量測曲線和診斷一起保留。R152／R153保留穩定性收益、SEM尺寸差、長距離限制和速度代價，不用單一總排名掩蓋取捨。

每一輪更具體的來源與選圖理由見[逐輪入口](EXPERIMENTS.md)。完整表格不依選圖篩選；歷史報告失效的絕對路徑或缺圖連結另列核對，不補造原結果。
