# 主R122至140：真實需求與量測比較

[全部分區](../EXPERIMENTS.md) · [研究沿革](../lineage/README.md) · [目前保存狀態](../STATUS.md)

對齊資料、SEM與量測定義，再讀完整比較和方法限制。

以下是閱讀順序，不表示相鄰兩輪必然繼承同一模型或資料。原正式報告優先於卡片的早期摘要。

| 實驗 | 研究問題 | 判讀與限制 |
|---|---|---|
| [main/R122_OperatorPrinciples](../experiments/main__R122_OperatorPrinciples.md) | 驗證位置／寬度操作與V42訓練來源 | 插值不保證獨立操作；V42評估來源重用訓練，不能稱未知驗證 |
| [main/R123_RealFirstModelDesign](../experiments/main__R123_RealFirstModelDesign.md) | 以真實量測需求制定下一代模型 | 是設計與既有結果核對，沒有新模型成績 |
| [main/R124_RealFirstPrototype](../experiments/main__R124_RealFirstPrototype.md) | 實作四步二維重建及可保存重載的原型 | 未訓練、未校準；執行正常不能當量測改善 |
| [main/R125_DataAlignedPilot](../experiments/main__R125_DataAlignedPilot.md) | 先對齊資料形成與模型，再實際小訓練 | 第一版資料失敗、第二版六組64次完成但不採用 |
| [main/R126_LearnabilityPhotometry](../experiments/main__R126_LearnabilityPhotometry.md) | 先確認簡單例子能學，再匹配測試亮暗擴充 | 固定例子改善，但實體參照分歧、乾淨輸入改動及位移跳動仍在 |
| [main/R127_MeasurementPreservationRepair](../experiments/main__R127_MeasurementPreservationRepair.md) | 修正SEM比例／取邊、位移有效性與條件原樣保留 | 軟體修復與物理校準分開，沒有新訓練或獨立物理準確度 |
| [main/R128_SourceOnlyFullTraining](../experiments/main__R128_SourceOnlyFullTraining.md) | 用獨立生成來源做四個完整研究訓練 | 四次8192完成；保留選定研究版本、暗曝光代價、細形狀與較慢速度 |
| [main/R129_OpticalPriorHybrid](../experiments/main__R129_OpticalPriorHybrid.md) | 恢復光學融合、抗混疊與原圖參考 | 短測、長訓練、80／16邊緣保留及完整LSC是不同版本；尺寸代價保留 |
| [main/R130_Clean](../experiments/main__R130_Clean.md) | 移除光學與放大，採原尺寸純神經模型 | 8192與930影像完成；較快、尺寸重拍較好，尺寸偏差仍在 |
| [main/R130_CleanV42Comparison](../experiments/main__R130_CleanV42Comparison.md) | 以乾淨來源從頭訓練V42作實用比較 | 32輪實用比較，訓練時間與起點未做完整因果匹配 |
| [main/R131_RecurrentStepValidation](../experiments/main__R131_RecurrentStepValidation.md) | 同一R129模型使用0到4次修正的得失 | 零次仍含光學與輸出規則；這不是不同深度從零訓練比較 |
| [main/R132_BoundaryPolicyStudy](../experiments/main__R132_BoundaryPolicyStudy.md) | 檢查原圖保留帶是否過寬 | 16像素只作研究選項，尺寸與橫向代價仍需保留 |
| [main/R133_SizeMechanismDiagnosis](../experiments/main__R133_SizeMechanismDiagnosis.md) | 拆解尺寸偏大來自光學、學習還是最後輸出 | 沒有找到可直接套用的統一縮小公式；成像與材料參照仍需核對 |
| [main/R134_DirectStateRepair](../experiments/main__R134_DirectStateRepair.md) | 直接修正影像狀態並避免8bit存檔誤導 | 精度修正版長訓練與最後比較完成；舊8bit失敗仍保留，尚未正式採用 |
| [main/R135_UnifiedModelComparison](../experiments/main__R135_UnifiedModelComparison.md) | 統一模型、保存精度與SEM／位移量法 | R61使用35顆評估SEM答案的限制必須與分數同時呈現 |
| [main/R136_PIRepeatability](../experiments/main__R136_PIRepeatability.md) | 用30趟重拍檢查固定模型的位移與不確定度 | 區域比對與LSC兩套數字分開；四方法追加保持先前包不變 |
| [main/R137_WeakPSFFeature](../experiments/main__R137_WeakPSFFeature.md) | 以低強度光學線索輔助原尺寸模型 | 短步與輪廓小改善、尺寸偏大；共用GPU舊計時不能直接排名 |
| [main/R138_V42PSF8](../experiments/main__R138_V42PSF8.md) | 讓八候選光學機制反覆作用於特徵 | CPU與裝置續行要保留；光學強度後期歸零不能稱選擇成功 |
| [main/R139_UNetRecurrentPrototype](../experiments/main__R139_UNetRecurrentPrototype.md) | 恢復U-Net並把光學放回解碼位置 | 後續8192訓練早期飽和、退化為原圖；首頁原型狀態已過時 |
| [main/R140_StableUNet](../experiments/main__R140_StableUNet.md) | 修復R139失穩並加短測限制 | 短測通過但正式來源檢查失敗，沒有正式更新 |
| [main/R140v2_StableUNet](../experiments/main__R140v2_StableUNet.md) | 獨立重新封裝穩定U-Net | 8192與930完成，光學仍等權；短步收益與尺寸限制分開 |
