「已整理」不等於已重新訓練；各輪驗證範圍與缺件另列，原始成功、失敗與中止狀態全部保留。

2026-10-20 新增 [R93 至 R98 共用來源的 GitHub 取回核對](r93_shared/README.md)：完整固定檔案、五輪原讀取程式、R93固定模型與原選模數字分別驗證。R93漏存的綜合候選及原影像歷程另補；沒有把R94失敗或其他歷史限制改成成功。
