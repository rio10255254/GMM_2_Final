# R33、R38v2／COMBO、R39、R40：必要來源與方法關係

[共用固定環形來源](../../../Shared_Sources/Baseline_Ring_Inputs/README.md) · [各輪研究分區](../EXPERIMENTS.md) · [目前保存狀態](../STATUS.md)

這次沿原啟動程式、配方、選用模型與原報告核對四個研究範圍。13個指定模型、主線PSF，以及535份小型原結果都有既有保存位置；需要補的是生成來源尚未釐清的早期固定環形配對。它們經使用者明確同意共用保存一次，可生成的大資料仍不整批上傳。

## 方法關係不能混成同一種「合併」

| 研究 | 真正做法與必要來源 | 本次確認 |
|---|---|---|
| R33 | 限制極端誤差牽引；共享早期環形配方，R30是當時比較基準 | 原p95選中模型為第22輪；不能把「使用R30配方」直接寫成「一定載入R30模型續訓」 |
| R38v2／COMBO | 使用8px序列、訊號門檻與暖身；COMBO在一次訓練中共同使用p95與序列項 | R38v2選中第54輪，COMBO第21輪；COMBO不是把R33與R38v2兩個模型做權重平均 |
| R39 | 從COMBO接續，加入多形狀；a030另由COMBO與strong端點混合 | safe為1,240對、strong為1,590對、形狀驗證210對；a030每個模型數值與原混合配方一致 |
| R40 | 分別從COMBO或R39 a030接續，增加顯微特徵；a043等另與COMBO混合 | 訓練1,300對、驗證100對；best與latest的取捨分開，未採用的a045失敗仍保留 |
| R39R40 a025 | 以R39 a030與R40 a043為兩個端點，再用0.25比例混合 | 126組模型數值全部與原檔一致；不是直接從兩個原訓練端點做一次同名平均 |

a030、a043、a025與a045四種混合都逐項核對126組模型數值相同；未另寫模型檔或執行推論。這不是宣稱重新序列化的模型檔一定逐位元組相同。[核對範圍與原模型身分](BASELINE_METHOD_CHECKS_20261023.json)。正式COMBO、核准替代與目前R152／RAW論文身分不變。

## 哪些資料不能只留生成器

- 前1,000組早期環形輸入／答案：原生成來源與舊PSF不明，故補存原件一次。
- 後100組：現存內容與已保存PSF處理輸入／共用答案相同，以位置對照恢復，沒有重傳。
- stage25／26序列：共150張乾淨與150張卷積後影像；原Data_Simulaion.py、PSF_Convolution.py與主線PSF保留。本次只核對現存檔案，不聲稱已重生同樣150對。
- R39／R40：五個原資料清單與R40乾淨資料生成設定保留。實際讀取原builder得到原報告相符的配對數；訓練與驗證來源路徑分離不等於未知實拍的獨立驗證。

R40的五種顯微特徵各抽第0、79、80、99張，共20張，用原seed4040生成後與現存答案逐像素相同。這只證明所列抽查，不擴大成完整卷積、所有資料或完整訓練重現。

## 仍有的重做限制

舊啟動器依賴共享Model程式；三份早期run_meta的pretrained_dir其實是該次輸出weights位置，不足以單獨證明初始化模型。部分歷史模型沒有完整設定／原共用程式快照，原紀錄也有非固定GPU設定，因此不能以今天的預設值代填當年操作，不能承諾逐步完全重訓相同。

本次新增的是固定必要來源、原表直接閱讀與方法對照。四輪都是指定面向完成核對，其他歷史來源與精確重訓條件仍按逐輪帳本續查。
