B1052 P style='Normal' drawings=[] :: 由於實際光學系統的成像特性可能隨視野位置而改變，單一且固定的點擴散函數無法完整描述整個相機視野範圍內的成像行為。因此，本實驗將相機的完整可視範圍劃分為10×10個區域，共計100個不同的視野位置，並針對各區域分別進行點擴散函數擬合。此劃分方式可使後續模型在使用PSF資料時，同時考量不同視野位置所產生的空間變異性，避免僅使用中心區域的擬合結果描述整個FOV，進而降低視野邊緣像差與成像模糊差異所造成的影響。相機視野之區域劃分方式如下圖所示。
B1054 P style='Normal' drawings=[] :: 影像拍攝過程以樣品中心附近的同一組pillar結構作為固定量測目標，並透過精密位移平台移動樣品，使該pillar結構依序出現在預先劃分的100個視野區域中。當pillar結構移動至指定區域後，位移平台會停止移動，待系統穩定後再進行影像拍攝。透過此方式，各區域所取得的影像皆來自相同的實體pillar結構，因此可以排除不同pillar之間可能存在的製造尺寸差異，使各區域影像之差異主要反映光學系統在不同視野位置下的成像特性。完成所有區域的影像拍攝後，本研究分別使用各區域的實驗影像進行點擴散函數參數擬合，並建立對應於整個FOV的空間變異PSF資料。

B1320 P style='Heading 3' drawings=[] :: 6.2.8 綜合討論
B1321 P style='Normal' drawings=[] :: 綜合主要比較、學習式對照與配對消融，可回答本研究的三項問題。第一，50倍Wiener雖產生最窄的表觀邊緣，跨門檻CD誤差卻最高，說明最大銳化不是最低CD誤差的充分條件；MOSR則取得最低的跨門檻誤差與最窄CD變動範圍。第二，在主要Raw、Wiener與MOSR比較中，MOSR取得最低的合併位移偏差與九顆pillar不一致量；抗混疊上採樣的配對消融進一步對應跨位置位移一致性。第三，輸入參考式殘差輸出相較其移除條件降低跨倍率振鈴，並維持較一致的CD量測行為。Via提供獨立SEM尺寸驗證，線條則檢查不同邊界方向下的集中程度與週期保持。
B1322 P style='Normal' drawings=[] :: 本節在同一受控顯微平台，以pillar、via、水平與垂直線條、兩種倍率及兩種位移步距，對照Raw、Wiener、EDSR、NAFNet與MOSR。SEM提供圓形結構尺寸，PI閉迴路設定步階提供共同位移參考；各方法共用影像、結構身分、物體空間尺度、門檻與統計規則，使方法差異能由同一量測鏈直接比較。
B1323 P style='Normal' drawings=[] :: 綜合現有證據，MOSR將顯微影像重建的判斷重點由單一視覺銳利度轉向邊界集中、尺寸穩健與跨位置位移一致性。抗混疊上採樣維持不同pillar間的相對幾何關係，輸入參考式殘差輸出限制最終輪廓改寫，多位置PSF與四組量測導向目標則提供固定光學條件及聯合訓練約束。這套設計使模型能在同一座標系中同時接受CD與微位移檢查。
B1324 P style='Heading 1' drawings=[] :: 結論與未來工作
B1325 P style='Normal' drawings=[] :: 本研究以量測導向超解析為主軸，完成光學先驗建立、單張同尺寸重建、SEM對照CD量測、PI閉迴路微位移量測、配對消融、跨形貌驗證、現代模型比較及運算效能量測。本章彙整研究問題、主要方法貢獻與量化結果，並提出後續工作。
B1326 P style='Heading 2' drawings=[] :: 7.1 研究結論
B1327 P style='Normal' drawings=[] :: 第一個研究問題關注單張同尺寸重建能否改善邊界與CD。50倍結果提供最直接的比較：Wiener的表觀邊緣過渡寬度為467.7 nm，低於MOSR的508.5 nm，但跨門檻CD中位絕對誤差為123.7 nm，高於MOSR的76.1 nm。最窄邊緣因此不是最低CD誤差的充分條件；MOSR的優勢在於同時降低跨門檻誤差與CD上下界寬度。
B1328 P style='Normal' drawings=[] :: 第二與第三個研究問題關注平移一致性及邊界保護。在主要Raw、Wiener與MOSR比較中，MOSR於四組PI閉迴路序列合併後取得最低的位移參考值平均絕對偏差與九顆pillar不一致量。配對消融顯示，抗混疊上採樣降低不同pillar的位移分歧；相較於移除輸入參考式殘差輸出的模型，完整模型則降低跨倍率振鈴，並在20倍CD上得到明顯改善。兩項模組分別對應解碼階段的跨位置一致性與輸出階段的輪廓穩定性。
B1329 P style='Normal' drawings=[] :: 跨形貌驗證顯示，MOSR的量測行為可由暗pillar延伸至亮via與線條。20倍via具有逐顆SEM尺寸，因此可直接比較CD中心誤差與門檻穩健性；水平與垂直線條則用於檢查不同邊界方向的集中程度與週期保持。MOSR在20倍via上優於Raw、EDSR及NAFNet，線條邊界變集中時表觀週期仍維持穩定。
B1330 P style='Heading 2' drawings=[] :: 7.2 主要方法貢獻
B1331 P style='Normal' drawings=[] :: 本研究的第一項主要貢獻，是將解碼上採樣造成的像素相位與空間位置敏感性，轉化為可由九顆pillar共同位移直接檢查的模型問題，並以抗混疊上採樣改善跨位置幾何一致性。第二項主要貢獻，是將輸入參考式殘差輸出建立為量測邊界保護機制，以Raw提供低頻位置基準，只允許幅度受限的高頻修正。兩項設計分別處理解碼階段與最終輸出階段的幾何風險，並由配對消融對應至位移分歧與輪廓穩定性。
B1332 P style='Normal' drawings=[] :: 影像內容、邊界幾何、運動一致性與輸出保守性四組目標，共同把外觀、輪廓、影格關係與非必要改動納入訓練限制。局部PSF建立Wiener對照，多位置PSF則提供固定光學條件資訊。EDSR與NAFNet使用相近參數量、相同資料分組及一般重建目標，使20倍via比較能檢查單純更換現代重建架構是否足以重現MOSR的量測結果。
B1333 P style='Heading 2' drawings=[] :: 7.3 主要量化結果
B1334 P style='Normal' drawings=[] :: 在CD量測中，Raw、Wiener與MOSR跨七個門檻與兩種剖面的中位絕對誤差分別為95.3、123.7與76.1 nm；MOSR相較Raw降低20.16%，相較Wiener降低38.48%。九顆pillar的CD上下界寬度中位數則由Raw的354.5 nm與Wiener的429.6 nm降至MOSR的143.3 nm，顯示MOSR的表觀邊界對量測規則較不敏感。
B1335 P style='Normal' drawings=[] :: 在四組位移序列共120個配對步中，Raw、Wiener與MOSR相對PI閉迴路位移參考值的平均絕對偏差為9.54、7.46與6.74 nm，九顆pillar不一致量為17.63、7.92與6.47 nm。抗混疊上採樣相較一般上採樣使合併不一致量降低14.31%；相較於移除輸入參考式殘差輸出的模型，完整模型的20倍CD中位絕對誤差降低42.52%，50倍與20倍振鈴分別降低71.11%與79.70%。
B1336 P style='Normal' drawings=[] :: 在20倍via中，MOSR將CD區間中點平均絕對誤差由644.0 nm降至224.2 nm，門檻區間寬度由432.6 nm降至129.0 nm，10%至90%邊緣寬度由887.5 nm降至180.9 nm。水平與垂直線條的邊緣寬度分別降低14.2%與18.0%，表觀週期變化小於2 nm。2048×1536影像的直接推論中位時間為400.2 ms。
