161 限制 :: 根據傅立葉光學之理論推導，成像平面上的影像可表示為物平面光場與系統點擴散函數（Point Spread Function, PSF）之卷積結果。在此架構下，若已知系統之 PSF，理論上可透過反卷積運算回推物體的原始光場分佈，從而降低由卷積效應所引入之模糊。然而，反卷積結果對 PSF 的準確性高度敏感，因此在實際應用前，PSF 的校正與建模成為不可忽略的關鍵步驟。即便經過校正，直接由顯微鏡量測所得之 PSF 影像仍常受到感測雜訊與有限動態範圍的影響，進而限制反卷積在精細結構與邊界重建上的可靠度。
162 限制 :: 基於上述限制，本研究以參數化模型擬合實測PSF，以降低感測雜訊與有限動態範圍對反卷積的影響。對精密量測而言，卷積與反卷積除了改變影像清晰度，也會影響邊界位置、結構幾何與亞像素特徵的估計。本章依序回顧PSF模型、校正方法、反卷積演算法、超解析卷積神經網路，以及與定位穩定性相關的研究。

208 補充 :: 維納反卷積可視為頻率域中的受控反濾波器；當PSF已知且需要快速處理大量影像時，具有計算效率與雜訊控制上的優勢[46]。Richardson–Lucy方法則以迭代方式逐步修正影像，並可加入正則化以抑制雜訊放大[47,48,49]。兩類傳統反卷積都對PSF準確性與退化假設敏感，當實際模糊具有空間變異或核失配時，復原品質容易不穩定[52,53,55,56]。因此，後續研究逐漸轉向以學習式模型補充或取代固定反卷積流程。
210 限制 :: 相較於傳統反卷積依賴明確的成像模型與PSF／雜訊假設，卷積神經網路可由資料學習低品質影像至高品質影像的非線性映射[40,43,44]。此類方法已用於內容感知、跨模態及電子顯微影像復原[35,71,72]，也延伸至單張顯微重建、物理資訊擴散與像差補償[74,76,77]；近期亦開始重視跨條件的通用復原能力[75]。其優點是推論快速且可涵蓋複雜退化，限制則是結果高度依賴訓練資料與實際成像分布是否一致。本節依代表性模型演進回顧CNN超解析與重建的設計思路。
212 限制 | 不足 :: 早期 CNN 超解析方法以 SRCNN 為代表，其流程通常先以雙三次插值（bicubic interpolation）將低解析影像上採樣至目標尺寸，再由淺層 CNN 對插值後影像進行細節修正。SRCNN 的三個主要步驟可更具體地理解為：第一步「特徵擷取」（feature extraction），透過卷積在插值影像上擷取局部結構與邊緣等低階特徵；第二步「非線性映射」（non-linear mapping），將低解析特徵映射到較接近高解析表徵的特徵空間，使網路能以非線性方式補償插值不足的細節；第三步「重建」（reconstruction），將映射後特徵線性重組為輸出影像，完成超解析結果。其優點是架構直觀、訓練相對容易，並能顯著優於純插值；限制在於效率較差，因為插值上採樣在前，後續卷積運算都在高解析尺度上進行，計算量與記憶體開銷偏高。 [40]

216 限制 :: VDSR 則將殘差學習明確引入超解析任務：由於低解析影像（或插值後影像）與高解析影像在低頻成分高度相似，網路只需學習高頻殘差（細節差異）即可，最終輸出以殘差加回輸入形成重建結果。此設計降低學習難度、加快收斂並提升重建品質，也形成後續 SR 網路設計的重要基礎。其優點在於深網路訓練更穩定、細節復原能力提升；限制在於深模型通常需要更多訓練資料與更嚴謹的正則化/學習率策略，且若訓練資料中的退化模型與真實系統不一致，模型仍可能產生過度平滑或不可靠的高頻補償，影響泛化能力。 [43]

601 允許 :: 因此，本研究保留九顆 pillar 各自的尺寸身分，不先將其平均，也不允許九個尺寸在不同位置之間任意交換。第 顆 pillar 的光學 CD，只與同一物理位置的第 顆 SEM 參考尺寸比較。此逐顆對應可避免一顆偏大的 pillar 所產生的負誤差，與另一顆偏小 pillar 所產生的正誤差在平均後互相抵銷。
604 未 :: 若直接把一個 PSF 矩陣中的每一個像素都當成獨立未知數，需要同時估計 10,201 個參數。這不僅會使最佳化問題過度龐大，也很容易讓雜訊、背景不均與影像配對誤差被吸收到 PSF 中，使最後得到的模糊核缺乏物理解釋。
613 不宜 | 單一 :: 此外，本研究的實際成像使用白光 LED，而式（4-4）是以單一等效光瞳建立的標量傅立葉光學近似。因此，擬合得到的 應解讀為在固定曝光、照明、物鏡、相機響應與樣品反射條件下的等效強度 PSF，而不是單一波長下的完整波前量測結果。相同地，擬合得到的 Zernike 係數是用來描述影像模糊的等效參數，不宜直接延伸解讀為某一光學元件的精確製造誤差。
625 不能 :: 取得最終 PSF 後，其峰值位置、水平與垂直剖面、半高全寬及頻率響應，均由原始數值 PSF 矩陣直接計算。論文中為了顯示而使用的色階拉伸、對數顯示或影像放大，只能用於視覺呈現，不能回頭作為 PSF 寬度、能量或頻譜分析的輸入。如此可避免顯示處理被誤認為實際光學特性。
628 不足 | 不作為 :: 局部PSF適合描述特定九宮格，但不足以代表整個視野。為提供模型一致的光學背景，本研究將多個視野位置的PSF對齊至共同中心並正規化為單位能量，再依倍率建立固定光學先驗。此先驗在完整模型、訓練重複與所有消融條件中保持相同，不作為單獨變動的研究因素。[50,54,55,56]
641 限制 :: 抗混疊上採樣與輸入參考式殘差輸出分別作用於兩個容易改變位置的階段。前者在解碼特徵放大時降低像素相位與空間位置造成的差異；後者在形成最終影像時保留Raw的低頻輪廓、亮暗拓樸與中心基準。固定PSF先驗、邊界殘差上限及品質門控則提供光學方向與修正幅度限制。
658 單一 :: 令編碼器—解碼器產生的主幹輸出為 。邊界修正分支除了讀取目前的影像預測，也參考水平方向梯度、垂直方向梯度、梯度幅值及解碼器提供的局部特徵。水平方向與垂直方向梯度可描述灰階在哪個方向發生變化；梯度幅值則表示該位置是否可能位於結構邊界。解碼特徵則提供較大範圍的結構與背景資訊，使修正分支不會只依靠單一像素的灰階變化作出判斷。
663 限制 :: 局部門控使模型在可能存在邊界的位置使用較完整的殘差，在平坦背景、高雜訊或不確定區域降低修正。殘差截斷則限制最後邊界分支的單點幅度，使邊界修正保持局部且受控。
664 限制 :: 此限制不代表整個網路必然不改變幾何，因為主幹輸出仍由編碼器—解碼器產生。其作用是降低最後修正分支大幅改寫輪廓的自由度，並把真正的有效性留給後續 CD 與位移量測檢查。
666 限制 | 單一 :: 即使將邊界分支的單一像素修正限制在較小範圍內，許多相鄰像素的小幅變化仍可能累積成整體輪廓偏移。例如，若 pillar 左側的一整段邊界都向外增加少量灰階，而右側同時向內減少少量灰階，最後仍可能造成直徑或中心位置改變。
672 補充 :: 式（4-11）表示最終影像由原始影像與受限的模型高頻成分組成。原始影像保留背景、低頻輪廓與主要亮暗，模型則補充局部邊界。係數0.35表示只加入35%的高頻成分，並不是將整張影像對比乘以1.35。
674 補充 | 限制 :: 此設計使原始影像提供背景、平均亮度與大尺度位置，模型主要補充局部快速變化的邊界資訊。高頻成分仍可能包含雜訊或振鈴，因此注入比例受到限制，且輸出平均值再以原圖為基準校正，避免產生不必要的全域亮度偏移。
675 限制 :: 高頻成分也不必然全是真實結構，其中可能同時包含雜訊、振鈴或局部反射紋理。因此，0.35 的比例限制、前一節的殘差上限，以及下一節的輸入品質門控需要共同作用。只有在後續邊緣、CD 與位移指標均呈現改善時，才可認為這些高頻成分具有量測價值。
678 不足 :: 不同輸入影像所包含的可用資訊並不相同。20 倍與 50 倍影像具有不同的物體空間取樣密度；即使倍率相同，曝光、焦點、照明、背景反射與相機雜訊也可能造成影像品質差異。如果所有影像都使用完全相同的修正強度，較清楚的影像可能被修正不足，而品質較差的影像則可能因高頻補償而放大雜訊。
685 限制 :: 輸入參考式殘差輸出負責維持最終輸出的低頻位置；邊界殘差上限限制局部修正；品質門控則依邊界訊號與平坦區噪聲調整整體修正幅度。三者作用於不同階段。
686 限制 :: 這三項機制共同限制模型的輸出，但各自是否能改善CD或位移，仍需在其他條件一致的消融實驗中檢查。
689 單一 :: 本研究模型同時需要學習真實顯微影像的外觀、結構邊界的幾何位置、奈米尺度的尺寸關係，以及連續影像中的位移一致性。然而，現有的任何單一資料來源都無法同時提供上述所有資訊。
690 單一 | 真值 :: 本研究採用多來源監督，不要求單一資料同時提供所有真值。真實影像、合成幾何、SEM與位移資料各自提供其能可靠描述的資訊，再由不同訓練目標共同使用。
691 不能 :: 真實顯微外觀、物理尺寸與位移是不同種類的資訊，彼此不能取代。模型必須同時利用這些資料，才有可能兼顧影像外觀與量測穩定性。
694 不能 | 真值 :: 真實顯微影像保留實際成像系統的亮暗分布、背景起伏、紋理與噪聲，適合約束輸出外觀。然而，光學影像的邊界已受到 PSF 與取樣影響，不能直接把某一灰階交點視為絕對幾何真值。
696 限制 :: 已知位移配對與實際連續影格提供相對位置關係。前者具有可控制的位移量，後者保留真實平台、照明與相機擾動；兩者共同限制模型不得因像素相位或影格差異任意改變中心與步進尺度。
697 限制 :: 跨條件資料則用來限制亮暗極性、曝光、背景與噪聲變化造成的不成比例輸出。這類資料不要求所有影像外觀完全一致，而是要求不影響真實幾何的條件變化不應被模型誤認為尺寸或位移變化。
705 單一 :: 模型若過度學習這種硬式邊界，可能產生鋸齒、對單一像素位置過度敏感，或把一個像素的標籤變化解讀為完全確定的物理邊界。這與本研究希望進行的亞像素 CD 與位移量測並不一致。
716 未 :: 固定分組驗證用於訓練期間監測未參與權重更新群組的表現，並與第六章針對指定系統與樣品的整體方法比較形成分工。
718 限制 :: 多來源資料提供量測導向損失函數所需的監督：真實影像提供外觀，合成幾何與SEM提供輪廓及尺寸，已知位移與連續影格提供位置關係，穩定性資料則限制模型對曝光、背景與雜訊變化產生過度反應。
720 補充 | 限制 :: 本研究的訓練目標不是單獨降低輸出與參考影像的像素差異，而是把可用重建限制在同時符合影像、邊界與運動關係的範圍。像素與感知品質並非完全一致[30,31]；頻域損失可補充不同空間頻率的學習[67,68]，梯度與任務特定損失可強化結構及下游需求[69,70]，等變約束則用於維持轉換前後的幾何關係[62,92]。
721 限制 :: 單獨強調像素誤差容易產生過度平滑；單獨強調梯度或高頻則可能產生過度銳化、振鈴與人工紋理。兩種結果都可能使表觀邊界偏離原始結構。因此，本研究不把任一單項分數作為唯一目標，而是用互補限制共同縮小可接受解的範圍。
722 限制 :: 總損失分為影像內容、邊界幾何、運動一致性與輸出保守性四組。四組目標分別限制影像外觀、輪廓與中心位置、相鄰影格的運動關係，以及非量測區域的不必要修改。
730 限制 :: 邊界遮罩用來標示模型應優先處理的輪廓區域；中心資訊用來限制左右或上下邊界不得同時向同一方向漂移；距離圖描述每一個像素與真實輪廓之間的相對距離，使模型不只知道某個像素是否位於邊界，也能理解其位於結構內側、外側或距離輪廓多遠；邊緣方向則用來限制亮暗轉換的方向，降低模型在亮 pillar 與暗 pillar 之間產生相反修正的風險。
731 不能 :: 對本研究而言，邊界幾何損失比單純的影像相似度更直接對應量測需求。兩張影像即使具有相近的整體灰階，只要邊界位置相差一個像素，其 CD 仍可能相差數十至數百奈米。因此，模型不能只學會產生合理外觀，也必須學會保留輪廓位置。
733 不能 :: 例如，當輸入影像中的 pillar 向右移動已知距離時，模型輸出中的同一 pillar 也應向右移動相同量級，而不能因邊界修正而使位移被壓縮、放大或改變方向。同樣地，相鄰影格中的同一顆 pillar 不應因為雜訊略有不同，就在重建後產生不規則的中心跳動。
735 限制 :: 第四組為輸出保守性損失 。此組損失用來限制模型在不需要修改的區域產生過大變化，包括低頻亮度偏移、背景區域改動、非邊界紋理生成及過大的局部殘差。
736 限制 :: 第4.3節的殘差截斷、輸入參考式殘差輸出與品質門控屬於架構限制；輸出保守性損失則是訓練時的軟性懲罰。前者直接限制輸出形成方式，後者在模型產生不合理改動時增加訓練代價。
737 限制 | 單一 :: 四組目標形成互補限制。影像內容維持真實顯微外觀；邊界幾何約束尺寸、輪廓與中心；運動一致性維持影格間的位置關係；輸出保守性則防止非目標區域被不必要地改動。模型必須同時滿足這些條件，而不是用單一指標的改善交換另一項量測能力。
738 單一 :: 量測導向訓練目標將一般影像相似度延伸到CD與微位移所需的幾何關係。完整模型使用四組目標共同訓練；第六章的單項移除結果則用來觀察補償關係，而不把整體效果勉強歸因於單一損失。
740 未 :: 影像重建模型可能對結構所在的像素位置敏感。下採樣與非線性會造成取樣相位依賴[39,58,61]，上採樣也可能引入額外的位置差異[91]，邊界補值則可能使模型利用絕對位置[59]。因此，即使輸入內容相同，整張影像向左或向右移動少量像素後，輸出輪廓仍可能產生不同變化。這種位置依賴性對一般辨識任務未必明顯，但會直接影響亞像素位移量測。
741 限制 :: 為限制此問題，本研究加入平移一致性損失。令 表示已知的水平與垂直位移， 表示將影像平移 的亞像素平移算子。理想情況下，「先平移輸入影像，再進行重建」與「先重建原始影像，再平移重建結果」應得到相近結果：[38,62,92]
745 限制 :: 亞像素平移會涉及內插及影像邊界填補。為避免新填入的影像邊界主導損失，實際計算時應使用相同的平移內插方式，並將比較限制在兩條路徑共同有效的重疊區域。否則，損失可能主要反映 padding 或邊界填值差異，而不是結構重建是否具有平移一致性。
746 限制 | 不能 :: 平移一致性只能限制相對關係，不能單獨決定絕對幾何。例如，模型若在所有位置都將pillar直徑縮小5%，兩條平移路徑仍可能一致，但CD依然錯誤。因此，式（4-14）須與SEM參考幾何、合成形狀、邊界距離及輸入參考式殘差輸出共同使用。
747 限制 :: 平移一致性檢查同一物體移動後，模型是否維持相同的處理方式；SEM與幾何監督則限制重建後的尺寸。兩者用途互補，但單項效果仍需由消融實驗確認。
752 限制 :: 分階段訓練同時用來限制參數改動範圍。第二階段不必重新學習完整的顯微影像分布，而是集中調整與量測輸出較直接相關的部分，降低少量幾何資料造成整體特徵漂移的風險。
759 未 :: 本研究比較未經重建的原始影像、由相應局部 PSF 建立的 Wiener 反卷積影像，以及所提量測導向模型的輸出。三者代表原始成像、傳統光學模型校正與資料驅動重建三種影像來源。
765 未 :: 影像顯示與數值計算分開處理。同一比較組使用共同的顯示範圍，不逐張自動拉伸；所有邊緣、CD、位移與頻譜數值均由未加入顯示用銳化、伽瑪或對比增強的資料計算。
770 不能 :: 過渡寬度越小，代表灰階轉換越集中，但不能單獨視為解析度提升。強反卷積可能以過衝或欠衝製造陡峭邊緣，因此同時記錄正規化剖面超出 0 至 1 範圍的最大振鈴量。
784 單一 :: 使用成對邊界的中點，可降低單側模糊或局部亮環對中心的影響；使用多條剖面的中位數，則降低單一剖面受噪聲或局部缺陷干擾所造成的離群值。水平與垂直方向使用相同原理。
790 不能 :: 代表位移回答整體移動量，九宮格內不一致量回答同一視野不同位置是否得到相近結果，跨軸位移則檢查與主要移動方向垂直的非預期變化。三者分別對應量值、空間一致性與方向耦合，不能相互取代。
804 限制 :: 本章建立一套由量測失效導出的單張顯微影像重建方法。固定PSF先驗描述成像模糊；抗混疊上採樣處理解碼時的像素相位與空間位置敏感性；輸入參考式殘差輸出限制低頻輪廓、亮暗拓樸與中心位置漂移；四組量測導向目標共同限制外觀、邊界、運動與非必要改動。
806 限制 :: 模型採單張、同尺寸輸入與輸出。抗混疊上採樣維持解碼過程的空間對應，輸入參考式殘差輸出使Raw保留為低頻位置基準；邊界殘差、品質門控與PSF修正則限制或引導局部修正。
821 單一 :: 本研究分別搭配三種不同倍率之Olympus/Evident物鏡進行量測，包含MPLFLN5X（MPlanFL N 5x/0.15）、MPLN20X（MPlan N 20x/0.40）以及MPLN50X（MPlan N 50x/0.75）。其中，MPLFLN5X之數值孔徑為0.15，視場數為26.5；MPLN20X之數值孔徑為0.40，視場數為22；MPLN50X之數值孔徑為0.75，視場數為22。若以相機像素大小除以系統放大倍率估算物方平面之單一像素取樣間距，則在5倍、20倍與50倍物鏡下，對應之數位取樣間距分別約為690 nm、172.5 nm與69 nm。

1209 限制 | 單一 :: 綜合現有證據，MOSR將顯微影像重建的判斷重點由單一視覺銳利度轉向邊界集中、尺寸穩健與跨位置位移一致性。抗混疊上採樣維持不同pillar間的相對幾何關係，輸入參考式殘差輸出限制最終輪廓改寫，多位置PSF與四組量測導向目標則提供固定光學條件及聯合訓練約束。這套設計使模型能在同一座標系中同時接受CD與微位移檢查。
1210 未 :: 結論與未來工作
1217 允許 :: 本研究的第一項主要貢獻，是將解碼上採樣造成的像素相位與空間位置敏感性，轉化為可由九顆pillar共同位移直接檢查的模型問題，並以抗混疊上採樣改善跨位置幾何一致性。第二項主要貢獻，是將輸入參考式殘差輸出建立為量測邊界保護機制，以Raw提供低頻位置基準，只允許幅度受限的高頻修正。兩項設計分別處理解碼階段與最終輸出階段的幾何風險，並由配對消融對應至位移分歧與輪廓穩定性。
1218 限制 :: 影像內容、邊界幾何、運動一致性與輸出保守性四組目標，共同把外觀、輪廓、影格關係與非必要改動納入訓練限制。局部PSF建立Wiener對照，多位置PSF則提供固定光學條件資訊。EDSR與NAFNet使用相近參數量、相同資料分組及一般重建目標，使20倍via比較能檢查單純更換現代重建架構是否足以重現MOSR的量測結果。
1226 未 :: 7.5 未來工作
1228 真值 :: 後續可使用雷射干涉儀與PI平台數值位置記錄同步量測，建立獨立位移真值，並將重複性、像素尺度、SEM參考、平台設定與模型變動整合為完整不確定度預算[84,85]。模型驗證亦可增加不同批次樣品、跨系統測試及跨條件分層統計，進一步擴充MOSR的操作範圍。
