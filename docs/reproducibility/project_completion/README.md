# 全專案保存核對

本次目標是核對本機真正存在的研究內容，而不是把「有程式、有索引、有 H 槽副本」當作已完整送上 GitHub。2026-10-21 本輪仍在執行中；未完成項目不能解讀為已保存或已重做。

本頁記錄這次全專案核對的範圍與完成證據。跨區域查找仍以[專案地圖](../../navigation/PROJECT_MAP.md)為唯一人工導航，各輪科學結論仍回到原正式報告。

## 完成的條件

- 每個實驗和研究區域都能說明問題、方法、來源、完整結果、失敗與後續關係。
- 本機與以前搬走的實驗歷史逐項對照 GitHub 的實際內容。檔案相同須核對內容；只有同尺寸不能算通過。
- 正式模型、實際引用的中途模型、初始化、失敗和既存訓練歷程保留原身分。最佳模型、最後模型與平均模型分開記錄。
- 相機原圖、平台原始紀錄、SEM、工作表、固定光學輸入和不能精確重做的歷史答案保存實際檔案。只有固定種子不能取代完整資料的重做核對。
- 完整數字與不利結果保留；重要影像有來源和選圖理由。相同內容可以只存一份，但所有需要的原位置須能恢復。
- 實際從 GitHub 取回核對，能執行的原讀取、模型或數值流程在另一位置驗證。訓練重跑、推論、數值重算與檔案還原分別記錄。
- 本輪不清理 D 槽，不改原論文與採用模型，不干擾正在執行的訓練。

## 核對範圍

既有[177 個實驗與歷史範圍](../EXPERIMENTS.md)是閱讀入口，不是「全專案共有177次訓練」的宣稱。例如 R33 的正式系列報告也包含 R34、R35、R37 等支線；沒有獨立資料夾的歷史仍要保存。

另核對下列內容：

| 內容 | 必須保留的脈絡 |
|---|---|
| 共用模型與早期訓練 | 起點、資料配方、真正採用的模型、逐輪歷程、命名不一致與未採用支線 |
| 光學擬合與快速校正 | 理論基底、當時使用的光學檔、相機與 SEM 配對、參數範圍、失敗方向與之後的修正；設計提案與已完成實驗分開 |
| Step、100MG、多倍率與原始重拍 | 完整原拍與位置紀錄、選圖及裁切、影格順序、樣本和倍率；模型重建不可冒稱原拍 |
| 論文證據與交接 | 各版主張、原始完整數表、圖說與來源、草稿與修訂理由；舊版結果不冒充目前採用版 |
| 通用分析與量測工具 | 實際算法、原有設定、測試例子、完整外部回傳與缺測；保存專有工具的輸入輸出並註明外部執行需求 |
| 獨立交付包 | 模型、必要輸入、來源關係、安裝紀錄與實測；通用環境副本與研究成果分開 |
| 封存、被否定方案與編輯歷史 | 保留有研究意義的不同版本和決策理由；複製品不算新的獨立證據 |
| 本機版本歷史 | 核對有名稱的本機分支是否已可從 GitHub 取得；未追蹤資料仍須另按實際檔案核對 |

## 判斷「已送上」的方法

每個需要的檔案會區分：原位置已存在且內容相同、內容存在於另一位置而仍須補恢復對應、真正缺件、與較舊版本不同、可完整重做、通用依賴或快取、正在使用而受保護。這些狀態不能互相代換。

來源與影像的具體判斷見[保存判斷](../SOURCE_AND_IMAGE_DECISIONS.md)。已完成的 R93 及 R94／95／97／98 取回驗證仍由原入口提供，本輪不把那些已完成項目重算為新的成果。
