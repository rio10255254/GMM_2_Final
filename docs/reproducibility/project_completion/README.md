## 完成的條件

- 每個實驗和研究區域都能說明問題、方法、來源、完整結果、失敗與後續關係。
- 逐項核對精選清單與GitHub實際內容；外部大型封存的用途與取得方式清楚，不以整份磁碟鏡像全部上傳為完成條件。
- 模型依當輪實際用途挑選關鍵版本，最佳、最後與平均模型分清；完整歷程可以記錄在本機封存索引，不要求全部中途模型都上GitHub。
- 相機原圖、平台原始紀錄、SEM、工作表、實測光學輸入與不可再生的人工／歷史答案保留原件。可再生的大型訓練資料保存原生成程式、設定與必要來源即可，不以先完整重建或逐位元相同作省略門檻。
- 完整量測／比較數表與不利結果保留；重要影像有來源和選圖理由。精選共用內容只存一次，原用途仍能查清楚。
- 確認GitHub收到完整內容、索引沒有未知漏件，固定程式、總索引與必要代表檔案可實際取回。已有訓練重跑、推論、數值重算與檔案還原證據分別保留；不再把新增測試或重算當成本輪完成的額外條件。
- 本輪不清理 D 槽，不改原論文與採用模型，不干擾正在執行的訓練。
