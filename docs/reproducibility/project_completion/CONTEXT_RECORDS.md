# 原始紀錄、必要標記與論文版本補件

這批保存全內容核對新找到的182,471個原位置，共55,605種不同內容。完整檔案從GitHub下載並在另一位置還原，逐份內容相同。相同內容集中保存，原用途和位置保留。

內容包含194份程式或原編輯版本、764份報告／文件，以及181,513份原始數據、分組、執行或訓練標記紀錄。通用環境副本沒有當成研究成果再塞入；當次測試保留的實際程式、失敗及舊版文件則留下。

## 為什麼要保留

- 訓練標記與配對資訊不能因為「有生成程式」就省略。舊版幾何或答案若尚未證明能整套重做相同，保存實際原件。
- 原執行、失敗與中途紀錄用來追查當時真正發生的事，不用現在較好的結果改寫。
- 論文草稿、原修訂及檢查文件保留不同版本，讓後來能分清楚主張如何改變；舊草稿不稱為目前採用稿。
- 原程式的歷史版本及當次執行副本，和目前主程式分開保留；不因資料夾叫runtime就把它略過。

原圖與數據仍以各輪正式報告解讀，沒有因成功取回便把失敗或待定方案改成成功。整個專案其他模型、固定資料及完整結果的補查仍在進行。
