## 同一個模型不等於同一份保存檔

已有可比較的記錄中，找到807組不同保存檔持有完全相同的模型陣列。仍保留各份原檔，因為原封裝、輪次、更新狀態及用途可能不同；不能只因模型陣列相同就當作可互換的完整續訓狀態。

程式版本、輸出設定及光學讀法也要一起保留；相同模型陣列本身不證明兩種執行方式會得到相同輸出。

4,672份記錄有更新狀態，4,308份內部明記輪次。沒有寫輪次的保持未知，不依檔名或修改日期補猜；52份採用較直接的模型儲存形式，這次原工具沒有替它們產生具名模型段的比較身分，不能把它們誤列為模型不同或不存在。完整原檔與陣列讀取檢查仍然通過。

第10輪當下模型、同輪平滑模型、最佳檔與最後檔分別保留。具體例子見[V41到V42來源鏈](../lab_comparisons/V42_HISTORY.md)：最佳第10輪保存的是平滑狀態，與同輪當下模型有26份陣列不同。保存索引不因檔案叫best或latest便替研究重選模型。

唯一無法作模型載入的4-byte內容是原測試寫出的`fake`，原程式與同內容來源都已核對。它是測試紀錄，不能算成實際訓練模型損毀；[原測試來源核對](INSPECTION_EXCEPTION_REVIEWED.json)。
