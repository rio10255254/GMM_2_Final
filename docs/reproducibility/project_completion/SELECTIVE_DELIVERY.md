# 精選研究保存的固定內容

這次保存研究方法、完整原結果與必要來源，不做整個磁碟的鏡像。程式、文件與數表的收斂依據是已盤點的實際內容和已發布版本；是否完成以本次GitHub保存版本的最後收據為準。

## 內容範圍

- 177個研究／歷史範圍各有原問題、方法、來源、結果與失敗入口；原科學判決不變。
- 原程式與設定有逐輪索引；18條共用性高的資料生產路線另按實際程式和參數整理，其餘沿用原方法文件，不編造或執行新的生成命令。
- 完整原量測／比較表、訓練、失敗與論文修訂紀錄由一般程式版本及既有已發布來源保存。常用R153、R33至COMBO及R100／R103／R104的小型原結果可直接讀，不必先下載整套訓練影像。
- 原相機、平台紀錄、SEM與不能再生的必要來源共用一次。9月3日930張原拍及30份原始位置紀錄保留同一份來源，沒有拿模型重建冒充原拍。
- 首要閱讀清單列出373個原圖／分析圖位置及16個固定模型用途，保留不利尺寸、速度、曝光、位移和失敗案例。較早一般版本中的其他方法圖與歷史附圖保留原位置；不把整個本機圖庫當成新增必傳內容。

## 來源與結果不是只留檔名

先前內容盤點中的292,510個程式、文件及數表位置，291,243份內容已在既有發布或一般程式版本找到；另外9份較早的導覽文件從已發布Git歷史實際取回相同。其餘1,258份屬可重新安裝的舊R26套件環境，已核對原套件記錄與檔案清單並留下版本及用途，不再包整套環境。

這是對原盤點內容與保存位置的收斂，不冒稱本次重新掃描所有磁碟、重跑全部實驗或重新下載所有大檔。舊完整取回與執行證據保留各自原時間和範圍。

## 不上傳整套可再生產物

訓練影像、逐張完整重建、分析中間陣列及未選中途模型，以原程式、設定及必要基礎來源保存。未先完整重建不構成必須上傳的理由；新的研究副本若產生不同資料，須記錄新身分，不能改寫當年的結果。

## 清楚保留的界線

- 22份較早訓練程式版本未尋回，9項早期R13總分公式仍缺；9個未寫出的ANN紀錄量不補造。
- 沒有重跑全部歷史GPU訓練，也不保證所有舊程式不調整位置就能在任何電腦執行。原環境、實際來源、外部MATLAB／GMF需求及各輪來源依賴照原紀錄保留。
- 四份先前超量草稿合計約385GB仍凍結，未發布、未刪除，並非這次精選交付的必要內容。撤回候選已列明，沒有自行刪除附件；這個另行決定的處置不要求重啟全量排程。
- 原D工作分支與索引、論文、正式模型及訓練資料受保護；這次不清D、不刪D/H研究原件。Git歷史和較早必要交付保留，因此精簡目前閱讀內容不等於已釋放歷史儲存空間。
