# 精選研究內容的交付條件

目前原則是保存研究方法、完整原結果與必要來源。可再生的大型資料留生成程式、設定及必要輸入，不要求先完整重建，也不要求所有產物上GitHub。

## 本次真正需要完成什麼

1. 每個研究範圍有問題、方法、原結果、失敗與限制入口；較早設計、實際完成與現在採用身分分清。未找到的22份早期程式與9項早期R13公式如實列出。
2. 原程式、設定、文獻整理、完整量測／比較表與研究紀錄可以取得。資料生產路線指到真正來源，原拍、人工來源與生成資料分開；未確認的命令不補造。
3. 只精選有用途的圖和少數關鍵模型。可再生的整套訓練影像、逐張重建、分析中間陣列及其他中途模型不是必傳內容；過去已完成的完整重建證據保留原時間與範圍，不增加新的重建門檻。
4. 共用930張原始相機照片與30份位置紀錄保留一次，其他已發布必要來源與固定模型引用原位置。各輪共用資料的關係與取得方法清楚；仍需外部來源時直接說明。
5. 精選來源清單對應實際GitHub內容，新的小型文件和必要代表檔案能取回。檢查只服務這次交付，不增加訓練、模型推論、全面資料生成或測試工程。
6. 新保存版本以固定來源和精選索引為主，附件只放必要的小型目錄／說明。不打包整個磁碟，也不把大檔拆成小附件續傳。較早的已發布版本與五個小型交付包保留原固定來源，不改寫成新的驗證範圍。
7. 預設閱讀入口指向目前已核對內容，並標清整理是否全部完成。原D工作分支、Git索引、論文、正式模型及訓練來源保持保護；本次不清D、不刪D/H研究原件，H至少留1TiB。
8. 四份超量草稿維持凍結，附件清單與具體撤回候選保留。沒有直接授權就不刪遠端附件；這個可另決定的撤回問題不要求重啟整套上傳，也不必無限阻擋其他精選整理。

各範圍的剩餘項目若只是歷史缺件或已明列外部依賴，必須如實交代，不能冒稱已精確重現全部GPU訓練。只有實際精選內容已整理、推送、用途及大型來源界線清楚，才說整理完成並移除自動接續。
