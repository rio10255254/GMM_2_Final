# 專案操作與保護規則

這裡服務實際維護；只想閱讀研究，先到[研究入口](../reproducibility/README.md)。

| 工作 | 先讀 |
|---|---|
| 編輯研究前找正式來源 | [正式來源規則](SOURCE_OF_TRUTH_POLICY.md)、[已知特殊路徑](QUIRKS.md) |
| 開新實驗 | [完整操作指南](STARTING_NEW_EXPERIMENT.md)；不拿舊輪次資料夾直接改名冒充新實驗 |
| 查早期Round16至31 | [早期批次操作規則](LEGACY_ROUNDS_OPERATIONS.md)；原決策和原檔位置保持 |
| 看現有檔案放哪裡 | [專案地圖](../navigation/PROJECT_MAP.md) |
| 規劃未來新增內容 | [結構藍圖](PROJECT_FUTURE_STRUCTURE_PLAN.md)；它是設計準則，並非所有搬遷都已做完 |
| 查封存與取回 | [封存索引](PROJECT_ARCHIVE_INDEX.md)、[已清副本的去向](D_DRIVE_FULL_CLEANUP_20261022.md) |
| 看各大型區為何仍保留 | [保留理由](D_DRIVE_RETENTION_REVIEW_20261022.md) |

容量操作必須依當時授權及逐批來源核對，不能只因資料夾叫trash、temp或archive就刪。正式模型、相機原拍、論文、活動訓練及必要來源保持保護。舊保存排程不重啟，大量可生成產物不用再送GitHub。
