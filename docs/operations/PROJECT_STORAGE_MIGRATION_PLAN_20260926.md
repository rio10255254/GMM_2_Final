### 防止再次堆滿

- 新實驗先記錄會讀取哪些共享資料、預計新增多少內容。
- 共享資料有清楚的單一來源，避免每輪複製整套資料。
- 實驗完成時一併保存完整歷史；D 通常保留採用模型、最後模型及必要比較模型，報告需要的其他版本另行明列。
- 大量候選與逐張輸出先保存到 H，D 留日常工作真正需要的內容與查找入口。
- 每批核對後更新同一份中央容量登錄與封存索引，不另造多份彼此落後的清冊。
