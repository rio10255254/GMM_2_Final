# 舊共享重建與分析入口

本區保留較早共享重建的說明和小型紀錄；新實驗的正式結果留在所屬輪次。

先看[當時本機重建筆記](README_LOCAL.md)，其中的2026年6月暫時觀察按原日期理解，不是目前正式模型判決。比較圖與失敗的網頁入口見[原圖冊](../RECON_GALLERY.md)，完整結果回[各輪報告](../docs/reproducibility/EXPERIMENTS.md)。

GitHub只有精選閱讀內容，少量代表圖不是完整序列。需要全部歷史時查[既有附件](../docs/reproducibility/ASSET_GUIDE.md)與原模型／來源，不能把生成影像當原始相機拍攝。
