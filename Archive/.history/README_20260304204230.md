# GMM_2_Final — 專案說明文件

## 概覽

本專案實現「以 PSF 物理先驗引導的邊界保真超解析／反捲積深度學習系統」，應用於光學顯微鏡影像的幾何保真重建。

**核心目標：**
- 從量測影像（含光學像差、散焦模糊）還原出接近 Ground Truth 的清晰影像
- 在還原過程中嚴格保持邊緣的位置與幾何形狀，不產生偏移或過度銳化
- 透過真實 PSF 擬合（非單一 Gaussian 假設）得到物理上更正確的先驗知識

**整體工作流程（一次性建立後，反覆執行訓練/推論）：**

```
[MATLAB] PSF_Fitting/                      [Python] Model/                   [輸出]
   │                                     │                              │
   │  psf_multiwavelength_2D.m           │  Training_Data/              │
   │  → psf_multi.mat                    │  tra_src_ring/  (1100張)     │
   │                                     │  tra_lbl_ring/  (1100張)     │
   │  HDR_fitting_2D_WholeFOV.m          │                              │
   │  → PSF_fitted_2D_FOVstack.mat      ──▶      訓練腳本               │
   │    (7.5 MB, 10×10 FOV 格點)         │  GeoEdgeAlignSR_*_Train.py   │
   │                                     │         │                    │
   │                                     │         ▼                    │
   │                                     │  Traing_Progress/            │
   │                                     │  └── weights/                │
   │                                     │      best_tradeoff.pth.tar  ──▶  推論腳本
   │                                     │      latest.pth.tar          │
   │                                     │  GeoEdgeAlignSR_*_Infer.py
   │                                     │                              │       │
   │                                     │                              │       ▼
   │                                     │                              │  Reconstruct_Progress/
   │                                     │                              │  └── output/  (重建影像)
```

## 各元件功能說明

### Model/ — 深度學習模型

模型名稱：**GeoEdgeAlignSR_v1_v5_NoCoord**

| 程式 | 行數 | 功能 |
|------|------|------|
| `GeoEdgeAlignSR_v1_ModelA_v5_NoCoord.py` | 659 | 模型定義（U-Net + PSF 物理層） |
| `GeoEdgeAlignSR_v1_Train_v5_NoCoord_return_v2_SimpleTest.py` | ~6800 | 訓練完整邏輯（Loss、排程、EMA、GMF 監控） |
| `GeoEdgeAlignSR_v1_Infer_v5_NoCoord_return_v2_SimpleTest.py` | 680 | 批次推論（自動搜尋最新 checkpoint） |
| `GeoEdgeAlignSR_v1_Utils.py` | 244 | 共用工具函式（次像素平移、Sobel、Hann 窗等） |

**模型架構簡述：**

```
輸入圖 [B,1,H,W]
    │
    ▼
[PSFDeconvPhysics]     Wiener 反捲積物理前處理（α 殘差混合，可訓練）
    │
    ▼
[U-Net Encoder]        E1(48ch) → E2(96ch) → E3(192ch) → Bottleneck(192ch)
    │
    ▼
[U-Net Decoder]        D3 → D2[WeakPSFDeconvBlock] → D1
    │                       ↑ 多 PSF 軟混合局部去模糊注入
    ▼
[OpticalBandpassFilter] 訓練時限制超物理頻率（Butterworth，推論時自動 bypass）
    │
    ▼
輸出圖 [B,1,H,W] ∈ [0,1]
```

每個 Upsample 使用 `ShiftSafeUpsample`（Bilinear×2 + 固定 Gaussian blur + Conv），防止 checkerboard 偽影。

**訓練 Loss 組成（SimpleTest 模式）：**

| Loss 項目 | 權重 | 說明 |
|----------|------|------|
| REC（重建） | 1.0 | Huber + 少量 SSIM |
| GRADMAG（梯度幅值） | 0.8 | Sobel 梯度幅值一致性 |
| EDGEORI（邊緣方向） | 0.3 | 邊緣方向向量一致性 |
| EQGEOM（平移等變幾何） | 0.5 | SR(shift(x)) ≈ shift(SR(x))，梯度域 |
| STAT（統計） | 0.10 | 均值 + 標準差一致性 |
| BAND（頻帶） | 0.10 | 中頻帶能量一致性 |
| HF_LAP（高頻 Laplacian） | 0.15 | 細節恢復（邊緣局部） |

詳細說明請參閱 [Model/README.md](Model/README.md)。

### PSF_Fitting/ — PSF 擬合（MATLAB）

以 Zernike 多項式描述光學像差，透過 BADS 最佳化演算法對實驗影像進行 PSF 擬合。

**三階段流程：**

| 階段 | 腳本 | 輸入 | 輸出 |
|------|------|------|------|
| 1 理論 PSF | `SimulatePSF/psf_multiwavelength_2D.m` | 光學參數（NA=0.23, 20×, 580 nm） | `psf_multi.mat` |
| 2B 全 FOV 擬合 | `HDR_fitting_2D_WholeFOV.m` | 100 張量測影像 + GT | `PSF_fitted_2D_FOVstack.mat` ★ |
| 3 反捲積驗證 | `HDR_fitting_2D*.m` Section 2 | 擬合 PSF + 實驗影像 + SEM GT | `deconv_result_2D.tiff` |

**關鍵輸出 `PSF_fitted_2D_FOVstack.mat`（7.5 MB）內容：**

```
fov_psf_data.psf_grid        [H, W, 10, 10]  — 10×10 FOV 格點的擬合 PSF
fov_psf_data.coef_grid       [15, 10, 10]    — 對應的 Zernike 係數
fov_psf_data.fval_map        [10, 10]        — 各格點擬合誤差
fov_psf_data.iterations_map  [10, 10]        — BADS 迭代次數
fov_psf_data.filename_map    [10, 10]        — 對應輸入檔名
```

詳細說明請參閱 [PSF_Fitting/README.md](PSF_Fitting/README.md)。

### Training_Data/ — 訓練資料集

| 項目 | 數值 |
|------|------|
| 訓練影像對數 | 1100 對 |
| 每個子資料夾大小 | ~333 MB |
| 影像格式 | BMP，灰階 |
| 命名規則 | 同檔名（src / lbl 一一對應） |

訓練時程式自動從每張影像隨機裁切 256×256 patch，並在線上合成次像素平移對（不需要預先準備帶位移的影像）：

- 80%：Tiny shift（< 0.3 px）
- 18%：Mid shift（0.3–1.0 px）
- 2%：Integer shift（1–2 px）

## 快速開始

### 前置需求

**Python 環境（訓練與推論）：**

```bash
pip install torch torchvision torchmetrics opencv-python scipy matplotlib tqdm numpy
```

- Python 3.12
- CUDA 12.x，NVIDIA GPU（訓練必要，推論建議）
- PyTorch 2.6+

**MATLAB 環境（PSF 擬合，一次性操作）：**

- MATLAB R2021b 以上
- Image Processing Toolbox
- Parallel Computing Toolbox（GPU 加速，可選）
- BADS 工具箱（已包含於 `PSF_Fitting/bads-1.1.3/`，需手動加入 Path）

---

### 步驟一：PSF 擬合（一次性，MATLAB）

> **已有 `PSF_Fitting/Crop_circle_FreqFiltered/Fits/PSF_fitted_2D_FOVstack.mat` 則跳過此步驟。**

1. 在 MATLAB 將 Current Folder 設為 `PSF_Fitting`
2. 加入工具箱路徑：
   ```matlab
   addpath(fullfile(pwd, 'SimulatePSF'));
   addpath(fullfile(pwd, 'bads-1.1.3'));
   ```
3. 執行全 FOV 批次擬合（約 1–2 小時，依 GPU 而異）：
   ```matlab
   % 開啟 HDR_fitting_2D_WholeFOV.m，執行 Section 1
   ```
4. 確認輸出：`Crop_circle_FreqFiltered/Fits/PSF_fitted_2D_FOVstack.mat`（約 7.5 MB）

---

### 步驟二：訓練（Python）

```bash
cd Model
python GeoEdgeAlignSR_v1_Train_v5_NoCoord_return_v2_SimpleTest.py
```

**訓練前確認：**
- `Training_Data/tra_src_ring` — 輸入影像（1100 張）
- `Training_Data/tra_lbl_ring` — 目標影像（1100 張）
- `PSF_Fitting/Crop_circle_FreqFiltered/Fits/PSF_fitted_2D_FOVstack.mat`

訓練結果自動儲存至 `Traing_Progress/training_progress_{MODEL}_{timestamp}\`。

**常用 TrainConfig 參數（修改腳本頂端的 dataclass）：**

| 參數 | 預設 | 說明 |
|------|------|------|
| `DEVICE` | `"cuda:0"` | 訓練裝置 |
| `LR` | `2e-5` | 學習率 |
| `BATCH_SIZE` | `4` | Batch size |
| `NUM_EPOCH` | `100` | 訓練 epoch 數 |
| `LOAD_MODEL` | `False` | 是否從 checkpoint 接續訓練 |

---

### 步驟三：推論（Python）

```bash
cd Model
python GeoEdgeAlignSR_v1_Infer_v5_NoCoord_return_v2_SimpleTest.py
```

推論腳本自動搜尋 `../../Traing_Progress/` 下最新的 `best_tradeoff.pth.tar`。

**指定 checkpoint 或自訂輸入：**

```bash
python GeoEdgeAlignSR_v1_Infer_v5_NoCoord_return_v2_SimpleTest.py \
    --weights Traing_Progress/training_progress_xxx/weights/best_tradeoff.pth.tar \
    --input-dir Training_Data/tra_src_ring \
    --device cuda:0
```

輸出影像儲存至 `Reconstruct_Progress/reconstruct_progress_{timestamp}\`。

## 注意事項

1. **`Traing_Progress/` 拼寫**：資料夾名稱少一個 i（`Traing` 非 `Training`），為歷史遺留，程式與路徑均以此命名，**勿更名**。

2. **PSF 路徑相對性**：所有 Python 腳本以 `Model` 為基準用相對路徑存取 PSF 與訓練資料，執行時需在 `Model\` 資料夾內啟動。

3. **MATLAB Current Folder**：所有 PSF 擬合腳本路徑均相對 `PSF_Fitting\`，執行前必須設定 Current Folder。

4. **GPU 記憶體需求**：訓練使用 Batch=4, Crop=256，約需 6–8 GB VRAM；推論可在更小顯卡執行。

5. **再現性模式**：訓練腳本預設 `REPRO_MODE=True`，固定隨機種子與 train/val split 以確保結果可複現。
