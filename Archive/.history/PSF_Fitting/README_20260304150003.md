# PSF_Fitting — 說明文件

## 概覽

本資料夾實現「以 Zernike 多項式描述像差，並透過 BADS 最佳化演算法擬合 2D PSF」的完整工作流程，最終用擬合結果執行 Wiener 反捲積。

整體流程分三個階段：

```
[1] PSF 模擬         [2] PSF 擬合              [3] 反捲積驗證
SimulatePSF/    →   HDR_fitting_2D*.m    →   Deconvolution/
psf_multi.mat       (BADS 最佳化)             Results/
```

## 使用前準備

### 1. MATLAB 工作目錄設定

**執行任何程式前，必須將 MATLAB Current Folder 設為本資料夾：**

```
PSF_Fitting
```

### 2. 加入 MATLAB Path

`normlz.m` 位於 `SimulatePSF/` 子資料夾，需加入 Path 才能被主程式呼叫：

```matlab
addpath('SimulatePSF');
```

或在 MATLAB → Home → Set Path 永久加入。

### 3. 必要工具箱 / 套件

| 套件 | 用途 |
|------|------|
| BADS (Acerbi & Ma, 2017) | PSF 擬合最佳化演算法，需另行下載安裝 |
| Image Processing Toolbox | `imread`, `imresize`, `deconvwnr` 等 |
| Parallel Computing Toolbox | `gpuArray`, `gather` (需 NVIDIA GPU) |

## 各程式使用說明

### 階段 1：重新產生 PSF（選用）

若需更新模擬 PSF，執行：

```
SimulatePSF/psf_multiwavelength_2D.m
```

**輸出：** `SimulatePSF/psf_multi.mat`（內含變數 `psf_multi`，為 2D 陣列）

> 若不需更新，跳過此步驟，直接使用現有的 `psf_multi.mat`。

---

### 階段 2A：單張影像 PSF 擬合

**程式：** `HDR_fitting_2D.m`

**輸入：**
- `SimulatePSF/psf_multi.mat` — 理論 PSF
- `SingleImage_Input/VisionTop_20250903160550_freqDenoise.bmp` — 量測影像（頻率濾波後）
- `SingleImage_Input/GT/GT_901_with_Block_proc.bmp` — Ground Truth

**執行方式：** 在 MATLAB 中開啟後，按 `Run`（或 `F5`）執行整個 Section 1。

**輸出：** `SimulatePSF/PSF_fitted_2D_0924.mat`（含 `fitted_psf`, `x`, `fval`）

**最佳化參數說明：**
- 優化 15 個參數：14 個 Zernike 係數（Z1–Z14）+ 1 個振幅縮放 `AC`
- Y-tilt / X-tilt 在 `aberration()` 函式內部強制鎖為 0（防止純平移）
- Loss = `MSE(頻率域)` + `2×10e4 × MSE(梯度域)`

---

### 階段 2B：全 FOV 批次 PSF 擬合（推薦）

**程式：** `HDR_fitting_2D_WholeFOV.m`

**輸入：**
- `SimulatePSF/psf_multi.mat` — 理論 PSF
- `Crop_circle_FreqFiltered/VisionTop_*.bmp` — 100 張頻率濾波影像（10×10 FOV 格點）
- `Crop_circle_FreqFiltered/GT/GT_901_with_Block_proc.bmp` — Ground Truth

**執行方式：** 在 MATLAB 中開啟後，按 `Run` 執行。程式會依序處理 100 張影像。

**輸出（自動建立於 `Crop_circle_FreqFiltered/Fits/`）：**
- `batch_results.csv` — 每張影像的擬合誤差、迭代次數、耗時
- `PSF_fitted_2D_FOVstack.mat` — 全 FOV PSF 結果，結構如下：

```matlab
fov_psf_data.psf_grid      % [H, W, 10, 10] — 每個 FOV 點的 fitted PSF
fov_psf_data.coef_grid     % [15, 10, 10]   — Zernike 係數
fov_psf_data.fval_map      % [10, 10]        — 擬合誤差
fov_psf_data.iterations_map% [10, 10]        — 迭代次數
fov_psf_data.filename_map  % [10, 10]        — 對應檔名
```

**效能選項：**

```matlab
ENABLE_PLOTS = false;  % 關閉即時繪圖，大幅加速批次執行
```

**影像排序規則：**
程式依檔名末尾數字（`_1`, `_2`, …, `_100`）自然排序，對應 FOV 格點為 row-major 左至右、上至下排列：

```
[_1  _2  ... _10 ]
[_11 _12 ... _20 ]
...
[_91 _92 ... _100]
```

---

### 階段 3：Wiener 反捲積驗證

位於 `HDR_fitting_2D.m` 或 `HDR_fitting_2D_WholeFOV.m` 的 **Section 2**（`%%` 分隔）。

**輸入：**
- `Deconvolution/PSF/PSF_fitted_2D.mat` — 擬合好的 PSF
- `Deconvolution/TestImages/30.tiff` — 待反捲積的實驗 TIFF
- `Deconvolution/GT/pillar_30_SEM.tiff` — SEM GT（用於計算誤差）

**執行方式：** 在 MATLAB 中選取 Section 2，按 `Ctrl+Enter` 單獨執行。

**輸出：**
- `Deconvolution/Results/deconv_result_2D.tiff` — 16-bit 反捲積結果

**最佳化邏輯：**
BADS 搜尋最佳 NSR（Noise-to-Signal Ratio）參數，Loss 為反捲積影像與 SEM GT 的梯度 MSE。

## 各函式說明

| 函式 | 位置 | 功能 |
|------|------|------|
| `aberration(coef)` | HDR_fitting_2D*.m 內 | 計算給定 Zernike 係數下的擬合誤差（Loss），供 BADS 呼叫 |
| `wnrbads(input)` | HDR_fitting_2D*.m 內 | 計算給定 NSR 下的 Wiener 反捲積誤差，供 BADS 呼叫 |
| `normlz(x)` | SimulatePSF/normlz.m | 將陣列正規化至 [0, 1] |
| `MicroscPSF` | SimulatePSF/MicroscPSF.m | 顯微鏡 PSF 理論計算（Gibson-Lanni 模型） |

## 常見問題

**Q: 執行時出現 `Undefined function 'normlz'`**
A: 尚未加入 Path。在 MATLAB 執行：`addpath('SimulatePSF')`

**Q: 執行時出現 `No input images found`（WholeFOV）**
A: 確認 MATLAB Current Folder 為 `PSF_Fitting/`，且 `Crop_circle_FreqFiltered/` 內有 `VisionTop_*.bmp` 檔案。

**Q: `Expected 100 images but found N`**
A: `grid_rows` 和 `grid_cols` 設定值（目前各為 10）必須與實際圖片數量相符。

**Q: GPU 相關錯誤**
A: 確認電腦有支援 CUDA 的 NVIDIA GPU，且已安裝 Parallel Computing Toolbox。反捲積（階段 3）可在 CPU 上執行，不受影響。
