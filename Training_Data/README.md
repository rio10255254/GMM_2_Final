# 共享訓練資料與原生成程式

本區主要保存早期共享主線的資料生成程式：[場景生成](Data_Simulaion.py)及[光學卷積](PSF_Convolution.py)。原檔拼字沿歷史保留。

**這兩支程式不是全部R輪次的通用生成器。** R88之後的獨立資料及Lab R61、R152各有自己來源；先讀[各輪生成方法與固定來源](../docs/reproducibility/GENERATION_GUIDE.md)。R94至98用R93基礎，R99／100／102至104用R92，不能互換。

可生成的大型訓練影像不整套放GitHub；原設定、來源、種子、修正與分組仍要保留。相機原拍及人工／歷史幾何不能用新生成器替代。
