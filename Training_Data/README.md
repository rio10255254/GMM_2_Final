# 訓練資料

這裡放第一代共用模型的資料生成程式：[Data_Simulaion.py](Data_Simulaion.py) 畫出邊緣清楚的合成場景，[PSF_Convolution.py](PSF_Convolution.py) 再照量到的 PSF 把它弄糊。檔名的拼字（Simulaion）是當年的寫法，沒有改。

**這兩支不是每一輪都通用的生成程式。** R88 以後的輪次、Lab 的 R61、論文的 R152，都各有自己的資料來源和生成方式，先查[各輪的生成方法](../docs/reproducibility/GENERATION_GUIDE.md)。有幾組輪次共用同一份基礎資料，但組跟組之間不能互換：R94 到 R98 用 R93 的，R99、R100、R102 到 R104 用 R92 的。

生成出來的大量訓練影像不放 GitHub，因為可以重新生成。要重新生成，需要的設定、來源、亂數種子、修正和分組都有保存。相機原拍和人工標的幾何就不一樣了，那是換不回來的東西，不能拿新生成的資料代替。
